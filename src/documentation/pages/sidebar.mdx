<PageHeader slug="sidebar" title="Sidebar" component="sidebar">
  A composable, themeable application sidebar with collapsible state, mobile sheet overlay, collapsible groups, submenus, badges, and keyboard shortcut (Cmd+B).
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground" style="margin:0 0 0.75rem;">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground" style="margin:0 0 0.75rem;padding-left:1.25rem;">
    <li><code>default</code> — expanded (the authored width; <code>setState('default')</code> restores it)</li>
    <li><code>collapsed</code> — icon-rail width via the documented <code>data-state="collapsed"</code> attribute</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/sidebar-\{state\}.png</code>.</p>
</StatesSection>
