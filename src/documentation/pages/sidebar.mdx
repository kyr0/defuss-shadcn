  <SkillField label="Notes">
<p class="text-muted-foreground m-0">• While the mobile sheet is modal, <code>html:has(.sidebar-mobile:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> - the page behind cannot scroll and its position is preserved for when the sheet closes (no JS scroll-lock).<br/>• <strong>Auto-collapse</strong>: when the sidebar's row (its container) drops below 24rem the component docks itself to the icon rail and restores above 28rem (hysteresis - no flicker). Trigger clicks, <code>Cmd/Ctrl+B</code> and <code>api.setState()</code> count as deliberate choices and pin the sidebar against the heuristic.</p>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - expanded (the authored width; <code>setState('default')</code> restores it)</li>
    <li><code>collapsed</code> - icon-rail width via the documented <code>data-state="collapsed"</code> attribute</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/sidebar-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/sidebar.schema.json"><code>sidebar.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `collapsed` | `boolean` | `true`, `false` | `false` | Rail mode - icon-only width carried by `data-state="collapsed"`. |
```
