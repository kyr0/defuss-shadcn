<PageHeader slug="chart" title="Chart" component="chart">
  Data visualization on the <DocLink href="state-api.html">State API</DocLink>: <strong>Apache ECharts</strong> does the drawing (vendor script, zero bytes shipped) while the component owns the lifecycle - declarative <code>data-chart</code> mounting, a theme adapter that reads the design tokens off <code>getComputedStyle</code> (themes and dark mode apply with no JS state), container-accurate resize, reduced-motion suppression, and <code>df$.shadcn.chartStory()</code> for data-storytelling transitions.
</PageHeader>
