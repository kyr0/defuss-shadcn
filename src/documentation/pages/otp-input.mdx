<PageHeader slug="otp-input" title="OTP Input" component="otp-input">
  A short code typed once - SMS verification, email confirmation, a PIN. One real <code>&lt;input&gt;</code> covers a row of slots instead of one input per digit: paste, <code>one-time-code</code> autofill, selection, IME and the form value all stay the browser's, and a screen reader announces one labelled field rather than six. The slots only mirror the value.
</PageHeader>

```html example label="Verify on complete" schema="none" hint="otp-complete fires with the value the moment the last character lands - typed, pasted or autofilled. Here it checks the code (try 424242): a wrong code enters the invalid state (aria-invalid, not just a red border), a right one submits."
<form class="flex flex-col gap-2 items-start" id="otp-form" onsubmit="event.preventDefault()">
  <label class="label" for="otp-verify">Enter the code - hint: 424242</label>
  <div class="otp-input" id="otp-verify-wrap" data-group-size="3">
    <input id="otp-verify" name="code" type="text" aria-describedby="otp-verify-msg">
  </div>
  <p class="field-description" id="otp-verify-msg" aria-live="polite">6 digits</p>
</form>
<script>
  const wrap = document.getElementById('otp-verify-wrap');
  const msg = document.getElementById('otp-verify-msg');
  wrap.addEventListener('otp-complete', (e) => {
    if (e.detail.value === '424242') {
      msg.textContent = 'Verified ✓';
    } else {
      wrap.api.setState('invalid');
      msg.textContent = 'That code is not right - try again.';
    }
  });
  wrap.querySelector('input').addEventListener('input', () => {
    if (wrap.api?.getState().name === 'invalid' && wrap.querySelector('input').value.length < 6) {
      wrap.api.setState('default');
      msg.textContent = '6 digits';
    }
  });
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - editable; <code>\{ value \}</code> presets the code</li>
    <li><code>filled</code> - complete; entered automatically the moment the last character lands (<code>\{ value \}</code> optional)</li>
    <li><code>invalid</code> - the code was rejected: <code>aria-invalid="true"</code> and destructive slots</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/otp-input-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/otp-input.schema.json"><code>otp-input.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `string` | `—` | `""` | The code; set through the State API (`setState('default', { value })`), read from the input. |
| `filled` | `boolean` | `true`, `false` | `false` | Complete - entered automatically when the last character lands. |
| `invalid` | `boolean` | `true`, `false` | `false` | Rejected: `aria-invalid` and destructive slots. |
```
