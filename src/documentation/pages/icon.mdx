<PageHeader slug="icon" title="Icon" component="icon">
  ~1,500 <DocLink href="https://lucide.dev/icons/" target="_blank">Lucide</DocLink> icons via CDN. Write <code>&lt;i data-lucide="name"&gt;</code> — the Lucide CDN script replaces it with an inline SVG at page load. Requires the Lucide <code>&lt;script&gt;</code> tag (see <DocLink href="installation.html">Installation</DocLink>).
</PageHeader>

<SkillPanel component="icon">
  <SkillField label="Native basis">
<SkillText><code>&lt;i&gt;</code> element with <code>data-lucide</code> attribute. Icons are provided by the \[Lucide\](https://lucide.dev) icon library via CDN. Lucide replaces each <code>&lt;i data-lucide="name"&gt;</code> with an inline SVG on page load.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/SVG/Element/svg" title="inline scalable vector graphics (injected by Lucide)"><code>&lt;svg&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-hidden" title="hides decorative icons from screen readers"><code>aria-hidden</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/color_value#currentcolor_keyword" title="icons inherit stroke color from the parent's color property"><code>currentColor</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion" title="suppresses icon animations when user prefers reduced motion"><code>prefers-reduced-motion</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="maps icon color to system CanvasText in Windows High Contrast Mode"><code>forced-colors</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-contrast" title="increases stroke width when user requests more contrast"><code>prefers-contrast</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-lucide</code> — icon name (required)</SkillText>
  <SkillText dense>• <code>data-size</code> — <code>xs</code> | <code>sm</code> | <code>md</code> | <code>lg</code> | <code>xl</code></SkillText>
  <SkillText>• <code>data-animate</code> — <code>spin</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Icons inherit <code>currentColor</code> for stroke — they automatically match the parent's text color</SkillText>
  <SkillText dense>• Browse all available icons at <DocLink href="https://lucide.dev/icons/" target="_blank">lucide.dev/icons</DocLink></SkillText>
  <SkillText dense>• Lucide provides ~1,500 icons covering every common web app need</SkillText>
  <SkillText dense>• The CDN script replaces <code>&lt;i data-lucide="name"&gt;</code> elements with inline SVGs on page load</SkillText>
  <SkillText dense>• Use <code>stroke-width</code> attribute to adjust line thickness (default: <code>2</code>)</SkillText>
  <SkillText dense>• Prefer visually-hidden text (<code>.sr-only</code>) over <code>aria-label</code> for accessible standalone icons</SkillText>
  <SkillText dense>• Animations (e.g., <code>data-animate="spin"</code>) are suppressed when the user has <code>prefers-reduced-motion</code> enabled</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>prefers-contrast: more</code> increases stroke width to 2.5 for better visibility</p>
  </SkillField>
</SkillPanel>
