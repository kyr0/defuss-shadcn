```html example label="Default" hint="Standard spinner at default size."
<svg class="spinner" role="status" aria-label="Loading" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <path d="M21 12a9 9 0 1 1-6.219-8.56"></path>
</svg>
```

```html example label="Sizes" hint="The full five-step scale via data-size - the default is 1rem, between sm and md."
<svg class="spinner" data-size="xs">...</svg>
<svg class="spinner" data-size="sm">...</svg>
<svg class="spinner" data-size="md">...</svg>
<svg class="spinner" data-size="lg">...</svg>
<svg class="spinner" data-size="xl">...</svg>
```

```html example label="In Button" hint="Spinner inside a loading button."
<button class="btn" data-variant="default" disabled>
  <svg class="spinner" data-size="sm" aria-hidden="true">...</svg>
  Loading...
</button>
```
