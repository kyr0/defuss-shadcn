<PageHeader slug="location-map" title="Location Map" component="location-map">
  Displays one or more locations on an interactive map - pins open a card anchored to them, a list beside the map names every place. Part of the <DocLink href="website-events-promotions.html">Events & Promotions</DocLink> blocks.
</PageHeader>

<SkillPanel component="location-map">
  <SkillField label="Native basis">
<SkillText>A map surface (an inline SVG - or an embedded map image) with absolutely placed pins (<code>--x</code> / <code>--y</code>): each pin is a <code>&lt;button popovertarget&gt;</code> whose <code>popover</code> card is anchored to it (<code>anchor-name</code> / <code>position-anchor</code>). A list beside it repeats every place as text.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
