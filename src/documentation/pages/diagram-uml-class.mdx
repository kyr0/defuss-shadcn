<PageHeader slug="diagram-uml-class" title="Illustrative · UML Class" component="diagram">
  The static structure of an object model: each class a box with up to three compartments - name (<code>data-shape="class"</code>, <code>«interface»</code> as the eyebrow, <code>data-abstract</code> sets it italic), attributes (<code>.diagram-node-fields</code>) and operations (<code>.diagram-node-ops</code>). The ends carry the meaning: <code>triangle</code> inheritance (dashed: realization), <code>diamond</code> composition, <code>diamond-open</code> aggregation, <code>open</code> + dashed dependency.
</PageHeader>

<H2 id="interactive">Interactive</H2>

<DocText>A click activates a box or an arrow: what it touches stays lit, everything else steps back. The buttons outside the figure drive the same activation - <code>data-diagram-for</code> + <code>data-diagram-action="next|prev|clear"</code> - and the <code>&lt;output data-diagram-for&gt;</code> names what is active. Keyboard: Tab to a box, Enter, arrows, Escape.</DocText>

<H2 id="inspect">Inspect and edit</H2>

The × closes the panel, the Inspector button toggles it.</DocText>
