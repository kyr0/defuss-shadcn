<PageHeader slug="alert-dialog" title="Alert Dialog" component="alert-dialog">
  A modal dialog that interrupts the user and requires a response. Unlike a standard dialog, users cannot dismiss it by clicking the backdrop or pressing Escape — they must choose an action. Built on native <code>&lt;dialog&gt;</code>.
</PageHeader>

<SkillPanel component="alert-dialog">
  <SkillField label="Native basis">
<SkillText><code>&lt;dialog&gt;</code> element used as a modal that requires user response. Unlike a standard dialog, it has no backdrop-close and no close button — the user must choose an action.</SkillText>
  </SkillField>

  <SkillField label="Wiring conventions">
<SkillText dense>• <code>data-alert-dialog-trigger</code> on any element — opens the component</SkillText>
  <SkillText>• <code>data-alert-dialog-close</code> on any element inside — closes the component</SkillText>
  </SkillField>

  <SkillField label="Accessibility">
<SkillText dense>• Uses <code>role="alertdialog"</code> instead of <code>role="dialog"</code> — signals interruption</SkillText>
  <SkillText dense>• <code>aria-labelledby</code> and <code>aria-describedby</code> link to title and description</SkillText>
  <SkillText dense>• No backdrop click dismiss — user must make an explicit choice</SkillText>
  <SkillText dense>• Escape key is disabled — user must use the action buttons</SkillText>
  <SkillText dense>• Focus is trapped inside the dialog via native <code>showModal()</code></SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• While the alert is modal, <code>html:has(dialog.alert-dialog:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> — the page behind cannot scroll and its position is preserved for when the alert closes (no JS scroll-lock)</p>
  </SkillField>
</SkillPanel>

<Example first>
  <ExampleLabel>Basic</ExampleLabel>
  <ExampleHint>Confirm/cancel pattern with title and description.</ExampleHint>
  <button class="btn" data-variant="outline" data-alert-dialog-trigger="demo-alert-dialog-1">Delete Account</button>
  <dialog id="demo-alert-dialog-1" class="alert-dialog" data-state-demo role="alertdialog" aria-modal="true" aria-labelledby="ad1-title" aria-describedby="ad1-desc">
    <div class="alert-dialog-content">
      <div class="alert-dialog-header">
        <h2 class="alert-dialog-title" id="ad1-title">Are you absolutely sure?</h2>
        <p class="alert-dialog-description" id="ad1-desc">This action cannot be undone. This will permanently delete your account and remove your data from our servers.</p>
      </div>
      <div class="alert-dialog-footer">
        <button class="btn" data-variant="outline" data-alert-dialog-close>Cancel</button>
        <button class="btn" data-variant="destructive" data-alert-dialog-close>Delete</button>
      </div>
    </div>
  </dialog>
