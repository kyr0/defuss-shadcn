<PageHeader slug="diagram-matrix" title="Illustrative · Matrix" component="diagram">
  A matrix is a real <code>&lt;table class="diagram-matrix"&gt;</code> inside the figure - row and column headers stay table semantics. Cells carry permission chips (<code>data-perm="full|write|read|none"</code>), heat (<code>--v</code> from 0 to 1, mixed from the accent) or plain values; the finding gets <code>data-tone="accent"</code>. Rows play as steps; any cell can carry its own <code>data-step</code>.
</PageHeader>
