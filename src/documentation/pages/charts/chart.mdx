<PageHeader slug="chart" title="Chart" component="chart">
  Data visualization on the <DocLink href="state-api.html">State API</DocLink>: <strong>Apache ECharts</strong> does the drawing (vendor script, zero bytes shipped) while the component owns the lifecycle - declarative <code>data-chart</code> mounting, a theme adapter that reads the design tokens off <code>getComputedStyle</code> (themes and dark mode apply with no JS state), container-accurate resize, reduced-motion suppression, and <code>df$.shadcn.chartStory()</code> for data-storytelling transitions.
</PageHeader>

  <SkillField label="Print">
<SkillText>A print lays the page out at the paper's width, where a ResizeObserver delivers nothing: every live chart resizes and repaints at once (no animation) when the print media query starts to match, and back when the print ends. Until then the screen drawing is clipped to its box, so it never widens the printed page - Chromium would shrink the whole print to fit.</SkillText>

```html example part label="Chart"
<div
  class="chart"
  role="img"
  aria-label="Bar chart of quarterly revenue, rising from 12 to 24"
  data-chart='{"xAxis":{"type":"category","data":["Q1","Q2","Q3","Q4"]},"yAxis":{"type":"value"},"series":[{"id":"rev","type":"bar","universalTransition":true,"barWidth":"48%","label":{"show":true,"position":"top","fontWeight":600},"data":[12,19,15,24]}]}'
></div>
```

