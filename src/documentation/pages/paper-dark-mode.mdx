    <h2 id="pd-abstract">Abstract</h2>
    <p>A theme that is round in light mode and square in dark mode is two themes. defuss-shadcn treats light and dark as two palettes of one identity: every preset declares its radius in both blocks with the same value, a verifier gate fails the build otherwise, and the reading pairs reach 4.5:1 in both modes.</p>

    <h2 id="pd-s2"><span class="paper-num">2</span>The switch</h2>
    <p>The Swap is a label around a checkbox; CSS turns the sun into the moon. The page listens to the checkbox and toggles <code>.dark</code> on the root element - the token file's dark block matches it, so every component follows without a second stylesheet.</p>
