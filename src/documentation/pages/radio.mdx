<PageHeader slug="radio" title="Radio Group" component="radio">
  A set of mutually exclusive options. Built on native <code>&lt;input type="radio"&gt;</code> with <code>&lt;fieldset&gt;</code> grouping.
</PageHeader>

<SkillPanel component="radio">
  <SkillField label="Native basis">
<SkillText><code>&lt;input type="radio"&gt;</code> elements with shared <code>name</code> attribute for mutual exclusivity.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/radio" title="native radio button with group exclusivity via name"><code>&lt;input type="radio"&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/fieldset" title="semantic group container with native disabled propagation"><code>&lt;fieldset&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:checked" title="matches selected state"><code>:checked</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:focus-visible" title="keyboard-only focus ring"><code>:focus-visible</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:has" title="parent-state styling for card variant"><code>:has()</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion" title="suppress transitions for motion-sensitive users"><code>prefers-reduced-motion</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="Windows High Contrast Mode support"><code>forced-colors</code></ApiPill>

  <SkillField label="Accessibility">
<SkillText dense>• Native <code>&lt;fieldset&gt;</code> + <code>&lt;legend&gt;</code> provides group labeling.</SkillText>
  <SkillText dense>• Radio buttons sharing the same <code>name</code> are mutually exclusive by default.</SkillText>
  <SkillText dense>• Arrow keys navigate between options (native browser behavior).</SkillText>
  <SkillText dense>• <code>:focus-visible</code> provides keyboard-only focus rings.</SkillText>
  <SkillText dense>• <code>prefers-reduced-motion</code> disables transitions.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>forced-colors</code> provides Windows High Contrast Mode support.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Styled with <code>appearance: none</code> and a custom dot via <code>::after</code>.</SkillText>
  <SkillText dense>• The <code>name</code> attribute is required for mutual exclusivity.</SkillText>
  <SkillText dense>• No JavaScript needed — browsers handle group behavior natively.</SkillText>
  <SkillText dense>• Use <code>.radio-item</code> for simple label. Use <code>.radio-item-block</code> for label + description.</SkillText>
  <SkillText dense>• Use <code>.radio-card</code> for card-style selection with <code>:has()</code> highlight.</SkillText>
  <SkillText dense>• Add <code>data-orientation="horizontal"</code> for horizontal layout.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>&lt;fieldset disabled&gt;</code> disables all radios in the group natively.</p>
  </SkillField>
</SkillPanel>
