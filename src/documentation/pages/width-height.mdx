<h2 id="numeric" class="h2-display">Numeric dimensions</h2>

<DocText><code>w-n</code>, <code>h-n</code> and <code>size-n</code> map directly to <code>n × --size-base</code> - <code>w-48</code> is 48 × 4px = 192px at the default root. Width and height are physical axes, matching their CSS names, and density does not change them.</DocText>

```html example schema="none"
<div class="stack gap-4" data-demo="width-height">
  <div class="demo-tile w-48 h-8">w-48 h-8</div>
  <div class="demo-tile w-24 h-8">w-24 h-8</div>
  <div class="flex items-center gap-3">
    <div class="demo-tile size-8"></div>
    <span class="demo-label demo-label-inline">size-8 - same in both axes</span>
  </div>
</div>
```

<h2 id="fractions" class="h2-display">Fractions and full width</h2>

<DocText><code>w-1/2</code>, <code>w-1/3</code>, <code>w-2/3</code>, <code>w-1/4</code>, <code>w-3/4</code> and <code>w-full</code> size against the containing block. Percentage heights like <code>h-1/2</code> need a definite containing height.</DocText>

```html example schema="none"
<div class="stack gap-3">
  <div class="demo-tile w-full h-6">w-full</div>
  <div class="demo-tile w-3/4 h-6">w-3/4</div>
  <div class="demo-tile w-2/3 h-6">w-2/3</div>
  <div class="demo-tile w-1/2 h-6">w-1/2</div>
  <div class="demo-tile w-1/3 h-6">w-1/3</div>
  <div class="demo-tile w-1/4 h-6">w-1/4</div>
</div>
```


<DocText>The classic sidebar/main split - resize the demo with the toolbar and watch it adapt:</DocText>

```html example schema="none"
<div class="flex flex-wrap gap-4">
  <aside class="w-1/3 demo-tile demo-outline h-24" data-variant="muted" style="min-width:8rem;">w-1/3 - Filters</aside>
  <section class="demo-tile h-24" style="flex:1;min-width:12rem;">w-2/3 - Results</section>
</div>
```

<h2 id="intrinsic" class="h2-display">Content-based sizing</h2>

<DocText><code>w-auto</code> defers to the layout algorithm; <code>w-fit</code> shrinks to the content; <code>w-min</code> and <code>w-max</code> use the content's minimum and maximum intrinsic widths. These are the right tools for badges, chips and buttons that should hug their label.</DocText>

```html example schema="none"
<div class="stack gap-3">
  <div class="demo-tile w-fit h-6 px-2" data-variant="secondary">w-fit hugs this label</div>
  <div class="demo-tile w-min h-6 px-2" data-variant="secondary">w-min wraps early</div>
  <div class="demo-tile w-auto h-6 px-2" data-variant="secondary">w-auto fills the block direction like any block box</div>
</div>
```

<h2 id="constraints" class="h2-display">Constraints: min, max and none</h2>

<DocText>Dimensions are constraints, not clipping. <code>max-w-\*</code> caps a box without narrowing the page below the cap; <code>min-h-\*</code> guarantees a floor while content can grow past it; <code>max-w-none</code> removes a cap a component shipped with.</DocText>

```html example schema="none"
<div class="stack gap-4">
  <div class="demo-tile max-w-32 h-auto p-2" data-variant="muted">max-w-32 caps this note at 128px, whatever the page does</div>
  <div class="demo-tile min-h-24 p-2" data-variant="outline">min-h-24 keeps this box at least 96px tall even with one line of content</div>
</div>
```


<DocText>In flex layouts a requested width may shrink: add <code>shrink-0</code> when that is intentional, and put <code>min-w-0</code> on the flexible child so long content wraps instead of widening the page:</DocText>

```html example schema="none"
<div class="flex gap-4">
  <aside class="demo-tile w-24 shrink-0 h-16">w-24 shrink-0</aside>
  <main class="flex-1 min-w-0 wrap-anywhere demo-tile h-auto p-2" data-variant="outline" style="justify-content:flex-start;">flex-1 min-w-0 - AnUnusuallyLongIdentifierThatMustWrapInsteadOfWideningThePage</main>
</div>
```


<DocText>A constrained box turns its overflow into a scrollbar with <code>overflow-x-auto</code>; pair it with <code>whitespace-nowrap</code> on the content so wide rows scroll instead of wrapping into a mess:</DocText>

```html example schema="none"
<div class="demo-tile demo-outline max-w-64 overflow-x-auto" data-variant="muted" style="display:block;padding:0.75rem;">
  <table class="table whitespace-nowrap" style="font-size:0.8125rem;">
    <thead><tr class="table-row"><th class="table-head">Component</th><th class="table-head">Native basis</th><th class="table-head">Needs JS</th></tr></thead>
    <tbody>
      <tr class="table-row"><td class="table-cell">Dialog</td><td class="table-cell">{"<dialog> + showModal()"}</td><td class="table-cell">State API only</td></tr>
      <tr class="table-row"><td class="table-cell">Accordion</td><td class="table-cell">{"<details name>"}</td><td class="table-cell">No</td></tr>
    </tbody>
  </table>
</div>
```

<h2 id="logical" class="h2-display">Logical dimensions</h2>

<DocText><code>inline-\*</code> and <code>block-\*</code> mirror the numeric scale on the writing-mode axes: inline is width in horizontal writing, height in vertical writing. Below, the same classes - <code>inline-40 block-24 ps-4</code> - in three contexts. The filled area is the content box; the gap the <code>ps-4</code> leaves follows inline-start: left in LTR, right in RTL, top in vertical writing.</DocText>

```html example schema="none"
<div class="flex flex-wrap gap-6">
  <div>
    <p class="demo-label">LTR</p>
    <div class="demo-tile inline-40 block-24 ps-4" data-variant="outline" style="padding-block:0.25rem;padding-inline-end:0.25rem;">
      <div class="demo-tile h-full" data-variant="muted" style="flex:1;">content</div>
    </div>
  </div>
  <div dir="rtl">
    <p class="demo-label">RTL - same classes</p>
    <div class="demo-tile inline-40 block-24 ps-4" data-variant="outline" style="padding-block:0.25rem;padding-inline-end:0.25rem;">
      <div class="demo-tile h-full" data-variant="muted" style="flex:1;">content</div>
    </div>
  </div>
  <div>
    <p class="demo-label">vertical-rl - same classes</p>
    <div class="demo-tile inline-40 block-24 ps-4" data-variant="outline" style="writing-mode:vertical-rl;padding-block:0.25rem;padding-inline-end:0.25rem;">
      <div class="demo-tile" data-variant="muted" style="flex:1;inline-size:100%;">content</div>
    </div>
  </div>
</div>
```

<h2 id="viewport" class="h2-display">Viewport sizes and the app shell</h2>

<DocText><code>h-screen</code> / <code>min-h-screen</code> / <code>max-h-screen</code> are 100vh, with <code>dvh</code>, <code>svh</code> and <code>lvh</code> variants for mobile browser chrome. Their classic use is the app shell - header, fluid content, footer at the bottom even with little content. The demo renders that pattern inside a fixed-height frame; at page level you would write <code>min-h-screen</code> instead of <code>h-full</code>.</DocText>

```html example schema="none"
<div class="demo-outline" style="block-size:16rem;">
  <div class="stack h-full gap-0">
    <header class="demo-tile h-10" style="border-radius:0;">header</header>
    <div class="flex-1 min-h-0 demo-tile h-auto" data-variant="muted">flex-1 - content fills whatever is left</div>
    <footer class="demo-tile h-10" data-variant="secondary" style="border-radius:0;">footer - pushed down, never floating mid-page</footer>
  </div>
</div>
```


<DocText>Prefer <code>dvh</code> units when content must survive the mobile URL bar collapsing. <code>w-screen</code> is 100vw - it includes the scrollbar and ignores the parent, so <code>w-full</code> is usually the right choice inside a page.</DocText>

<h2 id="custom" class="h2-display">Application-specific sizes</h2>

<DocText>Values outside the scale are ordinary CSS - a clamped inspector panel and an optimal reading width. Resize with the toolbar: the inspector's <code>clamp()</code> tracks the frame width while the prose column stays at its measure.</DocText>

```html example schema="none"
<div class="flex flex-wrap gap-4">
  <aside class="demo-tile h-32 p-2" data-variant="accent" style="width:clamp(10rem, 35%, 14rem);">inspector - clamp(10rem, 35%, 14rem)</aside>
  <article class="demo-tile h-auto p-4" data-variant="muted" style="max-inline-size:38ch;flex:1;min-width:14rem;display:block;">article-copy - max-inline-size keeps the measure readable no matter how wide the frame gets. This sentence just fills space to make the line length visible.</article>
</div>
```

```css
.inspector { width: clamp(16rem, 30vw, 24rem); }
.application-shell { min-height: 100dvh; }
.article-copy { max-inline-size: 70ch; }
```


<DocText>Keep content widths, typography and control recipes semantically distinct from the small geometric <code>--size-xs...xl</code> aliases. Load sizing.css; load layout.css as well for Flex/Grid helpers.</DocText>
