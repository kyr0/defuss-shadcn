<PageHeader slug="type-badge" title="Type Badge" component="type-badge">
  A mono chip marking a component's atomic-design type — one color identity per type (ATM · MOL · ORG · BLK · TPL), identical in light and dark schemes. Pure visual marker, no JavaScript required.
</PageHeader>

<SkillPanel component="type-badge">
  <SkillField label="Native basis">
    <SkillText><code>&lt;span&gt;</code> element with <code>data-type</code> driving the color and <code>title</code> carrying the full type name as the native tooltip. No interactivity.</SkillText>
  </SkillField>
  <SkillField label="Web Platform APIs">
