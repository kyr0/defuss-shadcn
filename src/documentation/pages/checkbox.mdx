<PageHeader slug="checkbox" title="Checkbox" component="checkbox">
  A control that toggles between checked and unchecked. Built on native <code>&lt;input type="checkbox"&gt;</code> with CSS-only checkmark.
</PageHeader>

<SkillPanel component="checkbox">
  <SkillField label="Native basis">
<SkillText><code>&lt;input type="checkbox"&gt;</code> element styled with CSS <code>appearance: none</code>.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/checkbox" title="native toggle control with built-in keyboard and form support"><code>&lt;input type="checkbox"&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:checked" title="matches checked state"><code>:checked</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:indeterminate" title="matches the indeterminate (mixed) state"><code>:indeterminate</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:focus-visible" title="keyboard-only focus ring"><code>:focus-visible</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:user-invalid" title="post-interaction validation styling"><code>:user-invalid</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.checkbox</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Accessibility">
<SkillText dense>• The native <code>&lt;input type="checkbox"&gt;</code> provides all keyboard and screen reader support.</SkillText>
  <SkillText dense>• Use <code>&lt;label&gt;</code> with <code>for</code> to associate the label text.</SkillText>
  <SkillText dense>• Use <code>&lt;fieldset&gt;</code> + <code>&lt;legend&gt;</code> for checkbox groups.</SkillText>
  <SkillText dense>• Use <code>aria-invalid="true"</code> for validation errors.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• Use <code>indeterminate</code> property via JS for the indeterminate (mixed) state.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Styled with <code>appearance: none</code> and a custom checkmark via <code>::after</code> pseudo-element.</SkillText>
  <SkillText dense>• The checkmark uses a CSS-only approach — no SVG or icon font needed.</SkillText>
  <SkillText dense>• Indeterminate state is set via JavaScript: <code>checkbox.indeterminate = true;</code>.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• In <code>forced-colors: active</code>, the checkbox reverts to <code>appearance: auto</code> so Windows High Contrast Mode controls rendering.</p>
  </SkillField>
</SkillPanel>
