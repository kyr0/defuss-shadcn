<PageHeader slug="checkbox" title="Checkbox" component="checkbox">
  A control that toggles between checked and unchecked. Built on native <code>&lt;input type="checkbox"&gt;</code> with CSS-only checkmark.
</PageHeader>

<SkillPanel component="checkbox">

  <SkillField label="Accessibility">
<SkillText dense>• The native <code>&lt;input type="checkbox"&gt;</code> provides all keyboard and screen reader support.</SkillText>
  <SkillText dense>• Use <code>&lt;label&gt;</code> with <code>for</code> to associate the label text.</SkillText>
  <SkillText dense>• Use <code>&lt;fieldset&gt;</code> + <code>&lt;legend&gt;</code> for checkbox groups.</SkillText>
  <SkillText dense>• Use <code>aria-invalid="true"</code> for validation errors.</SkillText>
  <p class="text-muted-foreground m-0">• Use <code>indeterminate</code> property via JS for the indeterminate (mixed) state.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Styled with <code>appearance: none</code> and a custom checkmark via <code>::after</code> pseudo-element.</SkillText>
  <SkillText dense>• The checkmark uses a CSS-only approach — no SVG or icon font needed.</SkillText>
  <SkillText dense>• Indeterminate state is set via JavaScript: <code>checkbox.indeterminate = true;</code>.</SkillText>
  <p class="text-muted-foreground m-0">• In <code>forced-colors: active</code>, the checkbox reverts to <code>appearance: auto</code> so Windows High Contrast Mode controls rendering.</p>
  </SkillField>
</SkillPanel>

```html example label="Default" hint="Basic checkbox with label."
<input class="checkbox" type="checkbox" id="terms">
<label for="terms">Accept terms and conditions</label>
```

```html example label="With description" hint="Checkbox with helper text."
<input class="checkbox" type="checkbox" id="notify" aria-describedby="notify-desc">
<div>
  <label for="notify">Enable notifications</label>
  <p class="field-description" id="notify-desc">...</p>
</div>
```

```html example label="Disabled"
<input class="checkbox" type="checkbox" disabled>
<input class="checkbox" type="checkbox" disabled checked>
```

```html example label="Checked by default"
<input class="checkbox" type="checkbox" id="option" checked>
<label for="option">Pre-checked option</label>
```

```html example label="Indeterminate" hint="Set via JavaScript: checkbox.indeterminate = true."
<input class="checkbox" type="checkbox" id="select-all">
<label for="select-all">Select all</label>

<script>
  document.getElementById('select-all').indeterminate = true;
</script>
```

```html example label="Invalid" hint="Shows destructive border via aria-invalid='true'."
<input class="checkbox" type="checkbox" aria-invalid="true">
<label for="terms">Accept terms and conditions</label>
```

```html example label="Group" hint="Multiple checkboxes in a group using &lt;fieldset&gt; and &lt;legend&gt;."
<fieldset aria-describedby="grp-desc">

  <p class="field-description" id="grp-desc">Choose which items are visible.</p>

    <label for="item-1">Hard disks</label>
  </div>
  <div class="checkbox-item">
    <input class="checkbox" type="checkbox" id="item-2" checked>
    <label for="item-2">External disks</label>

  <!-- ... more items -->
</fieldset>
```
