<PageHeader slug="diagram-loop" title="Illustrative · Loop" component="diagram">
  Reinforcing cycles: stations on a ring (<code>--i</code> of <code>--n</code>, placed with CSS <code>sin()</code> / <code>cos()</code>), a hub in the middle (<code>data-hub</code>) that every pass writes back to. Arcs are <code>data-curve="curve"</code> (they bend away from the center); a <code>data-flow</code> token travels the closing arc.
</PageHeader>
