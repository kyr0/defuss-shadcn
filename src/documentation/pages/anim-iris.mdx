The iris is a `clip-path: circle()` reveal - the visible region grows from a point into a full circle (`irisIn`) or collapses back into a point (`irisOut`). It is not directional; instead the **origin** is the star config: the circle opens and closes around any `'x y'` position you pass (default `'50% 50%'`). Everything below is driven by the imperative engine - `df$.anim.irisIn.*()` and `df$.anim.irisOut.*()` - whose generated keyframes make origin, duration and easing true runtime config.

<script type="module">
  // all.js (core → df$) boots after example scripts in the sandbox - reference
  // df$ only at event time, never at parse time
  let currentOrigin = '50% 50%';
  let lastChannel = 'irisIn'; // Pause/Resume/Finish/Reset act on the last play
  const target = document.getElementById('anim-iris-target');
  const config = () => ({
    origin: currentOrigin,
    duration: Number(document.getElementById('anim-iris-duration').value) || 600,
    easing: document.getElementById('anim-iris-easing').value,
  });

  document.getElementById('anim-iris-in').addEventListener('click', () => {
    lastChannel = 'irisIn';
    df$.anim.irisIn.play(target, config());
  });
  document.getElementById('anim-iris-out').addEventListener('click', () => {
    lastChannel = 'irisOut';
    df$.anim.irisOut.play(target, config());
  });

  document.querySelectorAll('[data-anim-iris-origin]').forEach((btn) => {
    btn.addEventListener('click', () => {
      currentOrigin = btn.dataset.animIrisOrigin;
      document.querySelectorAll('[data-anim-iris-origin]').forEach((b) =>
        b.setAttribute('aria-pressed', String(b === btn)),
      );
    });
  });

  document.querySelectorAll('[data-anim-iris-lifecycle]').forEach((btn) => {
    btn.addEventListener('click', () => {
      df$.anim[lastChannel][btn.dataset.animIrisLifecycle](target);
    });
  });
</script>
```

    df$.anim.irisIn.reset(el); // re-clicking re-binds deterministically

Press **Bind to scroll**, then scroll the stage: the scroll position scrubs the iris open. Passing `{ target: 'viewport' }` instead of an element binds the same progress to page scroll - the parallax use for presentations.

## Config axes

- **`origin`** - `'x y'` position the circle opens from / closes toward (default `'50% 50%'`; demo: center, top-left `0% 0%`, bottom-right `100% 100%`).
- **`duration`** - total time in ms (default `1500`).
- **`easing`** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
