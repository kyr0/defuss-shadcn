</PageHeader>

<SkillPanel component="steps">
  <SkillField label="Native basis">
<SkillText><code>&lt;ol&gt;</code> with step indicators for multi-step processes.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/ol" title="ordered list"><code>&lt;ol&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current" title="identifies the current step"><code>aria-current="step"</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion" title="suppresses transitions"><code>prefers-reduced-motion</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-contrast" title="thickens borders and connector lines"><code>prefers-contrast</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="maps to system colors"><code>forced-colors</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.steps</code>
    <code>.step</code>
    <code>.step-indicator</code>
    <code>.step-content</code>
    <code>.step-title</code>
    <code>.step-description</code>
    <code>.step-icon</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillGrid>
    <Variant name="data-variant (on .steps or one .step)" description="primary (default), secondary, accent, info, success, warning, neutral, destructive / error - the color of done and current steps" />
    <Variant name='.step-indicator[data-variant="plain"]' description="no circle - just the glyph (an emoji step)" />
    <Variant name='data-orientation="vertical" / "responsive"' description="stacked; or stacked below 48rem and in a row above" />
    <Variant name="data-active-step / data-error-step" description="statuses derived by steps.js" />
  </SkillGrid>
  </SkillField>
</SkillPanel>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">The runtime declares the single <code>default</code> state; the editable contract below lives on the nav/list as <code>data-*</code> attributes, driven per instance through the bound <code>api</code> or the State tab:</p>
  <p class="text-sm text-muted-foreground">Machine contract - verified against <a class="link" href="../schemas/steps.schema.json"><code>steps.schema.json</code></a> by <code>bun run verify</code>:</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `activeStep` | `number` | `—` | `2` | Index of the current step (1-based); earlier steps render `complete`. Set by the panel or by clicking a clickable step. |
| `errorStep` | `number` | `—` | `0` | Index rendered with the destructive error status (`0` = none) - mirrors the `activeStepError` intent as an index the CSS can key. |
| `size` | `enum` | `xs`, `sm`, `md`, `lg`, `xl` | `"md"` | Indicator + type scale (display sizes). |
| `activeStepError` | `boolean` | `true`, `false` | `false` | Marks the CURRENT step with the destructive error status (true = the active step failed, false clears). Equivalent to setting `errorStep` to the active index. |
```
