<PageHeader slug="iframe" title="Iframe" component="iframe">
  An embedded page that fits where it lives - the width of its container and a height from a ratio, from the container or from the framed page's own content - with a message bridge in both directions, so the framed page can control the page around it. Built on the native <code>&lt;iframe&gt;</code> and <code>postMessage</code>.
</PageHeader>

<h2 id="security" class="h3 mt-10 mb-3">Origins, CSP and sites that refuse to be framed</h2>

<p class="text-sm text-muted-foreground mb-3">The examples above frame <code>srcdoc</code> pages, which share this page's origin - so the host can measure them and their messages carry its own origin. Across origins, three things decide what works:</p>
<ul class="text-sm text-muted-foreground mb-3 ps-5">
  <li><strong>The embedded site</strong> decides whether it may be framed at all. <code>X-Frame-Options: DENY</code> or <code>SAMEORIGIN</code>, or a CSP <code>frame-ancestors</code> without your origin, makes the browser refuse the page and show its own error inside the frame - and no script on either side can detect it. Hugging Face model pages send <code>X-Frame-Options: DENY</code>; the <DocLink href="paper-redeschrift.html">Redeschrift paper</DocLink> therefore frames a model card of its own and links to the original.</li>
  <li><strong>Your page's CSP</strong> must allow the frame's origin in <code>frame-src</code>. Messages need no CSP permission, but the framed page must be allowed to run scripts to send any.</li>
  <li><strong>The bridge</strong> accepts a message only from the window of a frame this element hosts, and only from this page's origin or one listed in <code>data-origins</code> (<code>null</code> for a sandboxed srcdoc). Inside the framed page, set <code>data-iframe-parent</code> to the host's origin so nothing it sends goes elsewhere; never combine <code>allow-scripts</code> with <code>allow-same-origin</code> in <code>sandbox</code> for content you do not trust.</li>
</ul>
