<PageHeader slug="toggle" title="Toggle" component="toggle">
  A two-state button that can be either on or off. Uses <code>&lt;button&gt;</code> with <code>aria-pressed</code>. Common for toolbar formatting buttons (bold, italic) or feature toggles.
</PageHeader>

<SkillText><code>&lt;button&gt;</code> element with <code>aria-pressed</code>. The browser provides click and keyboard</SkillText>

  <SkillField label="Notes">
<SkillText dense>• The toggle is just a button with <code>aria-pressed</code> — no custom elements needed.</SkillText>
  <SkillText dense>• Icon-only toggles must have <code>aria-label</code> for screen readers.</SkillText>
  <SkillText dense>• For toggle groups (e.g., text alignment), wrap in a container with <code>role="group"</code> and <code>aria-label</code>.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• The pressed state uses <code>--accent</code> / <code>--accent-foreground</code> to match shadcn conventions.</p>
