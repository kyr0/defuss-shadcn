<PageHeader slug="toggle" title="Toggle" component="toggle">
  A two-state button that can be either on or off. Uses <code>&lt;button&gt;</code> with <code>aria-pressed</code>. Common for toolbar formatting buttons (bold, italic) or feature toggles.
</PageHeader>

  <SkillField label="Notes">
<SkillText dense>• The toggle is just a button with <code>aria-pressed</code> - no custom elements needed.</SkillText>
  <SkillText dense>• Icon-only toggles must have <code>aria-label</code> for screen readers.</SkillText>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - unpressed (the authored <code>aria-pressed</code> value is restored by <code>setState('default')</code>)</li>
    <li><code>pressed</code> - <code>aria-pressed="true"</code>, accent background</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/toggle-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/toggle.schema.json"><code>toggle.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `pressed` | `boolean` | `true`, `false` | `false` | Pressed state carried by `aria-pressed` (runtime writes it, CSS styles it). |
```
