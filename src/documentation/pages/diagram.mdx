<PageHeader slug="diagram" title="Illustrative Diagrams" component="diagram">
  Illustrations an agent can write: diagrams as plain HTML. Nodes are elements on a CSS grid (or a free or radial canvas), relationships are an ordered list - readable without JavaScript. The component measures the layout and draws the wires into an SVG layer behind the nodes: rounded orthogonal elbows that fan out and never share a channel, routes around nodes in the way, masked labels that avoid each other, typed ends from arrows to crow's feet. Beyond the picture there is only state: a diagram plays step by step, activates a box or an arrow on click (or from controls outside it), and shows a delta - before, changes, after - from one annotated source. Colors are the theme's (chart colors for the accent and the changes), corners its radius, text its monospace - dark mode and every theme just work. No Mermaid, no dependency; the visual grammar is adapted from <a href="https://github.com/cathrynlavery/diagram-design">diagram-design</a> by Cathryn Lavery (MIT).
</PageHeader>

<H2 id="edges">Edges</H2>

<DocText>Each <code>&lt;li class="diagram-edge" data-from data-to&gt;</code> is a wire; its text is the label. Routes are scored: the elbow that crosses no node, with the fewest bends, wins. Ports on one side fan out; middle segments in one gap spread apart; labels slide along their segment until they cover nothing.</DocText>

<H2 id="layouts">Layouts</H2>

<DocText>The default canvas is a grid: <code>--cols</code> on the canvas, <code>--col</code> / <code>--row</code> / <code>--span</code> / <code>--rspan</code> on each node (any <code>grid-template-columns</code> inline works too). <code>data-layout="free"</code> places nodes at <code>--x</code> / <code>--y</code> percent; <code>data-layout="radial"</code> seats them on a ring with <code>--i</code> of <code>--n</code> (the <DocLink href="diagram-loop.html">loop</DocLink>). Groups placed on the same cells draw zones behind nodes; groups that contain nodes nest (<DocLink href="diagram-nested.html">nested</DocLink>).</DocText>

    <li><code>playing</code> - the steps play from <code>config.step</code>, one element about every second (<code>--diagram-element-ms</code>); pauses on the last</li>
    <li><code>paused</code> - stopped on <code>config.step</code> (earlier steps shown, later ones hidden)</li>
    <li><code>active</code> - a node or an edge is active (<code>config.ref</code>): it and what it touches stay lit, the rest steps back</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/diagram-\{state\}.png</code>.</p>
