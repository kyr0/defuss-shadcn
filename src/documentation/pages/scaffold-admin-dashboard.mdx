<h2 id="how-it-works" class="h2-display">How it works</h2>

<DocText>The scaffold is a page, not a component: it composes the library and keeps its own glue small.</DocText>

<ul class="text-sm" style="display:grid;gap:0.5rem;max-width:46rem;padding-inline-start:1.25rem">
  <li><strong>Shell</strong> - <DocLink href="sidebar.html">Sidebar</DocLink> (collapsible with the trigger or <kbd class="kbd">⌘B</kbd>, a mobile drawer below 44rem of width), a top bar with <DocLink href="breadcrumb.html">Breadcrumb</DocLink>, a <DocLink href="popover.html">Popover</DocLink> of notifications and the theme toggle.</li>
  <li><strong>Navigation</strong> - every view is a section with an id; links point at <code>#orders</code> and CSS shows <code>.dash-view:target</code> (the first view when nothing is targeted).
