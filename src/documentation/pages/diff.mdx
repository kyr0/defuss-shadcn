<PageHeader slug="diff" title="Diff" component="diff">
  A side-by-side comparison of two items - drag the divider to reveal more of one or the other. Two layers share one cell; the divider is a native <code>&lt;input type="range"&gt;</code>, so it drags from anywhere on the figure, steps with the arrow keys and announces its value to screen readers.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on each <code>.diff</code> figure:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the authored position, or <code>config.position</code> (0-100)</li>
    <li><code>before</code> - the divider at 100%: only item 1</li>
    <li><code>after</code> - the divider at 0%: only item 2</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/diff-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/diff.schema.json"><code>diff.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `position` | `number` | `—` | `50` | The divider position in percent - `setState('default', { position })`; observed from the range's value. |
| `before` | `boolean` | `true`, `false` | `false` | Divider at 100% - only item 1 (`setState('before')`). |
| `after` | `boolean` | `true`, `false` | `false` | Divider at 0% - only item 2 (`setState('after')`). |
```
