<PageHeader slug="anim-pop" title="Pop" component="motion">
  Pop is the springy overshoot of the <code>df$.anim</code> engine: <code>popIn</code> scales the element in from 0.65 through a 1.07 overshoot that settles at 1, <code>popOut</code> reverses the curve on the way out. It is not directional - there is no edge to start from, only scale - and everything is driven imperatively through <code>df$.anim.popIn</code> and <code>df$.anim.popOut</code> (<code>play</code>, <code>pause</code>, <code>resume</code>, <code>finish</code>, <code>reset</code>, <code>state</code>).
</PageHeader>

The same binding with `{ target: 'viewport' }` ties progress to the page's own scroll instead of an element's - the parallax use for presentations.

## Config axes

`popIn` / `popOut` take the shared `df$.anim` options; the axes that matter for pop are:

- **`duration`** - total time in ms (default `1500`); under `prefers-reduced-motion` the engine collapses it to 1 ms.
- **`easing`** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`); the overshoot is in the keyframes, so even `linear` keeps the pop shape - a springier bezier just exaggerates it.
