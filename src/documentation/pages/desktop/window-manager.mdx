<PageHeader slug="window-manager" title="Window Manager" component="window-manager">
  The model behind a desktop's windows. A <code>.window-manager</code> holds <DocLink href="window.html">Window</DocLink> components and keeps track of them - which are open, in the order they opened, which one is in front, which are minimized or maximized - and publishes that as one <code>window-manager-change</code> event, so a <DocLink href="taskbar.html">Taskbar</DocLink>, a window menu or a switcher renders it. It never moves or styles a window itself: every change goes through the Window's State API. On top it adds the taskbar's click rule (<code>toggle()</code>), "show desktop" (the <code>desktop</code> state) and cascade / tile for its own windows. Two managers on one page each keep their own front window.
</PageHeader>

  <SkillText dense>• <code>toggle(window)</code>: a minimized window comes back (maximized when it was), the window in front minimizes, any other comes to the front.</SkillText>

<script>
  document.addEventListener('DOMContentLoaded', () => {
    const desk = document.querySelector('#wm-demo');
    const wm = df$.shadcn.windowManager;
    const list = document.querySelector('#wm-model');
    const show = (windows) => {
      list.replaceChildren(
        ...windows.map((w) => {
          const li = document.createElement('li');
          const b = document.createElement('button');
          b.className = 'btn';
          b.dataset.variant = w.active ? 'default' : 'ghost';
          b.dataset.size = 'sm';
          b.type = 'button';
          b.textContent = `${w.title} - ${w.state}${w.active ? ', in front' : ''}`;
          b.addEventListener('click', () => wm.toggle(w.id));
          li.append(b);
          return li;
        }),
      );
    };
    desk.addEventListener('window-manager-change', (e) => show(e.detail.windows));
    show(wm.windows(desk));
    document.querySelector('#wm-open').addEventListener('click', () => df$.shadcn.win.open('wm-calc'));
    document.querySelector('#wm-show').addEventListener('click', () => wm.showDesktop(desk));
    document.querySelector('#wm-cascade').addEventListener('click', () => wm.cascade(desk));
    document.querySelector('#wm-tile').addEventListener('click', () => wm.tile(desk));
    document.querySelector('#wm-notes p').addEventListener('input', (e) => {
      document.querySelector('#wm-notes .window-title').textContent = e.target.textContent.slice(0, 24) || 'Notes';
    });
  });
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on each <code>.window-manager</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the windows as the reader left them; leaving <code>desktop</code> brings back the windows it minimized</li>
    <li><code>desktop</code> - show the desktop: every open window minimized (<code>data-desktop-shown</code>); a window that shows again ends it</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/window-manager-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/window-manager.schema.json"><code>window-manager.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `desktop` | `boolean` | `true`, `false` | `false` | Every window minimized by show desktop (data-state-name). |
```
