<PageHeader slug="anim-blur" title="Blur" component="motion">
  Blur is the focus-pull animation of the <code>df$.anim</code> engine: the element sharpens out of a <code>blur(12px)</code> haze (<code>blurIn</code>) or dissolves back into it (<code>blurOut</code>), fading in opacity along the way. It is not directional - the blur radiates from the element itself - and both variants are driven entirely by <code>df$.anim.blurIn</code> / <code>df$.anim.blurOut</code>.
</PageHeader>

<script type="module">
  // df$ (all.js) boots after example scripts in the sandbox - reference it

    duration: Number(document.getElementById('anim-blur-duration').value) || undefined,

```html example label="Scroll binding" schema="none" hint="opts.scroll ties the animation's progress to a scroll position instead of time - scroll the stage and the card sharpens. Built on the platform's ScrollTimeline with a scrubbing fallback."
<div id="anim-blur-scroller" style="height: 220px; overflow-y: auto; border: 1px solid var(--border); border-radius: var(--radius-lg)">
  <div style="height: 600px; display: grid; place-items: center;">
    <div id="anim-blur-scroll-target" style="display: grid; place-items: center; width: 160px; height: 100px; border: 1px solid var(--border); border-radius: var(--radius-lg); background: var(--card); color: var(--card-foreground); font-size: 0.875rem; font-weight: 500;">Scroll-driven</div>
  </div>

<script type="module">
  // df$ boots after example scripts in the sandbox - bind on load,
  // never at parse time.
  const bindScrollBlur = () => {
    const scroller = document.getElementById('anim-blur-scroller');
    const target = document.getElementById('anim-blur-scroll-target');
    df$.anim.blurIn.play(target, { scroll: { target: scroller, axis: 'y' } });
  };
  if (document.readyState === 'complete') bindScrollBlur();
  else window.addEventListener('load', bindScrollBlur);
</script>
```

Passing `{ target: 'viewport' }` instead of an element binds progress to the page's own scroll - the parallax use case for presentations, where a slide element sharpens as it scrolls into view.

## Config axes

- **duration** - total runtime in ms (default `1500`); a number input in the demo above.
- **easing** - any CSS easing string (default `cubic-bezier(0.16, 1, 0.3, 1)`); the demo offers a few presets.

Both channels also accept the shared `delay` option and honor `prefers-reduced-motion` automatically; `df$.anim.<channel>.state(el)` reports `idle` / `running` / `paused` / `finished`.
