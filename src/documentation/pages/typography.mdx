  <SkillField label="Accessibility">
<SkillText dense>• Use heading levels in order (<code>h1</code> → <code>h2</code> → <code>h3</code>). Do not skip levels.</SkillText>
  <SkillText dense>• Headings create the document outline used by screen readers for navigation.</SkillText>
  <SkillText dense>• <code>&lt;blockquote&gt;</code> is announced as a quote by assistive technology - no extra ARIA needed.</SkillText>
  <SkillText dense>• <code>&lt;code&gt;</code> is announced as code - no extra ARIA needed.</SkillText>
  <SkillText dense>• <code>prefers-contrast: more</code> - removes tight letter-spacing, adds outline to inline code, thickens blockquote border, promotes muted text to foreground color.</SkillText>
  <p class="text-muted-foreground m-0">• <code>forced-colors: active</code> - blockquote border and inline code adapt to system colors.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• These are utility classes for prose content - not a component with variants/sizes.</SkillText>
  <SkillText dense>• The <code>.h1</code>–<code>.h4</code> classes allow applying heading styles to non-heading elements when semantic headings aren't appropriate.</SkillText>
  <SkillText dense>• Typography classes compose freely with other components (Card content, Dialog body, Alert description).</SkillText>
  <SkillText dense>• <code>text-wrap: balance</code> is used on all headings (h1–h4) for better visual line distribution.</SkillText>
  <SkillText dense>• <code>text-wrap: pretty</code> is used on paragraphs and lead text for orphan prevention.</SkillText>
  <SkillText dense>• <code>hanging-punctuation</code> is used on blockquotes for optical quote alignment.</SkillText>
  <SkillText dense>• Blockquote uses logical properties (<code>border-inline-start</code>, <code>padding-inline-start</code>) for automatic RTL support.</SkillText>
  <SkillText dense>• For lists, use the List component (<code>list.css</code>) - typography does not ship its own list styles.</SkillText>
  <p class="text-muted-foreground m-0">• For prose tables, use the Table component (<code>table.css</code>) - typography does not ship its own table styles.</p>
  </SkillField>
</SkillPanel>

<H2 id="typesetting">Typesetting (Satz)</H2>

<p class="text-sm text-muted-foreground mb-3">Continuous text set like a book or a journal page: one <code>.typeset</code> block, plain paragraphs inside, and each classic rule of the compositor's craft an opt-in attribute. The examples show every rule on its own first, then captions, separators, leading and figure groups, and only then pages that combine them. The <code>--typeset-*</code> properties tune each block; they are this component's knobs, not theme tokens, so a theme stays the tweakcn token set.</p>

```html example label="Columns" hint="data-columns='2' sets two columns, data-rule a hairline between them. No column is narrower than --typeset-column-width (18rem): switch the preview to Phone and the block sets one column - no media query." previewStyle="justify-content:flex-start;text-align:left;"
<div class="typeset" lang="en" data-columns="2" data-rule style="font-family: var(--font-serif);">
  <p>A printed column is a measure of even grey. Two columns halve the measure and keep a line within the sixty to seventy characters a reader takes in at a glance.</p>
  <p>The column property takes a count and a minimum width; when the page grows too narrow for two columns of that width, the block sets one, and a phone reads a single column.</p>
</div>
```

```html example label="Blocksatz (justified)" hint="data-align='justify' justifies the lines and hyphenates long words by the rules of the block's language (lang='en'); the last line of each paragraph stays flush to the start." previewStyle="justify-content:flex-start;text-align:left;"
<div class="typeset" lang="en" data-align="justify" style="font-family: var(--font-serif); max-width: 28rem;">
  <p>The compositor justified each line by adding space between words and, where the space grew too wide, broke a word at a syllable. Typographically, interdisciplinary and internationalization break where the language allows them to.</p>
</div>
