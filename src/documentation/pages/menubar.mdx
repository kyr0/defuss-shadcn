<PageHeader slug="menubar" title="Menubar" component="menubar">
  A persistent, desktop-style menu bar - File, Edit, View - where every trigger opens a <DocLink href="dropdown.html">dropdown menu</DocLink> with all it can do: submenus (here three levels deep), checkbox and radio items that switch on click, shortcuts, icons and disabled items. One tab stop for the bar, ← / → between the menus, and once a menu is open, hovering the others switches between them. After shadcn/ui's Menubar.
</PageHeader>

<SkillPanel component="menubar">
  <SkillField label="Native basis">
<SkillText>A <code>role="menubar"</code> of trigger buttons, each opening a <code>popover</code> menu anchored to it (CSS anchor positioning); submenus are popovers nested in their menu, so the browser keeps the tree open and dismisses it together.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>

<script>
  const mbc = document.querySelector('.menubar');
  const showMbc = () => {
    const on = [...mbc.querySelectorAll('[role="menuitemcheckbox"][aria-checked="true"]')].map((i) => i.firstChild.textContent.trim());
    const picked = [...mbc.querySelectorAll('[role="menuitemradio"][aria-checked="true"]')].map((i) => i.textContent.trim());
    document.getElementById('mbc-state').textContent = 'On: ' + (on.join(', ') || 'nothing') + ' · Zoom ' + picked[0] + ' · Align ' + picked[1];
  };
  mbc.addEventListener('dropdown:select', showMbc);
  showMbc();
</script>
