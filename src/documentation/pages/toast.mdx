  <SkillText>• <code>data-toast-action</code> identifies an interactive action element</SkillText>

  <SkillField label="Notes">
<SkillText dense>• The toast container should be a direct child of <code>&lt;body&gt;</code></SkillText>
  <SkillText dense>• Toasts use <code>popover="manual"</code> so they don't auto-dismiss on outside click</SkillText>
  <SkillText dense>• The stacking order is newest on top (CSS <code>flex-direction: column-reverse</code> for bottom positions)</SkillText>
  <SkillText dense>• Maximum visible toasts defaults to 3 — older toasts are dismissed</SkillText>
  <SkillText dense>• Swipe-to-dismiss can be added with touch event handling but is not required for MVP</SkillText>
  <SkillText dense>• For forms, show success/error toasts after submission rather than inline messages</SkillText>
  <p class="text-muted-foreground m-0">• The <code>toast()</code> API is imperative — call it from any event handler</p>
  </SkillField>

```html example label="Default" hint="Basic toast with title and description via df$.shadcn.toast.show()." height="20"
<button class="btn" data-variant="default" onclick="df$.shadcn.toast.show({ title: 'Event created', description: 'Monday, January 3rd at 6:00pm' })"> Show Toast </button>
```

```html example label="Variants" hint="Semantic variants add a colored border and icon. Use df$.shadcn.toast.success(), df$.shadcn.toast.warning(), df$.shadcn.toast.info(), or df$.shadcn.toast.error()." height="20"
<button class="btn" data-variant="outline" onclick="df$.shadcn.toast.success({ title: 'Success', description: 'Your changes have been saved.' })"> Success </button>
<button class="btn" data-variant="outline" onclick="df$.shadcn.toast.warning({ title: 'Warning', description: 'Your session will expire in 5 minutes.' })"> Warning </button>
<button class="btn" data-variant="outline" onclick="df$.shadcn.toast.info({ title: 'Info', description: 'A new version is available for download.' })"> Info </button>
<button class="btn" data-variant="destructive" onclick="df$.shadcn.toast.error({ title: 'Error', description: 'Something went wrong. Please try again.' })"> Error </button>
```

```html example label="With Description" hint="Pass a description for a secondary line of detail below the title." height="20"
<button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Scheduled', description: 'Your report will be generated at 9:00 AM tomorrow.' })"> Show Toast </button>
```

```html example label="With Action" hint="Add an action object with label and onClick to render an action button inside the toast." height="20"
<button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Changes saved', description: 'Your profile has been updated.', action: { label: 'Undo', onClick: () => df$.shadcn.toast.show('Undone!') } })"> Show Toast </button>
```

```html example label="Size & Density" hint="size scales the width envelope (sm / md / lg, md matches the unsized default), density the padding and content gap (compact / comfortable / spacious) — pass either option to show() and it lands as the matching data-* attribute on the toast." height="20"
<div class="flex flex-wrap gap-2">
  <button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Narrow toast', description: 'Width envelope sm.', size: 'sm' })">Size sm</button>
  <button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Wide toast', description: 'Width envelope lg.', size: 'lg' })">Size lg</button>
  <button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Compact toast', description: 'Tighter padding and gap.', density: 'compact' })">Density compact</button>
  <button class="btn" data-variant="outline" onclick="df$.shadcn.toast.show({ title: 'Spacious toast', description: 'Roomier padding and gap.', density: 'spacious' })">Density spacious</button>
</div>
```
