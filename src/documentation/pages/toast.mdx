<SkillText dense>• The toast container should be a direct child of <code>&lt;body&gt;</code></SkillText>
  <SkillText dense>• Toasts use <code>popover="manual"</code> so they don't auto-dismiss on outside click</SkillText>
  <SkillText dense>• The stacking order is newest on top (CSS <code>flex-direction: column-reverse</code> for bottom positions)</SkillText>
  <SkillText dense>• Maximum visible toasts defaults to 3 - older toasts are dismissed</SkillText>
  <SkillText dense>• Swipe-to-dismiss can be added with touch event handling but is not required for MVP</SkillText>
  <SkillText dense>• For forms, show success/error toasts after submission rather than inline messages</SkillText>
  <p class="text-muted-foreground m-0">• The <code>toast()</code> API is imperative - call it from any event handler</p>

```html example label="Stacked toasts" hint="configure({ stack: 'pile' }): the newest toast stays in front and the older ones wait behind it as the Stacks sheets (shapes.css stack-top - tapered sheets) with a +n badge; hover or focus the pile and it fans out into a list, leave it and it folds back. Send a few - then switch to a list for comparison." height="30"
<div class="flex flex-wrap gap-2">
  <button class="btn" id="pile-send">Send 3 notifications</button>
  <button class="btn" data-variant="outline" id="pile-mode" aria-pressed="true">Mode: pile</button>
</div>
<script>
  // the toast module is a deferred module script - wait until it has run
  addEventListener('DOMContentLoaded', () => {
  const t = df$.shadcn.toast;
  t.configure({ stack: 'pile', position: 'bottom-right' });
  const news = [
    { title: 'Build passed', description: 'main · 2m 14s', variant: 'success' },
    { title: 'New comment', description: 'Sofia replied to your review.' },
    { title: 'Deploy queued', description: 'production · waiting for approval', variant: 'info' },
    { title: 'Invoice paid', description: 'INV-2291 · €1,200.00', variant: 'success' },
  ];
  let n = 0;
  document.getElementById('pile-send').addEventListener('click', () => {
    for (let i = 0; i < 3; i++) setTimeout(() => t.show({ ...news[n++ % news.length], duration: 12000 }), i * 350);
  });
  const mode = document.getElementById('pile-mode');
  mode.addEventListener('click', () => {
    const pile = mode.getAttribute('aria-pressed') !== 'true';
    t.configure({ stack: pile ? 'pile' : 'list' });
    mode.setAttribute('aria-pressed', String(pile));
    mode.textContent = 'Mode: ' + (pile ? 'pile' : 'list');
  });
  });
</script>
```
