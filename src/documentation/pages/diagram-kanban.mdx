<PageHeader slug="diagram-kanban" title="Illustrative · Kanban" component="diagram">
  A state census, not a flow - so no connectors. Columns are groups (<code>data-shape="column"</code>) with a WIP chip (<code>.diagram-group-meta</code>, <code>data-over</code> when breached); cards are nodes with <code>data-status="blocked|waiting|done"</code> - each state is a dash, a bar or a check, not just a color.
</PageHeader>

<H2 id="interactive">Interactive</H2>

<DocText>A click activates a box or an arrow: what it touches stays lit, everything else steps back. The buttons outside the figure drive the same activation - <code>data-diagram-for</code> + <code>data-diagram-action="next|prev|clear"</code> - and the <code>&lt;output data-diagram-for&gt;</code> names what is active. Keyboard: Tab to a box, Enter, arrows, Escape.</DocText>

<H2 id="inspect">Inspect and edit</H2>

<DocText>Select, inspect, edit: a click hands the selection to a <a href="property-grid.html">Property Grid</a> in a closable <a href="panel.html">Panel</a> - <code>df$.shadcn.diagram.properties()</code> reads the box or the arrow as JSON, <code>propertySchema()</code> gives the grid its options, <code>setProperties()</code> writes an edit back and the diagram redraws. The × closes the panel, the Inspector button toggles it.</DocText>

  document.addEventListener('DOMContentLoaded', () => {
    const { diagram, propertyGrid } = df$.shadcn;
    const fig = document.getElementById('dg-kanban-edit');
    const grid = document.getElementById('dg-kanban-edit-grid');
    const title = document.getElementById('dg-kanban-edit-title');
    let ref = null;
    // a selection: its properties (and their options) into the grid
    fig.addEventListener('diagram-activate', (e) => {
      ref = e.detail.ref;
      title.textContent = ref ? 'Inspector · ' + e.detail.label : 'Inspector';
      propertyGrid.configure(grid, { sourceConfig: ref ? diagram.propertySchema(fig, ref) : {} });
      propertyGrid.setSource(grid, ref ? diagram.properties(fig, ref) : {});
    });
    // an edit: back into the diagram, which redraws
    grid.addEventListener('property-grid-change', (e) => {
      if (ref) diagram.setProperties(fig, ref, e.detail.source);
    });
  });
</script>
