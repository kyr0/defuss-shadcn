<PageHeader slug="mockup-code" title="Code" component="mockup-code">
  A terminal window for commands and what they print - install steps, CLI docs, a session transcript. Each line is a <code>&lt;pre&gt;</code>; its prompt (<code>$</code>, <code>&gt;</code>, a line number) is generated by CSS, so selecting or copying the window yields the commands alone. Tones, highlighted lines, window chrome with a title, line numbers, a blinking cursor. CSS only, after daisyUI's mockup-code - the <DocLink href="installation.html">installation</DocLink> and <DocLink href="vibe-coding.html">agent-skill</DocLink> guides use it for every command.
</PageHeader>

```html example label="Line numbers and syntax highlighting" schema="none" hint="data-numbers numbers every line without its own prefix - CSS counters, nothing to keep in sync. The colours come from Shiki (the highlighter these docs use): codeToTokens returns one token list per line, which maps one-to-one onto the window's <pre> lines - plain text until it loads, and the numbers and the highlighted line keep working."
<div class="mockup-code" data-numbers data-title="button.html" id="mc-source">
  <pre><code>&lt;button class="btn" data-variant="outline"&gt;</code></pre>
  <pre><code>  Search</code></pre>
  <pre><code>  &lt;kbd class="kbd" data-size="sm"&gt;⌘K&lt;/kbd&gt;</code></pre>
  <pre data-highlight><code>&lt;/button&gt;</code></pre>
</div>
<script type="module">
  import { codeToTokens } from 'https://esm.sh/shiki@3.0.0';
  const lines = [...document.querySelectorAll('#mc-source > pre > code')];
  const { tokens } = await codeToTokens(lines.map((code) => code.textContent).join('\n'), { lang: 'html', theme: 'github-dark' });
  tokens.forEach((line, i) => lines[i].replaceChildren(...line.map((token) => {
    const span = document.createElement('span');
    span.textContent = token.content;
    span.style.color = token.color;
    return span;
  })));
</script>
```

```html example label="Animated diff" schema="none" hint="data-animate plays the change: removed lines turn red and strike through, then the added lines slide in green, one after another (sibling-index() staggers them; --mockup-code-delay / --mockup-code-stagger tune it). CSS only - the script here only starts it when the window scrolls into view and replays it on click."
<div class="flex flex-col gap-3 items-start">
  <div class="mockup-code w-full" id="diff-demo" data-chrome="mac" data-title="release.md">
    <pre><code>Release 0.9.3</code></pre>
    <pre><code></code></pre>
    <pre data-diff="remove"><code>Search box: planned</code></pre>
    <pre data-diff="remove"><code>Typewriter: planned</code></pre>
    <pre data-diff="add"><code>Search &amp; Filter: a search box with a clear button</code></pre>
    <pre data-diff="add"><code>Typewriter: typed, deleted, cycled</code></pre>
    <pre data-diff="add"><code>Code mockup: git-style diffs</code></pre>
  </div>
  <button class="btn" data-variant="outline" data-size="sm" id="diff-replay">Replay</button>
</div>
<script>
  const win = document.getElementById('diff-demo');
  const play = () => { win.removeAttribute('data-animate'); void win.offsetWidth; win.setAttribute('data-animate', ''); };
  new IntersectionObserver((entries, io) => {
    if (entries.some((e) => e.isIntersecting)) { play(); io.disconnect(); }
  }).observe(win);
  document.getElementById('diff-replay').addEventListener('click', play);
</script>
```
