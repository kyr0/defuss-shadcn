<PageHeader slug="tabs" title="Tabs" component="tabs">
  Organize content into switchable panels. Uses WAI-ARIA Tabs pattern with roving <code>tabindex</code> and arrow key navigation. Available in pill and line variants.
</PageHeader>

<SkillPanel component="tabs">
  <SkillField label="Native basis">
<SkillText><code>role="tablist"</code> + <code>role="tab"</code> + <code>role="tabpanel"</code>. No native HTML element</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://www.w3.org/WAI/ARIA/apg/patterns/tabs/" title="role contract (`tablist`, `tab`, `tabpanel`) and roving tabindex keyboard navigation"><code>WAI-ARIA Tabs pattern</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:has" title="auto-detects vertical orientation for layout switching"><code>:has()</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:focus-visible" title="keyboard-only focus ring"><code>:focus-visible</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion" title="suppresses tab transitions"><code>prefers-reduced-motion</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="maps active tab to system Highlight"><code>forced-colors</code></ApiPill>

  <SkillField label="Notes">
<SkillText dense>• Only the active tab is in the tab order (<code>tabindex="0"</code>) - inactive tabs use <code>tabindex="-1"</code></SkillText>
  <SkillText dense>• Arrow keys cycle through tabs (wrap around) - this is the roving tabindex pattern</SkillText>
  <SkillText dense>• The active panel uses <code>tabindex="0"</code> so it can receive focus from the tab trigger</SkillText>
  <SkillText dense>• Use <code>hidden</code> attribute on inactive panels for accessibility (screen readers skip them)</SkillText>
  <SkillText dense>• Disabled tabs should have <code>disabled</code> attribute and be skipped by keyboard navigation</SkillText>
  <p class="text-muted-foreground m-0">• For lazy-loaded content, panels can be rendered empty and populated on activation</p>
  </SkillField>
</SkillPanel>

  const root = document.getElementById('tabs-pg');
  const list = document.getElementById('tabs-pg-list');
  const apply = () => {
    const side = document.getElementById('tabs-pg-side').value;
    root.dataset.side = side;
    root.dataset.align = document.getElementById('tabs-pg-align').value;
    const variant = document.getElementById('tabs-pg-variant').value;
    if (variant) list.dataset.variant = variant; else delete list.dataset.variant;
    // the tablist's ARIA orientation follows the side
    const vertical = side === 'left' || side === 'right';
    if (vertical) list.setAttribute('aria-orientation', 'vertical');
    else list.removeAttribute('aria-orientation');
    // vertical labels need a taller panel: beside it, the panel sets the height
    root.querySelectorAll('.card').forEach((card) => { card.style.minHeight = vertical ? '17rem' : '8rem'; });
  };
  ['tabs-pg-side', 'tabs-pg-align', 'tabs-pg-variant'].forEach((id) => document.getElementById(id).addEventListener('change', apply));
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - on a tab, enabled and not picked (the authored selection stands; label and icon stay); on the tablist, everything as authored - selection, disabled flags, labels, icons (the init snapshot)</li>
    <li><code>active</code> - on a tab, this tab selected and its panel visible (selection stays exclusive); on the tablist, the tab at <code>config.index</code> (or <code>config.id</code>) selected</li>
    <li><code>disabled</code> - on a tab, not selectable and skipped by the arrow keys (a selected tab hands the selection on); on the tablist, every tab disabled</li>
    <li>config <code>{'{ label, icon }'}</code> on a tab renames / re-icons it (a lucide name mounts <code>&lt;i data-lucide&gt;</code>, anything else - an emoji - a <code>.tab-icon</code> span, <code>''</code> removes it); re-entering the current state with a config applies just the config</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/tabs-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/tabs.schema.json"><code>tabs.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `selected` | `number` | — | `0` | Index of the selected tab - the tablist's own api: `setState('active', { index })`, read back from `getState().config.index`. |
| `active` | `boolean` | `true`, `false` | `false` | The demo’s second tab activated (its panel shown, others `hidden`) - the State API binds per `.tab-trigger`. |
| `disabled` | `boolean` | `true`, `false` | `false` | The second tab disabled - `setState('disabled')`; unchecking enables it with `setState('default')`. |
| `label` | `string` | — | — | The second tab's text - `setState(current, { label })`, selection untouched. |
| `icon` | `string` | — | — | The second tab's icon: a lucide name, an emoji, or empty for none - `setState(current, { icon })`. |
```
