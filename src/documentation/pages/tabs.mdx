<PageHeader slug="tabs" title="Tabs" component="tabs">
  Organize content into switchable panels. Uses WAI-ARIA Tabs pattern with roving <code>tabindex</code> and arrow key navigation. Available in pill and line variants.
</PageHeader>

  <SkillField label="Notes">
<SkillText dense>• Only the active tab is in the tab order (<code>tabindex="0"</code>) — inactive tabs use <code>tabindex="-1"</code></SkillText>
  <SkillText dense>• Arrow keys cycle through tabs (wrap around) — this is the roving tabindex pattern</SkillText>
  <SkillText dense>• The active panel uses <code>tabindex="0"</code> so it can receive focus from the tab trigger</SkillText>
  <SkillText dense>• Use <code>hidden</code> attribute on inactive panels for accessibility (screen readers skip them)</SkillText>
  <SkillText dense>• Disabled tabs should have <code>disabled</code> attribute and be skipped by keyboard navigation</SkillText>
  <p class="text-muted-foreground m-0">• For lazy-loaded content, panels can be rendered empty and populated on activation</p>
  </SkillField>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — this tab's authored selection (setState restores the snapshot taken at init)</li>
    <li><code>active</code> — this tab is selected and its panel visible (per-tab API; selection stays exclusive)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/tabs-\{state\}.png</code>.</p>

Machine contract — verified against <a href="../schemas/tabs.schema.json"><code>tabs.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `active` | `boolean` | `true`, `false` | `false` | The demo’s second tab activated (its panel shown, others `hidden`) — the State API binds per `.tab-trigger`. |
```
