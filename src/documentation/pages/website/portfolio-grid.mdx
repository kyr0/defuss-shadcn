<PageHeader slug="portfolio-grid" title="Portfolio Grid" component="portfolio-grid">
  The work, arranged with character - a bento mosaic, masonry columns, scattered polaroids, a film strip that snaps, or an editorial index whose pictures appear on hover and focus. Part of the <DocLink href="website-resume-portfolio.html">Resume &amp; Portfolio</DocLink> blocks.
</PageHeader>

<SkillPanel component="portfolio-grid">
  <SkillField label="Native basis">
<SkillText>A <code>&lt;ul&gt;</code> of projects; each item one link around the picture and a caption (title and meta), so the whole tile is one focusable target named by its caption.</SkillText>
  </SkillField>

  <SkillField label="Built from">
<SkillText>Plain HTML; character from the shape utilities (<code>theme/utils/shapes.css</code>), <DocLink href="motion.html">Motion</DocLink> entrances and <DocLink href="parallax.html">Parallax</DocLink> reveals.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/grid-auto-flow" title="the mosaic fills its gaps"><code>grid-auto-flow: dense</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/columns" title="masonry columns"><code>columns</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/scroll-snap-type" title="the strip stops on each project"><code>scroll-snap</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries" title="narrow, the spans fold"><code>Container queries</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:focus-visible" title="the index shows its picture for the keyboard too"><code>:focus-visible</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_counter_styles/Using_CSS_counters" title="the index numbers its rows"><code>counter()</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
