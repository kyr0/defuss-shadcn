<p>Slide Right is the WAAPI twin of the motion component's <code>right</code> entrance: the target starts at the west edge and glides right into place. It ships as a pair of channels - <code>slideIn</code> (starts at the named edge) and <code>slideOut</code> (exits toward it) - and both accept the four orientation variants <code>north</code>, <code>south</code>, <code>east</code> and <code>west</code> (default <code>west</code>, matching motion.css's <code>right</code>). Everything below is driven imperatively by <code>df$.anim.slideIn</code> and <code>df$.anim.slideOut</code> - <code>play</code>, <code>pause</code>, <code>resume</code>, <code>finish</code> and <code>reset</code>.</p>

<script type="module">
  // all.js (df$) boots after example scripts in the sandbox - reference df$
  // only inside event handlers, never at parse time. lastChannel is a NAME so
  // the lifecycle buttons act on whichever variant ran most recently.
  const target = document.getElementById('anim-right-target');
  const dirButtons = document.querySelectorAll('#anim-right-dirs [data-direction]');
  const durationInput = document.getElementById('anim-right-duration');
  const easingSelect = document.getElementById('anim-right-easing');
  let currentDirection = 'west'; // default - matches motion.css 'right'
  let lastChannel = 'slideIn';

  const config = () => ({
    direction: currentDirection,
    duration: Number(durationInput.value) || 1500,
    easing: easingSelect.value,
  });

  document.getElementById('anim-right-in').addEventListener('click', () => {
    lastChannel = 'slideIn';
    df$.anim.slideIn.play(target, config());
  });
  document.getElementById('anim-right-out').addEventListener('click', () => {
    lastChannel = 'slideOut';
    df$.anim.slideOut.play(target, config());
  });
  dirButtons.forEach((btn) =>
    btn.addEventListener('click', () => {
      currentDirection = btn.dataset.direction;
      dirButtons.forEach((b) => b.setAttribute('aria-pressed', String(b === btn)));
    }),
  );
  for (const method of ['pause', 'resume', 'finish', 'reset']) {
    document
      .getElementById(`anim-right-${method}`)
      .addEventListener('click', () => df$.anim[lastChannel][method](target));
  }
</script>
```

<p class="text-sm text-muted-foreground m-0 mb-3">Passing <code>scroll: {`{ target: 'viewport' }`}</code> binds progress to the page scroll instead of an element's own scroll offset - the parallax use for presentations.</p>

## Config

<ul>
  <li><code>direction</code> - <code>'north' | 'south' | 'east' | 'west'</code>, default <code>'west'</code>. slideIn STARTS at the named edge; slideOut EXITS toward it.</li>
  <li><code>distance</code> - slide travel as any CSS length, default <code>'24px'</code> (e.g. <code>'4rem'</code>, <code>'120px'</code>).</li>
  <li><code>duration</code> - total duration in ms, default <code>1500</code> (flattens to 1ms under <code>prefers-reduced-motion: reduce</code>).</li>
  <li><code>easing</code> - any CSS easing, default <code>cubic-bezier(0.16, 1, 0.3, 1)</code>.</li>
</ul>
