<PageHeader slug="comment-header" title="Comment Header" component="comment-header">
  Introduces a discussion with its comment count and sorting options - a native Select, or sort links in a segmented row. Part of the <DocLink href="website-comments.html">Comments</DocLink> blocks.
</PageHeader>

<SkillPanel component="comment-header">
  <SkillField label="Native basis">
<SkillText>A <code>&lt;header&gt;</code>: the title with the comment count (a Badge), the sort - a native Select inside its <code>&lt;label&gt;</code>, or sort links with <code>aria-current</code> - and optional actions.</SkillText>
  </SkillField>

  <SkillField label="Built from">
<SkillText><DocLink href="badge.html">Badge</DocLink>, <DocLink href="select.html">Select</DocLink>, <DocLink href="button.html">Button</DocLink>, <DocLink href="toggle-group.html">Toggle Group</DocLink>, <DocLink href="avatar.html">Avatar</DocLink>, <DocLink href="alert.html">Alert</DocLink>.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/select" title="the sort order"><code>&lt;select&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/label" title="wraps &quot;Sort by&quot; + the select"><code>&lt;label&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current" title="the current sort link"><code>aria-current</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.mk-comment-header</code>
    <code>.mk-comment-header-title</code>
    <code>.mk-comment-header-actions</code>
    <code>.mk-comment-header-sort</code>
    <code>.mk-comment-header-tabs</code>
    <code>.mk-comment-header-people</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText><code>data-variant="plain"</code>; <code>.mk-comment-header-tabs</code> for sort links; <code>.mk-comment-header-people</code> (an Avatar group + a sentence).</SkillText>
  </SkillField>
</SkillPanel>

```html example label="Default" hint="Title with the count (a Badge), the sort - a native Select in its label - and a follow action, over a rule." previewStyle="align-items:stretch;"
<header class="mk-comment-header">
  <h2 class="mk-comment-header-title">Comments <span class="badge" data-variant="secondary">128</span></h2>
  <div class="mk-comment-header-actions">
    <label class="mk-comment-header-sort">Sort by
      <select class="select" data-size="sm" name="sort">
        <option>Top</option>
        <option>Newest</option>
        <option>Oldest</option>
      </select>
    </label>
    <button type="button" class="btn" data-variant="outline" data-size="sm"><i data-lucide="bell"></i> Follow</button>
  </div>
</header>
```

```html example label="Sort links" hint="The sort as links (aria-current marks the order) in a segmented row - no script at all; data-variant='plain' drops the rule." previewStyle="align-items:stretch;"
<header class="mk-comment-header" data-variant="plain">
  <h2 class="mk-comment-header-title">Discussion <span class="badge" data-variant="secondary">42</span></h2>
  <nav class="mk-comment-header-tabs" aria-label="Sort comments">
    <a href="#" aria-current="page">Top</a>
    <a href="#">Newest</a>
    <a href="#">Oldest</a>
  </nav>
</header>
```

```html example label="Toggle sort and participants" hint="The sort as a Toggle Group (single), and who is talking - an Avatar group with a sentence on its own row (.mk-comment-header-people)." previewStyle="align-items:stretch;"
<header class="mk-comment-header">
  <h2 class="mk-comment-header-title">Discussion <span class="badge" data-variant="secondary">86</span></h2>
  <div class="toggle-group" role="group" aria-label="Sort comments" data-type="single" data-size="sm">
    <button class="toggle" aria-pressed="true" value="top"><i data-lucide="flame"></i> Top</button>
    <button class="toggle" aria-pressed="false" value="new"><i data-lucide="clock"></i> New</button>
    <button class="toggle" aria-pressed="false" value="old">Oldest</button>
  </div>
  <div class="mk-comment-header-people">
    <div class="avatar-group">
      <span class="avatar" data-size="sm"><img class="avatar-image" src="images/mk-portrait.png" alt=""></span>
      <span class="avatar" data-size="sm"><img class="avatar-image" src="images/mk-portrait2.png" alt=""></span>
      <span class="avatar" data-size="sm"><img class="avatar-image" src="images/mk-portrait.png" alt=""></span>
      <span class="avatar-group-count">+12</span>
    </div>
    <span><strong>Hannah</strong>, <strong>Sophie</strong> and 12 others are talking</span>
  </div>
</header>
```
