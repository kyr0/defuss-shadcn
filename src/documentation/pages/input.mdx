<PageHeader slug="input" title="Input" component="input">
  A styled text input built on the native <code>&lt;input&gt;</code> element. Includes label, description, error, sizes, file input, textarea auto-grow, and focus ring. Zero JavaScript.
</PageHeader>

<SkillPanel component="input">

  <SkillField label="Notes">
<SkillText dense>• Always pair inputs with <code>&lt;label&gt;</code> using matching <code>for</code>/<code>id</code></SkillText>
  <SkillText dense>• Use <code>type="file"</code> for file inputs — styled via the <code>.input</code> class</SkillText>
  <SkillText dense>• Textarea auto-grows via <code>field-sizing: content</code> — zero JavaScript</SkillText>
  <SkillText dense>• Use <code>readonly</code> for non-editable values the user can still select/copy</SkillText>
  <SkillText dense>• For hidden labels, use <code>sr-only</code> class on the label element</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• Use semantic <code>type</code> values (<code>email</code>, <code>tel</code>, <code>url</code>, <code>search</code>, <code>password</code>, <code>number</code>) for mobile keyboards and validation</p>
  </SkillField>
</SkillPanel>
