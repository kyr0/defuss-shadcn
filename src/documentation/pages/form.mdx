<PageHeader slug="form" title="Form" component="form">
  Consistent field layout for forms. Built on native <code>&lt;form&gt;</code> with <code>.form-field</code> spacing, <code>.form-field-inline</code> for checkbox/switch rows, <code>.form-field-row</code> for notification-style items, and <code>.form-fieldset</code> for grouped fields.
</PageHeader>

<SkillPanel component="form">
  <SkillField label="Native basis">
<SkillText><code>&lt;form&gt;</code> element with consistent field layout using Label, Input, and description/error helpers. Composes with all form control components.</SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• <code>.form-field</code> provides consistent vertical spacing between fields.</SkillText>
  <SkillText dense>• <code>.form-field-inline</code> aligns checkbox/switch/radio horizontally with their label.</SkillText>
  <SkillText dense>• <code>.form-field-row</code> creates a card-like row for notification-style switch items.</SkillText>
  <SkillText dense>• <code>.form-fieldset</code> styles native <code>&lt;fieldset&gt;</code> with legend and description.</SkillText>
  <SkillText dense>• No JavaScript needed for basic forms — use native Constraint Validation.</SkillText>
  <p class="text-muted-foreground m-0">• Compose with Label, Input, Textarea, Select, Checkbox, Radio, Switch, Slider, etc.</p>
  </SkillField>
</SkillPanel>

  <div class="form-field">

  </div>
  <div class="form-field">
