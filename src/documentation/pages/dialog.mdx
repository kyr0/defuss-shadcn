  <SkillField label="Wiring conventions">
<SkillText dense>• <code>data-dialog-trigger="\[id\]"</code> on any element → opens that dialog</SkillText>
  <SkillText dense>• <code>data-dialog-close</code> on any element inside → closes the dialog</SkillText>
  <SkillText dense>• Click on backdrop → closes (click lands on <code>&lt;dialog&gt;</code> itself)</SkillText>
  <SkillText>• Place <code>&lt;dialog&gt;</code> elements as direct children of <code>&lt;body&gt;</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Animation uses CSS-only enter via <code>@starting-style</code> and exit via <code>transition</code> + <code>allow-discrete</code>.</SkillText>
  <SkillText dense>• While the dialog is modal, <code>html:has(dialog.dialog:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> — the page behind cannot scroll and its position is preserved for when the dialog closes (no JS scroll-lock).</SkillText>
  <SkillText dense>• The selector is <code>dialog.dialog</code> (element + class) to avoid styling native <code>&lt;dialog&gt;</code> elements used elsewhere.</SkillText>
  <p class="text-muted-foreground m-0">• For forms inside dialogs, use the <code>dialog-body</code> wrapper for the form content.</p>
  </SkillField>
</SkillPanel>

```html example label="Form Dialog" hint="Dialog with form inputs. Click 'Edit Profile' to open."
<button class="btn" data-variant="default"
        data-dialog-trigger="edit-dialog"
        aria-haspopup="dialog">
  Edit Profile
</button>

<dialog id="edit-dialog" class="dialog"
        role="dialog" aria-modal="true"
        aria-labelledby="edit-title">
  <div class="dialog-content">
    <div class="dialog-header">
      <h2 class="dialog-title" id="edit-title">Edit Profile</h2>
      <p class="dialog-description">Make changes to your profile here.</p>
    </div>
    <div class="dialog-body">
      <div style="display:flex;flex-direction:column;gap:1rem;">
        <div>
          <label class="label" for="name">Name</label>
          <input class="input" id="name" type="text" value="Cody Lindley">
        </div>
        <div>
          <label class="label" for="username">Username</label>
          <input class="input" id="username" type="text" value="@kyr0">
        </div>
      </div>
    </div>
    <div class="dialog-footer">
      <button class="btn" data-variant="outline" data-dialog-close>Cancel</button>
      <button class="btn" data-variant="default" data-dialog-close>Save changes</button>
    </div>
  </div>
</dialog>
```

    </div>
    <div class="dialog-footer">

              data-dialog-close>Cancel</button>

              data-dialog-close>Delete account</button>
    </div>
  </div>
</dialog>
```
