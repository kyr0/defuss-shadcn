  <SkillField label="Wiring conventions">
<SkillText dense>• <code>data-dialog-trigger="\[id\]"</code> on any element → opens that dialog</SkillText>
  <SkillText dense>• <code>data-dialog-close</code> on any element inside → closes the dialog</SkillText>
  <SkillText dense>• Click on backdrop → closes (click lands on <code>&lt;dialog&gt;</code> itself)</SkillText>
  <SkillText>• Place <code>&lt;dialog&gt;</code> elements as direct children of <code>&lt;body&gt;</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Animation uses CSS-only enter via <code>@starting-style</code> and exit via <code>transition</code> + <code>allow-discrete</code>.</SkillText>
  <SkillText dense>• While the dialog is modal, <code>html:has(dialog.dialog:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> — the page behind cannot scroll and its position is preserved for when the dialog closes (no JS scroll-lock).</SkillText>
  <SkillText dense>• The selector is <code>dialog.dialog</code> (element + class) to avoid styling native <code>&lt;dialog&gt;</code> elements used elsewhere.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• For forms inside dialogs, use the <code>dialog-body</code> wrapper for the form content.</p>
  </SkillField>
