<PageHeader slug="toggle-group" title="Toggle Group" component="toggle-group">
  A set of two-state buttons that can be toggled on or off. Supports single (radio-like) and multiple (checkbox-like) selection modes with roving tabindex keyboard navigation.
</PageHeader>

  <SkillField label="Notes">
<SkillText dense>• Uses <strong>roving tabindex</strong>: only one item has <code>tabindex="0"</code>; others have <code>tabindex="-1"</code>.</SkillText>
  <SkillText dense>• <code>data-type="single"</code> enforces one-at-a-time selection (radio-like). Pressing the active item deselects it.</SkillText>
  <SkillText dense>• <code>data-type="multiple"</code> allows any combination of pressed states (checkbox-like).</SkillText>
  <SkillText dense>• CSS uses logical properties for RTL support.</SkillText>
  <p class="text-muted-foreground m-0">• Connected mode collapses adjacent radii; outline variant collapses double borders via negative margin.</p>
  </SkillField>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — enabled (items clickable and focusable)</li>
    <li><code>disabled</code> — sets the documented <code>data-disabled</code> attribute (CSS dims items, <code>pointer-events: none</code>)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/toggle-group-\{state\}.png</code>.</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `disabled` | `boolean` | `true`, `false` | `false` | Whole group disabled (`data-disabled` on `.toggle-group` — all toggles inert). |
```
