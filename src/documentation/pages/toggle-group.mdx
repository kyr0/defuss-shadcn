<PageHeader slug="toggle-group" title="Toggle Group" component="toggle-group">
  A set of two-state buttons that can be toggled on or off. Supports single (radio-like) and multiple (checkbox-like) selection modes with roving tabindex keyboard navigation.
</PageHeader>

<SkillPanel component="toggle-group">

<SkillText><code>role="group"</code> container with <code>&lt;button class="toggle"&gt;</code> items using <code>aria-pressed</code> for state. Supports single and multiple selection with roving tabindex.</SkillText>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-type</code> — <code>single</code> (default) or <code>multiple</code></SkillText>
  <SkillText dense>• <code>data-orientation</code> — <code>vertical</code> for vertical layout</SkillText>
  <SkillText dense>• <code>data-spacing</code> — adds gap, restores individual radii</SkillText>
  <SkillText>• <code>data-disabled</code> — disables all items in the group</SkillText>
  </SkillField>

    <Variant name="Space/Enter" description="Toggle the focused item" />
  </SkillGrid>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Uses <strong>roving tabindex</strong>: only one item has <code>tabindex="0"</code>; others have <code>tabindex="-1"</code>.</SkillText>
  <SkillText dense>• <code>data-type="single"</code> enforces one-at-a-time selection (radio-like). Pressing the active item deselects it.</SkillText>
  <SkillText dense>• <code>data-type="multiple"</code> allows any combination of pressed states (checkbox-like).</SkillText>
  <SkillText dense>• CSS uses logical properties for RTL support.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• Connected mode collapses adjacent radii; outline variant collapses double borders via negative margin.</p>
  </SkillField>
</SkillPanel>
