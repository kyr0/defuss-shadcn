<PageHeader slug="anim-fade" title="Fade" component="motion">
  Fade is the quietest animation in the <code>df$.anim</code> engine: a pure opacity cross-fade from <code>0</code> to the element's authored opacity (never a hardcoded <code>1</code>). It ships as the paired variants <code>fadeIn</code> (appear) and <code>fadeOut</code> (disappear) - it is not directional, so there is no <code>direction</code> axis. Everything on this page is driven imperatively by <code>df$.anim.fadeIn</code> and <code>df$.anim.fadeOut</code>.
</PageHeader>

<script type="module">
  // all.js (df$) boots after example scripts in the sandbox - reference df$
  // only inside event handlers, never at parse time.
  const target = document.getElementById('anim-fade-target');
  const status = document.getElementById('anim-fade-state');
  const duration = document.getElementById('anim-fade-duration');
  const easing = document.getElementById('anim-fade-easing');
  let channel = 'fadeIn'; // the channel the lifecycle controls act on
  const opts = () => ({ duration: Number(duration.value) || 1500, easing: easing.value });
  const report = () => { status.textContent = df$.anim[channel].state(target); };

  document.getElementById('anim-fade-in').addEventListener('click', () => {
    channel = 'fadeIn';
    df$.anim.fadeIn.play(target, opts());
    report();
  });
  document.getElementById('anim-fade-out').addEventListener('click', () => {
    channel = 'fadeOut';
    df$.anim.fadeOut.play(target, opts());
    report();
  });
  document.getElementById('anim-fade-pause').addEventListener('click', () => { df$.anim[channel].pause(target); report(); });
  document.getElementById('anim-fade-resume').addEventListener('click', () => { df$.anim[channel].resume(target); report(); });
  document.getElementById('anim-fade-finish').addEventListener('click', () => { df$.anim[channel].finish(target); report(); });
  document.getElementById('anim-fade-reset').addEventListener('click', () => { df$.anim[channel].reset(target); report(); });
</script>
```

  // currentTime - run it on load, after all.js has installed df$.
  window.addEventListener('load', () => {

Pass `{ target: 'viewport' }` (or omit `target` - the viewport is the default) to bind the fade to page scroll instead of an element's own offset - the parallax use for presentations.

## Config axes

- **`duration`** - total duration in ms (default `1500`; flattened to `1` under `prefers-reduced-motion`).
- **`easing`** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
