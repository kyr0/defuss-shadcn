  <SkillField label="Accessibility">
<SkillText dense>• <code>role="switch"</code> tells screen readers this is an on/off toggle, not a checkbox.</SkillText>
  <SkillText dense>• <code>aria-checked</code> is automatically set by the browser for <code>type="checkbox"</code>.</SkillText>
  <SkillText dense>• <code>:focus-visible</code> provides keyboard-only focus ring.</SkillText>
  <SkillText dense>• <code>prefers-reduced-motion</code> disables all transitions.</SkillText>
  <p class="text-muted-foreground m-0">• <code>forced-colors</code> provides Windows High Contrast Mode support.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Pure CSS — no JavaScript needed.</SkillText>
  <SkillText dense>• The thumb slides via <code>:checked</code> and <code>translateX()</code>.</SkillText>
  <SkillText dense>• Uses <code>appearance: none</code> with <code>::after</code> for the thumb.</SkillText>
  <SkillText dense>• Wrap in <code>.switch-item</code> for auto disabled label styling via <code>:has()</code>.</SkillText>
  <p class="text-muted-foreground m-0">• <code>aria-invalid="true"</code> shows the track in the destructive color.</p>
  </SkillField>
</SkillPanel>

```html example label="Default" hint="Toggle switch with label."
<div class="switch-item">
  <input class="switch" type="checkbox" role="switch" id="airplane">
  <label for="airplane">Airplane Mode</label>
</div>
```

```html example label="With Description" hint="Switch with label and description text using .switch-item-block."
<div class="switch-item-block">
  <label for="share">Share across devices</label>
  <input class="switch" type="checkbox" role="switch" id="share" checked>
  <span class="switch-description">Focus is shared across devices.</span>
</div>
```

```html example label="Sizes" hint="The full five-step scale via data-size — the default equals md."
<input class="switch" data-size="xs" type="checkbox" role="switch">
<input class="switch" data-size="sm" type="checkbox" role="switch">
<input class="switch" data-size="md" type="checkbox" role="switch">
<input class="switch" data-size="lg" type="checkbox" role="switch">
<input class="switch" data-size="xl" type="checkbox" role="switch">
```

```html example label="Checked by default"
<div class="switch-item">
  <input class="switch" type="checkbox" role="switch" checked>
  <label>Notifications</label>
</div>
```

```html example label="Disabled" hint="Disabled state — .switch-item auto-dims the label via :has()."
<div class="switch-item">
  <input class="switch" type="checkbox" role="switch" disabled>
  <label>Disabled</label>
</div>
```

```html example label="Invalid" hint="Validation error state with aria-invalid='true'."
<div class="switch-item-block">
  <label for="terms">Accept terms and conditions</label>
  <input class="switch" type="checkbox" role="switch" id="terms" aria-invalid="true">
  <span class="switch-description" style="color:var(--destructive);">You must accept the terms.</span>
</div>
```
