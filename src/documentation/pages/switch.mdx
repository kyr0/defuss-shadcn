<PageHeader slug="switch" title="Switch" component="switch">
  A toggle control for on/off states. Built on native <code>&lt;input type="checkbox" role="switch"&gt;</code> with CSS-only thumb animation.
</PageHeader>

  <SkillField label="Accessibility">
<SkillText dense>• <code>role="switch"</code> tells screen readers this is an on/off toggle, not a checkbox.</SkillText>
  <SkillText dense>• <code>aria-checked</code> is automatically set by the browser for <code>type="checkbox"</code>.</SkillText>
  <SkillText dense>• <code>:focus-visible</code> provides keyboard-only focus ring.</SkillText>
  <SkillText dense>• <code>prefers-reduced-motion</code> disables all transitions.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>forced-colors</code> provides Windows High Contrast Mode support.</p>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Pure CSS — no JavaScript needed.</SkillText>
  <SkillText dense>• The thumb slides via <code>:checked</code> and <code>translateX()</code>.</SkillText>
  <SkillText dense>• Uses <code>appearance: none</code> with <code>::after</code> for the thumb.</SkillText>
  <SkillText dense>• Wrap in <code>.switch-item</code> for auto disabled label styling via <code>:has()</code>.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>aria-invalid="true"</code> shows the track in the destructive color.</p>
  </SkillField>
</SkillPanel>
