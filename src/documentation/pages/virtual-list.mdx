<PageHeader slug="virtual-list" title="Virtual List" component="virtual-list">
  A list too long to render. Only the rows on screen exist in the DOM, and their elements are recycled as you scroll - ten rows and ten million cost the same, the frame rate holds, and the last row is reachable even past the browser's element-height cap. One engine for lists and grids; screen readers still hear "row 5,000,099 of 10,000,000". Hand it records instead of a count and a <a href="https://www.npmjs.com/package/defuss-dataview">defuss-dataview</a> source backs it: filters and sorting run locally over every record, and the query lives in the list's store.
</PageHeader>

```html example label="Ten million rows" hint="Only the rows on screen exist in the DOM - about sixteen at any scroll position - and they are recycled as you scroll, so ten rows and ten million cost the same. Past the browser's height cap the scroll range is mapped, so the last row stays reachable. Every row carries aria-posinset / aria-setsize against the real length."
<div class="virtual-list" id="vl-main" data-empty-text="No results found" aria-label="Ten million rows" style="height:20rem;max-width:28rem;"></div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const { virtualList } = df$.shadcn;
    // rows are recycled: overwrite everything, never append to what was there
    const renderRow = (row, index) => {
      row.textContent = '';
      const label = document.createElement('span');
      label.textContent = 'Item ' + (index + 1).toLocaleString('en');
      const meta = document.createElement('span');
      meta.className = 'virtual-list-row-meta';
      meta.textContent = '#' + (index + 1).toLocaleString('en');
      row.append(label, meta);
    };
    virtualList.setData(document.getElementById('vl-main'), 10_000_000, renderRow);
  });
</script>
```

```html example label="Records: filter and sort locally" schema="none" hint="setSource hands the list 250,000 records behind a defuss-dataview source. The input and the select are bound by data-virtual-list-filter / data-virtual-list-sort - no listener code: every keystroke filters ALL records (case-insensitive; 'age' takes > 40, <= 30 …), sorting reorders them, and the window shows the result. The query is the list's store: the line below subscribes to it."
<div class="flex flex-col gap-3" style="max-width:28rem;">
  <div class="flex flex-wrap gap-2">
    <input class="input" style="flex:1;min-width:9rem;" placeholder="Filter by name…" aria-label="Filter by name" data-virtual-list-filter="vl-records" data-field="name">
    <input class="input" style="width:7rem;" placeholder="Age > 40" aria-label="Filter by age" data-virtual-list-filter="vl-records" data-field="age" data-kind="number" inputmode="decimal">
    <select class="select" aria-label="Sort" data-virtual-list-sort="vl-records">
      <option value="">Source order</option>
      <option value="name:asc">Name A–Z</option>
      <option value="age:desc">Oldest first</option>
      <option value="city:asc">City</option>
    </select>
  </div>
  <div class="virtual-list" id="vl-records" data-empty-text="Nobody matches" aria-label="People" style="height:16rem;"></div>
  <p class="text-sm text-muted-foreground m-0" id="vl-records-count" aria-live="polite"></p>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const { virtualList } = df$.shadcn;
    const first = ['Sofia', 'Jackson', 'Isabella', 'William', 'Olivia', 'Liam', 'Mia', 'Noah'];
    const cities = ['Berlin', 'Lisbon', 'Osaka', 'Toronto', 'Nairobi', 'Lima'];
    const people = Array.from({ length: 250_000 }, (_, i) => ({
      id: i + 1,
      name: first[i % 8] + ' ' + String.fromCharCode(65 + ((i * 7) % 26)) + '.',
      age: 18 + ((i * 13) % 70),
      city: cities[(i * 5) % 6],
    }));
    const list = document.getElementById('vl-records');
    // rows are recycled: overwrite everything; the renderer gets the record
    virtualList.setSource(list, people, {
      render: (row, person) => {
        row.textContent = '';
        const label = document.createElement('span');
        label.textContent = person.name + ' · ' + person.city;
        const meta = document.createElement('span');
        meta.className = 'virtual-list-row-meta';
        meta.textContent = person.age;
        row.append(label, meta);
      },
    });
    const count = document.getElementById('vl-records-count');
    const show = () => {
      count.textContent = virtualList.rows(list).length.toLocaleString('en') + ' of 250,000 people';
    };
    list.store.subscribe(show);
    show();
  });
</script>
```

```html example label="Grid" schema="none" hint="data-columns puts several items in a row (role='grid', aria-rowcount / aria-colcount); the renderer is called per cell with the ITEM index. A million photos - each cell composes the image component; seeded URLs give a recycled cell its own picture back."
<div class="virtual-list" id="vl-grid" data-columns="3" aria-label="Photo grid" style="--virtual-list-row-height:96px;height:18rem;max-width:28rem;"></div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const { virtualList } = df$.shadcn;
    virtualList.setData(document.getElementById('vl-grid'), 1_000_000, (cell, index) => {
      cell.textContent = '';
      const figure = document.createElement('figure');
      figure.className = 'image';
      figure.dataset.ratio = '1/1';
      const img = document.createElement('img');
      img.src = 'https://picsum.photos/seed/' + index + '/88/88';
      img.loading = 'lazy';
      img.decoding = 'async';
      img.alt = '';
      figure.append(img);
      const label = document.createElement('span');
      label.textContent = 'Photo ' + (index + 1).toLocaleString('en');
      cell.append(figure, label);
    });
  });
</script>
```

```html example label="Rich rows and one listener" schema="none" hint="Rows can hold anything - an avatar, a name, a badge. Because the elements are recycled, never attach a listener per row: one delegated listener on the list reads row.dataset.index."
<div class="flex flex-col gap-2" style="max-width:28rem;">
  <div class="virtual-list" id="vl-people" aria-label="Contacts" style="--virtual-list-row-height:52px;height:16rem;"></div>
  <p class="text-sm text-muted-foreground m-0" id="vl-picked" aria-live="polite">Click a contact.</p>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const { virtualList } = df$.shadcn;
    const names = ['Sofia Davis', 'Jackson Lee', 'Isabella Nguyen', 'William Kim', 'Olivia Martin', 'Liam Chen'];
    const list = document.getElementById('vl-people');
    virtualList.setData(list, 250_000, (row, index) => {
      row.textContent = '';
      const name = names[index % names.length] + ' ' + (Math.floor(index / names.length) + 1);
      const avatar = document.createElement('span');
      avatar.className = 'avatar';
      avatar.dataset.size = 'sm';
      avatar.innerHTML = '<span class="avatar-fallback"></span>';
      avatar.firstChild.textContent = name.split(' ').map((w) => w[0]).slice(0, 2).join('');
      const label = document.createElement('span');
      label.textContent = name;
      const badge = document.createElement('span');
      badge.className = 'badge';
      badge.dataset.variant = index % 7 === 0 ? 'default' : 'secondary';
      badge.textContent = index % 7 === 0 ? 'Online' : 'Away';
      badge.style.marginInlineStart = 'auto';
      row.append(avatar, label, badge);
    });
    list.addEventListener('click', (e) => {
      const row = e.target.closest('.virtual-list-row');
      if (row) document.getElementById('vl-picked').textContent = 'Picked contact #' + (Number(row.dataset.index) + 1).toLocaleString('en');
    });
  });
</script>
```

```html example label="Loading" schema="none" hint="setState('loading') marks the list aria-busy and shows placeholder rows; the next setData (or setState('default')) shows the rows."
<div class="flex flex-col gap-3" style="max-width:28rem;">
  <button class="btn" data-variant="outline" data-size="sm" type="button" id="vl-reload" style="align-self:flex-start;">Reload</button>
  <div class="virtual-list" id="vl-loading" aria-label="Loading list" style="height:12rem;"></div>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const { virtualList } = df$.shadcn;
    // rows are recycled: overwrite everything, never append to what was there
    const renderRow = (row, index) => {
      row.textContent = '';
      const label = document.createElement('span');
      label.textContent = 'Item ' + (index + 1).toLocaleString('en');

      list.api.setState('loading');

    load();
  });
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the rows; <code>\{ index \}</code> scrolls that row into view</li>
    <li><code>loading</code> - <code>aria-busy="true"</code> and placeholder rows</li>
    <li><code>empty</code> - no items: the <code>data-empty-text</code> message</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/virtual-list-\{state\}.png</code>.</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `loading` | `boolean` | `true`, `false` | `false` | aria-busy with placeholder rows (`setState('loading')`). |
| `empty` | `boolean` | `true`, `false` | `false` | No items - shows data-empty-text (`setState('empty')`). |
