<PageHeader slug="avatar" title="Avatar" component="avatar">
  An image element with a fallback for representing the user. Supports sizes, status badges, and avatar groups.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - image shown (or fallback when there is no image)</li>
    <li><code>error</code> - the broken-image look, forced without a network failure (same DOM changes a real <code>error</code> event makes)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/avatar-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/avatar.schema.json"><code>avatar.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `error` | `boolean` | `true`, `false` | `false` | Image load failure → initials fallback (the runtime marks `.avatar-image` with `data-error`). |
```
