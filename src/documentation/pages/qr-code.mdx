<PageHeader slug="qr-code" title="QR Code" component="qr-code">
  Encode a URL or exact text locally and render it as a native SVG. The figure follows the theme's surface, border, radius and typography; the symbol keeps its dark-on-light colors and complete quiet zone. Change the payload through the State API, a store or declared attributes.
</PageHeader>

```html example label="Store and markup replay" hint="Subscribe to the effective state, write a complete saved state back to the store, and render a snapshot without changing the live figure." height="39"
<div class="flex flex-col items-start gap-3">
  <div class="flex flex-wrap gap-2">
    <button class="btn" type="button" id="qr-store-change">Change payload</button>
    <button class="btn" type="button" data-variant="outline" id="qr-store-restore">Restore snapshot</button>
    <button class="btn" type="button" data-variant="outline" id="qr-store-render">Render markup</button>
  </div>
  <figure id="qr-store" class="qr-code" data-value="https://example.com/original" data-variant="outline">
    <div class="qr-code-symbol" role="img" aria-label="QR code for the original page"></div>
    <output class="qr-code-status" hidden></output>
    <figcaption class="qr-code-caption">Observable state</figcaption>
  </figure>
  <output id="qr-store-summary"></output>
  <label class="label" for="qr-store-markup">Rendered snapshot markup</label>
  <textarea class="textarea" id="qr-store-markup" rows="5" readonly style="font-family:var(--font-mono);"></textarea>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const qr = df$('#qr-store').get(0);
    const original = JSON.parse(JSON.stringify(qr.api.getState()));
    const show = () => {
      const state = qr.api.getState();
      df$('#qr-store-summary').text(state.name + ' · ' + state.config.value);
    };
    qr.store.subscribe(show);
    show();
    df$('#qr-store-change').on('click', () => qr.api.setState('default', {
      value: 'https://example.com/updated',
      label: 'QR code for the updated page',
      ecc: 'Q'
    }));
    df$('#qr-store-restore').on('click', () => qr.store.set({ name: original.name, config: original.config }));
    df$('#qr-store-render').on('click', () => df$('#qr-store-markup').val(qr.api.render(qr.api.getState())));
  });
</script>
```

<DocText><code>setState()</code> merges partial config; <code>store.set()</code> replaces a complete typed, JSON-serializable state. Successful <code>getState()</code> results include <code>actualVersion</code> and <code>moduleCount</code>; failures include an <code>errorCode</code> and message. Pass snapshots back unchanged for replay. Unknown option names, invalid types and invalid option values throw before application, while capacity failures clear the symbol and enter <code>error</code>.</DocText>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states on every <code>.qr-code</code> figure:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - encode the effective input; empty input lands in <code>empty</code>, encoding failure in <code>error</code>.</li>
    <li><code>empty</code> - clear the symbol and show <code>No QR code data.</code>; retain input.</li>
    <li><code>error</code> - clear the symbol and show <code>QR code unavailable.</code> or controlled failure feedback; retain input.</li>
  </ul>
  <p class="text-sm text-muted-foreground">Pass <code>message</code> to localize explicit empty/error feedback. Calling <code>setState('default')</code> recovers the retained payload. The first figure carries <code>data-state-demo</code>; screenshots exercise all three states without config in light and dark modes.</p>

Machine contract - verified against <a class="link" href="../schemas/qr-code.schema.json"><code>qr-code.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `string` | `—` | `""` | Exact text; a partial default-state update, mirrored in data-value. |
| `ecc` | `enum` | `L`, `M`, `Q`, `H` | `M` | Requested error-correction level, without automatic boosting. |
| `version` | `string` | `—` | `auto` | Attribute editor for auto or a canonical decimal 1–40; the public API uses auto or a number. |
| `label` | `string` | `—` | `QR code` | The accessible name on the image container. |
| `size` | `enum` | `sm`, `md`, `lg` | `md` | Display size; a local --qr-code-size overrides it. |
| `variant` | `enum` | `plain`, `outline` | `plain` | Unframed or themed outline presentation. |
| `default` | `boolean` | `true`, `false` | `—` | Re-encode retained input; observation reports the actual landing state. |
| `empty` | `boolean` | `true`, `false` | `—` | Explicit empty feedback; turning this control off returns to default. |
| `error` | `boolean` | `true`, `false` | `—` | Explicit error feedback; turning this control off returns to default. |
```
