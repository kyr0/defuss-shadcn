<PageHeader slug="theme-switcher" title="Theme Switcher" component="theme-switcher" crumb="theme-switcher">
  A dropdown that re-themes the page by loading one generated stylesheet into
  <code>{"<link id=\"theme-css\">"}</code> — no JS token objects, no inline overrides.
  Each theme is a <code>.css</code> file with <code>:root</code> + <code>.dark</code>
  token blocks (the same shape as <code>default-semantic-tokens.css</code>), so dark
  mode needs no re-apply.
</PageHeader>

<H2>How the mechanism works</H2>

<p class="text-sm text-muted-foreground mb-5">A theme is a plain CSS file — <code>{"theme/<id>.css"}</code> — generated from the tweakcn presets dataset and shipped next to the token file. Applying it is one DOM operation, no matter which UI triggers it:</p>

<CodeCard lang="js" title="theme in 5 lines">{`// apply
let link = document.getElementById('theme-css');
if (!link) {
  link = Object.assign(document.createElement('link'),
    { id: 'theme-css', rel: 'stylesheet', href: 'theme/claude.css' });
  document.getElementById('tokens-css').after(link); // right after the token sheet
}
// reset
link?.remove();`}</CodeCard>

<p class="text-sm text-muted-foreground mt-5 mb-5">This component wraps exactly that: trigger + <code>popover</code> menu + one <code>{"<link>"}</code> swap, plus <code>localStorage</code> persistence, the <code>defuss-theme-change</code> sync event, and a State API for agents/tests. On this repo the files are generated by <code>scripts/build.ts</code> (<code>src/documentation/runtime/themes.ts</code> → <code>dist/theme/*.css</code>); for your own themes, author files in the <code>default-semantic-tokens.css</code> shape (<code>:root</code> + <code>.dark</code> token blocks, tweakcn-compatible) and add one menu item each.</p>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per menu through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — closed (the authored state; the trigger toggles it)</li>
    <li><code>open</code> — shown via the native <code>showPopover()</code>, first theme item focused</li>
  </ul>
