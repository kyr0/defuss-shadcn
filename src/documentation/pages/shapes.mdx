<PageHeader slug="shapes" title="Shapes" introStyle="max-width:38rem;">
  A catalog of ready-made silhouettes for websites, landing pages and documentation: radius scale, organic and cut corners, {"shape-*"} silhouettes, section edges, stylized shadows, frames and background patterns (the theme's plain shadow scale, <code>shadow-2xs</code> ... <code>shadow-2xl</code>, is covered in <DocLink href="theming.html">Theming</DocLink>). One opt-in stylesheet, token colors only - so every shape follows the active theme and dark mode. Every code block is the live demo.
</PageHeader>

<h2 id="install" class="h2-display">Load the module</h2>

<DocText><code>theme/utils/shapes.css</code> is optional, like the sizing and layout modules - no component depends on it. Load it after the token file. Every class is a zero-specificity <code>:where()</code> rule in <code>@layer utilities</code>, so it overrides component styles (a <code>card</code> becomes a leaf, a <code>btn</code> gets a hard shadow) and any rule of your own overrides it.</DocText>

```html
<link rel="stylesheet" href="../theme/utils/default-semantic-tokens.css">
<!-- optional module: corners, clips, edges, shadows, frames, patterns -->
<link rel="stylesheet" href="../theme/utils/shapes.css">
```

<h2 id="cut-corners" class="h2-display">Cut, notch, scoop and squircle corners</h2>

<DocText>Where the browser supports the native <code>corner-shape</code> property (Chromium 139+), these use it, so borders and shadows keep following the outline. <h3 id="aura" class="text-lg font-medium mt-8 mb-2">Aura</h3>

<DocText>An animated light around an element - DaisyUI's aura, same class names. <code>aura</code> is a <strong>wrapper</strong>: its background is the light, a conic gradient turning on a typed <code>@property</code> angle, and the element inside covers the middle, so a ring of light runs around it. <code>aura-dual</code> sends two lights, <code>aura-rainbow</code>, <code>aura-holo</code>, <code>aura-gold</code> and <code>aura-silver</code> swap in a material, and <code>aura-glow</code> turns the ring into a blurred halo behind the element. <code>--shape-ink</code> colors the plain, dual and glow light, <code>--shape-round</code> matches the wrapped element's radius (default <code>--radius-xl</code>, a card), <code>--shape-duration</code> sets one turn. The wrapper is block-level, like the card it usually wraps - in a flex row it hugs its content; around an inline element elsewhere, add <code>w-fit</code>. Under reduced motion the light stands still. Around content that has played - a <DocLink href="teaser.html">Teaser</DocLink> marks itself <code>data-played</code> - the aura rests: the light goes, and the frame keeps its size, so the page does not move.</DocText>

<h2 id="stacks" class="h2-display">Stacks</h2>

<DocText>A pile of sheets behind an element - three box-shadows, so they follow its radius and need no extra markup. The direction picks where the sheets peek out: <code>stack-top</code>, <code>stack-bottom</code>, <code>stack-left</code> and <code>stack-right</code> are centered and taper - every sheet a little narrower and one full step further out, like a pile of notifications - while <code>stack-top-left</code>, <code>stack-top-right</code>, <code>stack-bottom-left</code> and <code>stack-bottom-right</code> offset full-size sheets toward the corner. Modifiers set the step (<code>stack-tight</code> 4px, default 8px, <code>stack-loose</code> 14px), the fill (card sheets with a border by default, <code>stack-outline</code> hollow, <code>stack-filled</code> solid, each sheet a step closer to the background so the pile reads as sheets) and <code>stack-fade</code>, which fades every sheet further out. <code>--shape-ink</code> colors the outline edge or the filled sheets. A stack is the element's box-shadow, so it replaces a <code>shadow-*</code> class - and leave room around it. (Not the layout module's <code>.stack</code>, which is a flex column.)</DocText>

<h2 id="accessibility" class="h2-display">Accessibility</h2>

<DocText>Shapes are decoration: they never replace a label, and clipped text should stay inside the visible area. In forced-colors mode (Windows High Contrast) the browser removes box-shadows and background images, so every shadow-only or pattern-only silhouette gets a system-color outline instead. <code>shadow-lift</code> and <code>frame-marching-ants</code> drop their motion under <code>prefers-reduced-motion: reduce</code>. When you set a <code>--shape-ink</code> behind text, check the contrast yourself - the module only uses theme tokens and cannot know which one you picked.</DocText>
