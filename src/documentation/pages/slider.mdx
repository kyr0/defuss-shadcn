<PageHeader slug="slider" title="Slider" component="slider">
  An input for selecting a value from a range. Built on native <code>&lt;input type="range"&gt;</code> with custom track and thumb styling, filled track indicator, and full keyboard support.
</PageHeader>

  <SkillField label="Keyboard">
<SkillText dense>• <kbd>Right Arrow</kbd> / <kbd>Up Arrow</kbd> - increase value by one step</SkillText>
  <SkillText dense>• <kbd>Left Arrow</kbd> / <kbd>Down Arrow</kbd> - decrease value by one step</SkillText>
  <SkillText dense>• <kbd>Home</kbd> - set to minimum value</SkillText>
  <SkillText dense>• <kbd>End</kbd> - set to maximum value</SkillText>
  <SkillText>• <kbd>Page Up</kbd> / <kbd>Page Down</kbd> - increase/decrease by larger step</SkillText>
  </SkillField>

  <SkillField label="Accessibility">
<SkillText dense>• Native <code>&lt;input type="range"&gt;</code> provides implicit <code>role="slider"</code>, <code>aria-valuenow</code>, <code>aria-valuemin</code>, <code>aria-valuemax</code>.</SkillText>
  <SkillText dense>• Use <code>&lt;label for&gt;</code> to associate a visible label.</SkillText>
  <SkillText dense>• Use <code>aria-valuetext</code> for human-readable value descriptions (e.g., "50%", "Medium").</SkillText>
  <SkillText dense>• Use <code>aria-label</code> when no visible <code>&lt;label&gt;</code> is present.</SkillText>
  <SkillText>• Use <code>&lt;output for&gt;</code> to display the current value accessibly.</SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Firefox uses <code>::-moz-range-progress</code> for the filled track. WebKit/Blink uses a <code>linear-gradient</code> on the track with <code>--slider-value</code> set by JS.</SkillText>
  <SkillText dense>• Vertical sliders use <code>writing-mode: vertical-lr; direction: rtl</code> for cross-browser support.</SkillText>
  <p class="text-muted-foreground m-0">• <code>accent-color</code> set as fallback for browsers that don't support custom pseudo-element styling.</p>
  </SkillField>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - enabled (authored <code>disabled</code> attribute restored; optional <code>\{ value \}</code> config presets the position)</li>
    <li><code>disabled</code> - native <code>disabled</code> attribute: greyed track/thumb, no pointer or keyboard input</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/slider-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/slider.schema.json"><code>slider.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `disabled` | `boolean` | `true`, `false` | `false` | Native disabled state - interaction off, muted styling. |
| `value` | `number` | `—` | `50` | Live slider value; set through the State API (`setState('default', { value })`) and read from `input.value`, so dragging updates it too. |
```
