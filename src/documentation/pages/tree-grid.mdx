<PageHeader slug="tree-grid" title="Tree Grid" component="data-grid">
  A <a class="link" href="data-grid.html">Data Grid</a> whose rows may have a parent. Name the parent field with <code>data-parent-field</code> and the grid becomes an ARIA <code>treegrid</code>: the first column indents by depth and opens and closes branches, while everything a grid does still works on the visible rows - multisort orders siblings, a column filter keeps the ancestors of every match and opens the way to it, pages and infinite loading walk the tree, columns lock. The records stay one flat array; <a class="link" href="https://www.npmjs.com/package/defuss-dataview">defuss-dataview</a> builds the hierarchy.
</PageHeader>

<H2 id="how">How it works</H2>

<DocText>The tree grid IS the <a class="link" href="data-grid.html">Data Grid</a> - same component, same files, same State API (see its page for every attribute and state). <code>data-parent-field</code> (and <code>data-id-field</code>, default <code>id</code>) switch on the hierarchy:</DocText>

<ul class="text-sm text-muted-foreground mb-5 ps-5">
  <li><code>role="treegrid"</code>; each row carries <code>aria-level</code> and, with children, <code>aria-expanded</code>.</li>
  <li>The config gains <code>expanded</code> (the open branch ids) and, while a filter is active, <code>collapsed</code> (branches closed again - a filter opens every branch that holds a match).</li>
  <li>Sorting orders siblings; the hierarchy never breaks. A filter's matches keep their ancestors, and the status line counts both (<em>"12 rows shown · 10 of 11,020 match"</em>).</li>
  <li>Keyboard on the first column: → opens a branch, ← closes it or moves to the parent. <code>df$.shadcn.dataGrid.expandAll(grid)</code> / <code>collapseAll(grid)</code> open or close everything.</li>
</ul>
