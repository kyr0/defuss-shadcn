```html example label="Switchable notation" hint="Let the user choose: a select.color-picker-format inside the picker switches the notation live. An input[data-color-output] inside the picker always holds the value in the chosen notation, so the form submits it that way (the native input keeps #rrggbb under its own name). Click the value to select it for copying."
<form id="brand-form" onsubmit="event.preventDefault()">
  <label class="label" for="brand-color">Brand colour</label>
  <div class="color-picker" data-format="oklch">
    <input type="color" id="brand-color" value="#0f766e"></input>
    <span class="color-picker-value">#0f766e</span>
    <input type="hidden" name="brand" data-color-output></input>
    <select class="color-picker-format" aria-label="Colour notation">
      <option value="hex">HEX</option>
      <option value="rgb">RGB</option>
      <option value="hsl">HSL</option>
      <option value="oklch">OKLCH</option>
    </select>
  </div>
  <p class="text-sm text-muted-foreground" style="margin:0.75rem 0 0;">Submits <code>brand=<output id="brand-out"></output></code></p>
</form>
<script>
  const out = document.querySelector('#brand-form [data-color-output]');
  const show = () => { document.getElementById('brand-out').textContent = out.value; };
  out.addEventListener('change', show);
  setTimeout(show, 0);
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - <code>setState('default', \{ value \})</code> presets the color through the native input (events fire); <code>getState().config.value</code> reports the live hex</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/color-picker-\{state\}.png</code>.</p>
