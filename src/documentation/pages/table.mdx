<PageHeader slug="table" title="Table" component="table">
  A responsive table component for displaying tabular data. Built on native <code>&lt;table&gt;</code> with styled headers, rows, and cells.
</PageHeader>

  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on every <code>table.table</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - as authored: the original row order, no sort, nothing selected</li>
    <li><code>sorted</code> - by <code>config.column</code> (index) and <code>config.direction</code> (ascending / descending)</li>
    <li><code>selected</code> - <code>config.rows</code>: row indices or <code>'all'</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/table-\{state\}.png</code>.</p>

| `selected` | `boolean` | `true`, `false` | `false` | Rows selected (`setState('selected', { rows })`). |
