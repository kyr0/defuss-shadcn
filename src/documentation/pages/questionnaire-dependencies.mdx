<PageHeader slug="questionnaire-dependencies" title="Dependent Answers" component="questionnaire">
  Going back and changing an answer can make later answers wrong. The questionnaire handles two kinds: answers on a branch the new answer no longer leads to (a beach preference after switching to a city break), and answers that were chosen <em>from</em> the changed one (a state picked for the previous country). Both are cleared when the changed step is left - the user is told, <code>questionnaire-invalidate</code> lists them, and they are never submitted.
</PageHeader>

<H2 id="orphans">Abandoned branches</H2>

<DocText>After a changed answer the controller asks the graph which answered steps the answers can still reach: an answered (or skipped) step leads where its answer leads, a step still open may take any of its edges. Every answered step outside that set is an orphan and loses its answers. Answers further along that are still reachable stay.</DocText>

<H2 id="depends-on">Declared dependencies</H2>

<DocText>Some answers stay on the path but stop making sense: a state chosen for a country, a size chosen for a product. <code>data-depends-on="country"</code> (a list: <code>"a, b"</code>) on a step clears its answers whenever one of those fields changes - even when the walk still passes it. The step asks again with its options for the new answer.</DocText>

```html example label="Shipping address" schema="none" hint="Choose a country, then a region - its options are built from the country. Go back, change the country, continue: the region is empty again (data-depends-on='country'), because a German state is no answer for Canada."
<form class="questionnaire" id="q-ship" aria-label="Shipping" data-persist="none" style="max-width:32rem;">
  <div class="questionnaire-progress"></div>
  <fieldset class="questionnaire-step" data-step="country">
    <legend class="questionnaire-title">Ship to which country?</legend>
    <div class="questionnaire-choices">
      <label class="questionnaire-choice"><input type="radio" name="country" value="DE" required><span class="questionnaire-choice-label">Germany</span></label>
      <label class="questionnaire-choice"><input type="radio" name="country" value="CA"><span class="questionnaire-choice-label">Canada</span></label>
    </div>
  </fieldset>
  <fieldset class="questionnaire-step" data-step="region" data-depends-on="country">
    <legend class="questionnaire-title">Which region?</legend>
    <select class="select" name="region" required aria-label="Region" id="q-region"><option value="">Choose…</option></select>
  </fieldset>
  <fieldset class="questionnaire-step" data-step="speed">
    <legend class="questionnaire-title">How fast?</legend>

      <label class="questionnaire-choice"><input type="radio" name="speed" value="express"><span class="questionnaire-choice-label">Express</span></label>
    </div>
  </fieldset>
  <fieldset class="questionnaire-step" data-step="ok" data-end>

    <div class="questionnaire-summary"></div>

  <div class="questionnaire-actions">
    <button class="btn" data-variant="ghost" type="button" data-questionnaire="back">Back</button>

<script>
  document.addEventListener('DOMContentLoaded', () => {
    const REGIONS = { DE: ['Bavaria', 'Berlin', 'Hamburg', 'Saxony'], CA: ['Alberta', 'British Columbia', 'Ontario', 'Quebec'] };
    const form = document.getElementById('q-ship');
    const select = document.getElementById('q-region');
    // the region's options follow the country - built when the region step shows
    form.addEventListener('questionnaire-step', (e) => {
      if (e.detail.step !== 'region') return;
      const keep = select.value;
      select.replaceChildren(new Option('Choose…', ''), ...(REGIONS[e.detail.answers.country] || []).map((r) => new Option(r, r)));
      select.value = keep;
    });
  });
</script>
```

<H2 id="what-is-sent">What is sent</H2>

<DocText>Sending passes only the answers of the steps on the path to the end - an answer that survived on a hidden step (typed, then the user went another way before leaving the step) is still not sent. <code>questionnaire-submit</code> carries <code>\{ answers, history \}</code>; <code>configure(form, \{ onSubmit \})</code> receives the same.</DocText>
