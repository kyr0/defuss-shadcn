<PageHeader slug="radial-progress" title="Radial Progress" component="radial-progress">
  A progress ring with its number in the middle - storage used, a score, a goal reached. CSS draws the arc (one <code>conic-gradient</code> masked to a ring, a round cap on the leading edge); the optional script makes it state: any color, a percent, "x / n" or your own label, values that jump in steps or glide there linearly, and the same reset / step / play buttons as the <DocLink href="progress.html">progress bar</DocLink> (<code>commandfor</code> + <code>command="--reset"</code>).
</PageHeader>

<script>
  function runRingSteps() {
    const ring = document.getElementById('rp-st');
    clearInterval(ring._timer);
    ring.api.setState('default', { value: 0 });
    ring._timer = setInterval(() => {
      const { value, max } = ring.api.getState().config;
      if (value >= max) return clearInterval(ring._timer);
      ring.api.setState('default', { value: value + 10 });
    }, 450);
  }
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code> (the ring's state name follows its value) - the same contract as the <DocLink href="progress.html">progress bar</DocLink>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - determinate: <code>\{ value \}</code> jumps there, <code>\{ value, duration \}</code> glides there linearly (ms), no config restores the authored value; optional <code>\{ max \}</code></li>
    <li><code>indeterminate</code> - <code>aria-valuenow</code> removed: the spinning arc</li>
    <li><code>complete</code> - value = max (<code>\{ duration \}</code> glides there); <code>progress:completed</code> fires</li>
  </ul>
  <p class="text-sm text-muted-foreground m-0 mb-3">Every change fires <code>progress:change</code> (<code>detail: \{ value, max, percent \}</code>). Button commands: <code>commandfor="id" command="--reset"</code> (<code>--increment</code>, <code>--decrement</code>, <code>--play</code>, <code>--pause</code>, <code>--complete</code>, <code>--indeterminate</code>) - or <code>progress:&lt;command&gt;</code> events on the ring. Writing <code>aria-valuenow</code> directly repaints it too.</p>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/radial-progress-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/radial-progress.schema.json"><code>radial-progress.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `number` | `—` | `70` | The value (0 – aria-valuemax); set through the State API (`setState('default', { value })`), observed from `aria-valuenow`. |
| `indeterminate` | `boolean` | `true`, `false` | `false` | No value - the spinning arc (`setState('indeterminate')`). |
| `complete` | `boolean` | `true`, `false` | `false` | Value = max (`setState('complete')`); `progress:completed` fires. |
| `size` | `enum` | `sm`, `md`, `lg` | `"md"` | Ring diameter. |
| `tone` | `enum` | `primary`, `success`, `warning`, `info`, `destructive`, `auto` | `"primary"` | Arc and label color; `auto` follows the value. |
```
