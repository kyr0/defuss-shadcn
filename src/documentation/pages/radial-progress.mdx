<PageHeader slug="radial-progress" title="Radial Progress" component="radial-progress">
  A progress ring with its number in the middle - storage used, a score, a goal reached. Set <code>--value</code> (0-100) and CSS draws the arc: one <code>conic-gradient</code> masked down to a ring, with a round cap on the leading edge. Change the value and the ring tweens there on its own - a typed <code>@property</code> does the animation, no JavaScript, no SVG.
</PageHeader>

<SkillPanel component="radial-progress">

<SkillText>A <code>&lt;div role="progressbar"&gt;</code> with <code>aria-valuenow</code> / <code>aria-valuemin</code> / <code>aria-valuemax</code> - not <code>&lt;progress&gt;</code>, which cannot hold visible text in its center.
```html example label="Animated" schema="none" hint="Write a new --value and the ring tweens there (600ms) - the typed @property animates it; the script only sets the value and the ARIA."
<div class="flex items-center gap-4">
  <div class="radial-progress" id="rp-live" data-size="lg" role="progressbar" aria-valuenow="25" aria-valuemin="0" aria-valuemax="100" style="--value:25">25%</div>
  <div class="flex flex-col gap-2">
    <button class="btn" data-variant="outline" data-size="sm" type="button" onclick="setRing(-10)">− 10</button>
    <button class="btn" data-variant="outline" data-size="sm" type="button" onclick="setRing(10)">+ 10</button>
  </div>
</div>
<script>
  function setRing(delta) {
    const ring = document.getElementById('rp-live');
    const v = Math.max(0, Math.min(100, Number(ring.getAttribute('aria-valuenow')) + delta));
    ring.style.setProperty('--value', v);
    ring.setAttribute('aria-valuenow', v);
    ring.textContent = v + '%';
  }
</script>
```
