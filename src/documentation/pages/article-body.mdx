<div class="mk-article-body">
  <p>Sync is the feature nobody notices until it fails. When we started on Acme 4.0, our goal was simple to state and hard to build: <strong>never lose a keystroke</strong>, online or off.</p>
  <h2>Why CRDTs</h2>
  <p>A conflict-free replicated data type lets two devices edit the same document without a server deciding who wins. Every change is an operation; every operation <a href="#">commutes</a>. Merging becomes a set union.</p>
  <ul>
    <li>Edits apply instantly, on any device</li>
    <li>The server stores operations, not documents</li>
    <li>Any two replicas converge - in any order</li>
  </ul>
  <blockquote>
    <p>The best sync is the one you forget is there.</p>
    <cite>Hannah Lee, Design</cite>
  </blockquote>
  <h3>The write-ahead log</h3>
  <p>Every operation lands in a local log before it touches the document. Call <code>flush()</code> and the log ships in batches:</p>
  <div class="mockup-code" data-title="sync/flush.ts" data-numbers>
    <pre><code>const ops = log.since(cursor);</code></pre>
    <pre><code>await server.push(ops);</code></pre>
    <pre><code>cursor = ops.at(-1).id;</code></pre>
  </div>
