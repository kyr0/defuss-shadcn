<PageHeader slug="visual-editor" title="Visual Editor" component="visual-editor">
  <a class="link" href="https://grapesjs.com" target="_blank" rel="noopener">GrapesJS</a>, the drag-and-drop HTML editor, over the markup the component skills document. Write the page in the element's <code>&lt;script type="text/html"&gt;</code> source block; the first editor on a page loads the pinned GrapesJS build and shows that page in a canvas styled by the page's own sheets. Blocks - any button with a <code>&lt;template&gt;</code> of markup - drop in or insert at the selection; elements select, move and change; <code>html()</code> hands back the same markup the skills describe. The <DocLink href="studio.html">Studio</DocLink> builds whole apps on it.
</PageHeader>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-readonly</code> - read only (the <code>readonly</code> state); <code>data-device="tablet|phone"</code> - the canvas width</SkillText>
  <SkillText dense>• <code>data-visual-editor-for="id"</code> - on a control or a block list: the editor it drives; <code>data-visual-editor-action</code> - <code>undo</code> <code>redo</code> <code>duplicate</code> <code>remove</code> <code>device</code> (a select)</SkillText>
  <SkillText dense>• <code>data-visual-editor-block</code> - a block: its first <code>&lt;template&gt;</code> is the markup it inserts</SkillText>
  <SkillText dense>• <code>data-ready</code> / <code>data-error</code> - written by the runtime once the editor mounted, or when GrapesJS could not be loaded</SkillText>
  </SkillField>

  <SkillField label="Notes">
<p class="text-muted-foreground m-0">• GrapesJS is the official package, pinned (<code>grapesjs@0.23.6</code>) and requested from jsDelivr by the first editor on a page - a page without one never loads it. Its telemetry is off. Its canvas is an iframe it writes into, so a sandboxed frame needs <code>allow-same-origin</code>: these examples use <code>sandbox="editor"</code>. The canvas runs no scripts - a component shows its markup there, the <DocLink href="code-example.html">HTML Preview Editor</DocLink> runs it.</p>
<p class="text-muted-foreground m-0">• Nothing that runs gets in: every markup that enters (the source, <code>setHtml()</code>, <code>insert()</code>, <code>replace()</code>, a dragged block) is cleaned first - scripts, frames, <code>&lt;object&gt;</code>, <code>&lt;embed&gt;</code>, <code>&lt;base&gt;</code>, <code>on*</code> handlers, <code>srcdoc</code>, URLs that run code (also when obfuscated) and SVG animations of an <code>href</code> go, in a template's content too. A stateful component is one locked unit (<code>lock()</code>): it changes through its state and <code>replace()</code>.</p>
  </SkillField>

```html example label="Inspect the selection" hint="Click an element in the canvas: visual-editor-select reports it, and the fields below change it through apply() - the text of a text-only element, a button's data-variant. A handler or a javascript: URL is refused." sandbox="editor" previewStyle="justify-content:flex-start;"
<div class="stack gap-3">
  <div class="visual-editor" id="ve-inspect" aria-label="A call to action" style="--visual-editor-height: 16rem">

      <div class="flex items-center gap-3" style="padding: 2rem">
        <h3 class="h3">Ready to ship?</h3>
        <button class="btn">Deploy</button>
        <button class="btn" data-variant="outline">Preview</button>

    </script>
  </div>
  <div class="flex flex-wrap items-end gap-3">
    <div class="stack gap-1">

    </div>
    <div class="stack gap-1">
      <label class="label" for="ve-inspect-variant">Variant</label>
      <select class="select" id="ve-inspect-variant" disabled>
        <option value="">default</option>
        <option>secondary</option>
        <option>outline</option>
        <option>ghost</option>
        <option>destructive</option>
      </select>
    </div>
    <output class="text-sm text-muted-foreground" id="ve-inspect-out" for="ve-inspect">Nothing selected</output>
  </div>

<script>
  document.addEventListener('DOMContentLoaded', () => {
    const ve = df$.shadcn.visualEditor;
    df$('#ve-inspect').on('visual-editor-select', (e) => {
      const s = e.detail.selection;
      df$('#ve-inspect-out').text(
        s ? `${s.tag}${s.classes.length ? '.' + s.classes.join('.') : ''} at ${s.path}` : 'Nothing selected',
      );
      df$('#ve-inspect-text')
        .prop('disabled', !s || s.text === null)
        .val(s?.text ?? '');
      df$('#ve-inspect-variant')
        .prop('disabled', !s)
        .val(s?.attributes['data-variant'] ?? '');
    });
    df$('#ve-inspect-text').on('input', (e) => ve.apply('#ve-inspect', { text: e.target.value }));
    df$('#ve-inspect-variant').on('change', (e) =>
      ve.apply('#ve-inspect', { attributes: { 'data-variant': e.target.value || null } }),
    );
  });
</script>

```html example label="A locked component" hint="lock(path) makes the accordion one unit: it moves, copies and goes as a whole, but nothing in it is edited, moved or removed and nothing drops into it - its markup is a function of its state (render()), so it changes through its state. Click a part of it, then the heading: selection().unit tells them apart. replace() swaps the selected element for new markup (here: every item open) and keeps it locked." sandbox="editor" previewStyle="justify-content:flex-start;"
<div class="stack gap-3">
  <div class="visual-editor" id="ve-locked" aria-label="Questions" style="--visual-editor-height: 18rem">
    <script type="text/html" class="visual-editor-source">
      <section style="padding: 1.5rem">
        <h3 class="h3">Questions</h3>
        <div class="accordion">
          <details class="accordion-item"><summary class="accordion-trigger"><span>Is it accessible?</span></summary><div class="accordion-content"><p>Yes - native details and summary.</p></div></details>
          <details class="accordion-item"><summary class="accordion-trigger"><span>Is it styled?</span></summary><div class="accordion-content"><p>Yes - the theme's tokens.</p></div></details>
        </div>
      </section>
    </script>
  </div>
  <div class="flex flex-wrap items-center gap-2">
    <button class="btn" data-variant="outline" data-size="sm" type="button" id="ve-locked-open">Open every item</button>
    <span class="text-muted-foreground" id="ve-locked-info">Select an element.</span>
  </div>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const ve = df$.shadcn.visualEditor;
    const el = df$('#ve-locked').get(0);
    const lock = () => ve.lock(el, '0.1');
    if (el.hasAttribute('data-ready')) lock();
    else df$(el).on('visual-editor-ready', lock);
    df$(el).on('visual-editor-select', (e) => {
      const s = e.detail.selection;
      df$('#ve-locked-info').text(
        !s
          ? 'Select an element.'
          : s.unit
            ? `<${s.tag}> belongs to the locked unit at ${s.unit}`
            : `<${s.tag}> is free to edit`,
      );
    });
    // the accordion in another state: the markup its render() gives for that state, from its markup now
    df$('#ve-locked-open').on('click', () => {
      const page = new DOMParser().parseFromString(ve.html(el), 'text/html');
      const model = df$.shadcn.shared.elementModel(df$(page.body).find('.accordion').get(0));
      ve.select(el, '0.1');
      ve.replace(el, df$.shadcn.accordionApi.render({ name: 'all-open', config: {}, model }));
    });
  });
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - editing: elements select, blocks drop, the changes of <code>apply()</code> land; config <code>&#123; device &#125;</code></li>
    <li><code>readonly</code> - <code>data-readonly</code> on the element: the canvas is inert, the selection chrome hidden; config <code>&#123; device &#125;</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/visual-editor-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/visual-editor.schema.json"><code>visual-editor.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `readonly` | `boolean` | `true`, `false` | `false` | Read only: `data-readonly` on the element, the canvas inert. |
| `device` | `enum` | `desktop`, `tablet`, `phone` | `desktop` | The canvas width: `data-device` on the element (tablet 834px, phone 390px). |
```
