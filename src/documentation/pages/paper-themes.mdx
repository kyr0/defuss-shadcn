  <section class="paper-abstract" aria-labelledby="pt-abstract">
    <h2 id="pt-abstract">Abstract</h2>
    <p>A theme is a value for every token and nothing else - but a theme can still be unreadable. We measured the text pairs of the 43 presets that ship with defuss-shadcn and the default palette, 90 palettes in light and dark. Body text reaches 4.5:1 in every one of them; the labels on controls do not. From that measurement we derive three tiers for an automatic theme checker: body text must reach 4.5:1, control labels should and must reach 3:1, and the focus ring should reach 3:1 against the page.</p>
  </section>
