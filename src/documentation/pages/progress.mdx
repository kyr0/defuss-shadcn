<PageHeader slug="progress" title="Progress" component="progress">
  A progress bar showing how much of a task is done. Built on the native <code>&lt;progress&gt;</code> element, in any color, with a live readout - a percentage, "x / n" or your own template - above or inside the bar. The value is state: jump it in steps, let it glide there linearly, and reset, step or play it from plain buttons (<code>commandfor</code> + <code>command="--reset"</code>) - no script of your own.
</PageHeader>

```html example label="Step by step" schema="none" hint="Jumps: --increment / --decrement move the bar by data-step (10% by default) at once, --reset empties it - plain buttons with commandfor + command, no script. 'Run' steps through a task in 10% jumps via the State API."
<div class="flex flex-col gap-4 w-full" style="max-width:24rem;">
  <div class="progress-field">
    <div class="progress-header"><span class="progress-label">Installing packages</span><output class="progress-value" for="st"></output></div>
    <progress class="progress" id="st" value="30" max="100" data-step="10" aria-label="Installing packages"></progress>
  </div>
  <div class="flex flex-wrap gap-2">
    <button class="btn" data-variant="outline" data-size="sm" type="button" commandfor="st" command="--decrement">− 10%</button>
    <button class="btn" data-variant="outline" data-size="sm" type="button" commandfor="st" command="--increment">+ 10%</button>
    <button class="btn" data-variant="secondary" data-size="sm" type="button" onclick="runSteps()">Run</button>
    <button class="btn" data-variant="ghost" data-size="sm" type="button" commandfor="st" command="--reset">Reset</button>
  </div>
</div>
<script>
  function runSteps() {
    const bar = document.getElementById('st');
    clearInterval(bar._timer);
    bar.api.setState('default', { value: 0 });
    bar._timer = setInterval(() => {
      const { value, max } = bar.api.getState().config;
      if (value >= max) return clearInterval(bar._timer);
      bar.api.setState('default', { value: value + 10 });
    }, 450);
  }
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code> (the bar's state name follows its value):</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - determinate: <code>\{ value \}</code> jumps there, <code>\{ value, duration \}</code> glides there linearly (ms), no config restores the authored value; optional <code>\{ max \}</code></li>
    <li><code>indeterminate</code> - the value removed: the moving sweep for an unknown amount</li>
    <li><code>complete</code> - value = max (<code>\{ duration \}</code> glides there); <code>progress:completed</code> fires, as it does whenever a value reaches max</li>
  </ul>
  <p class="text-sm text-muted-foreground m-0 mb-3">Every change fires <code>progress:change</code> (<code>detail: \{ value, max, percent \}</code>). The same moves are button commands - <code>commandfor="id" command="--reset"</code> (<code>--increment</code>, <code>--decrement</code>, <code>--play</code>, <code>--pause</code>, <code>--complete</code>, <code>--indeterminate</code>) - or <code>progress:&lt;command&gt;</code> events on the bar.</p>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/progress-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/progress.schema.json"><code>progress.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `number` | `—` | `66` | Completion (0–max); set through the State API (`setState('default', { value })`), so the readouts, level and events follow. |
| `indeterminate` | `boolean` | `true`, `false` | `false` | No value - the moving sweep (`setState('indeterminate')`). |
| `complete` | `boolean` | `true`, `false` | `false` | Value = max (`setState('complete')`); `progress:completed` fires. |
| `size` | `enum` | `xs`, `sm`, `md`, `lg`, `xl` | `"md"` | Bar thickness. |
| `tone` | `enum` | `primary`, `success`, `warning`, `info`, `destructive`, `auto` | `"primary"` | Fill color; `auto` follows the value. |
```
