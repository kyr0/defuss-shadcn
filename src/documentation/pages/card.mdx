<PageHeader slug="card" title="Card" component="card">
  Content container with header, body, and footer regions. Use <code>&lt;div&gt;</code> for layout grouping or <code>&lt;article&gt;</code> for standalone content.
</PageHeader>

<SkillPanel component="card">
  <SkillField label="Native basis">
<SkillText><code>&lt;div&gt;</code> for layout grouping. <code>&lt;article&gt;</code> for standalone self-contained content.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries" title="responsive layout based on card container width"><code>CSS Container Queries (@container)</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio" title="intrinsic ratio for card media images"><code>aspect-ratio</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.card</code>
    <code>.card-header</code>
    <code>.card-title</code>
    <code>.card-description</code>
    <code>.card-content</code>
    <code>.card-footer</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Card is a container pattern — its children define its purpose</SkillText>
  <SkillText dense>• Avoid deeply nesting cards (card inside card) — use <code>--muted</code> surface instead</SkillText>
  <SkillText dense>• For interactive cards (click to navigate), wrap in <code>&lt;a&gt;</code> and apply card classes to it</SkillText>
  <SkillText dense>• <code>card-footer</code> uses <code>padding-top: 0</code> to avoid double-spacing with <code>card-content</code></SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• For a card grid, use CSS Grid on the parent — the card itself has no layout opinion</p>
  </SkillField>
</SkillPanel>
