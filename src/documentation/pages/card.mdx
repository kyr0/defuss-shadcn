<PageHeader slug="card" title="Card" component="card">
  Content container with header, body, and footer regions. Use <code>&lt;div&gt;</code> for layout grouping or <code>&lt;article&gt;</code> for standalone content.
</PageHeader>

<SkillPanel component="card">
  <SkillField label="Native basis">
<SkillText><code>&lt;div&gt;</code> for layout grouping. <code>&lt;article&gt;</code> for standalone self-contained content.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries" title="responsive layout based on card container width"><code>CSS Container Queries (@container)</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio" title="intrinsic ratio for card media images"><code>aspect-ratio</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>

  </SkillField>

  <SkillField label="Data attributes (on .card)">
<SkillGrid>
    <Variant name="data-variant" description="outline, dashed, ghost, muted, elevated, primary, neutral (charcoal), glass" />
    <Variant name="data-size" description="xs, sm, md (default), lg, xl - padding and type scale together" />
    <Variant name="data-density" description="compact, comfortable (default), spacious - combines with data-size" />
    <Variant name="data-layout" description="side, auto (side while the card is wide enough), overlay (image as background)" />
    <Variant name="data-align" description="center - centered content and actions" />
    <Variant name="data-interactive / a.card" description="lifts on hover, focus ring" />
    <Variant name="label.card" description="selectable: a checked checkbox / radio inside rings the card" />
    <Variant name=".card-media[data-inset]" description="padded, rounded media instead of edge to edge" />
  </SkillGrid>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Card is a container pattern - its children define its purpose</SkillText>
  <SkillText dense>• Avoid deeply nesting cards (card inside card) - use <code>--muted</code> surface instead</SkillText>
  <SkillText dense>• For interactive cards (click to navigate), put the card classes on an <code>&lt;a&gt;</code> - it lifts on hover and shows a focus ring</SkillText>
  <SkillText dense>• On <code>primary</code> / <code>neutral</code> cards, use <code>secondary</code> or <code>outline</code> buttons - a default button matches the card surface</SkillText>
  <SkillText dense>• Shapes, frames, stacks and aura from <DocLink href="shapes.html">Shapes</DocLink> compose with any card</SkillText>
  <SkillText dense>• <code>card-footer</code> uses <code>padding-top: 0</code> to avoid double-spacing with <code>card-content</code></SkillText>
  <p class="text-muted-foreground m-0">• For a card grid, use CSS Grid on the parent - the card itself has no layout opinion</p>
  </SkillField>
</SkillPanel>
