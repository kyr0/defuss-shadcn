<PageHeader slug="anim-wipe-up" title="Wipe Up" component="motion">
  A <code>clip-path</code> reveal: the element is clipped to a zero-height sliver at one edge and the inset animates open until nothing is clipped - the imperative twin of <code>data-df-entrance="wipe-up"</code> on the Motion page. It ships as a paired channel - <code>df$.anim.wipeIn</code> reveals, <code>df$.anim.wipeOut</code> conceals - and both are directional: <code>north</code>/<code>south</code>/<code>east</code>/<code>west</code> pick the edge the wipe starts from (in) or exits toward (out); <code>south</code> is the classic wipe up from the bottom. Everything below is driven by <code>df$.anim.wipeIn</code> / <code>df$.anim.wipeOut</code>.
</PageHeader>

<script type="module">
  // df$ (all.js) boots after example scripts in the sandbox - reference it
  // only at event time, never at parse time.
  const target = document.getElementById('anim-wipe-up-target');
  const durationInput = document.getElementById('anim-wipe-up-duration');
  const easingSelect = document.getElementById('anim-wipe-up-easing');
  let direction = 'south';        // wipe up from the bottom edge
  let lastChannel = 'wipeIn';     // Pause/Resume/Finish/Reset act on this one

    direction,
    duration: Number(durationInput.value) || 600,
    easing: easingSelect.value,
  });

  document.getElementById('anim-wipe-up-in').addEventListener('click', () => {
    lastChannel = 'wipeIn';
    df$.anim.wipeIn.play(target, config());
  });
  document.getElementById('anim-wipe-up-out').addEventListener('click', () => {
    lastChannel = 'wipeOut';
    df$.anim.wipeOut.play(target, config());

  document.querySelectorAll('[data-dir]').forEach((btn) => {
    btn.addEventListener('click', () => {
      direction = btn.dataset.dir;
      document.querySelectorAll('[data-dir]').forEach((b) => {
        if (b === btn) b.setAttribute('aria-pressed', 'true');
        else b.removeAttribute('aria-pressed');
      });
    });
  });

  document.getElementById('anim-wipe-up-pause').addEventListener('click', () => df$.anim[lastChannel].pause(target));

```html example label="Scroll binding" schema="none" hint="opts.scroll ties progress to a scroll position instead of time - here the scroller's own y offset scrubs the reveal. Scroll the stage."
<script type="module">
  // all.js (df$) boots after example scripts in the sandbox - bind in the
  // load handler, never at parse time. play() with a scroll binding hands the
  // animation to a ScrollTimeline (or the rAF fallback): progress IS the
  // scroller's relative y position, direction 'south' reveals from the bottom.
  window.addEventListener('load', () => {
    const scroller = document.getElementById('anim-wipe-up-scroller');
    const scrollTarget = document.getElementById('anim-wipe-up-scroll-target');
    df$.anim.wipeIn.play(scrollTarget, { direction: 'south', scroll: { target: scroller, axis: 'y' } });
  });
</script>
```

Pass `{ target: 'viewport' }` (or omit `target`) instead of an element to bind progress to the page's own scroll - the parallax use for presentations, where a long page scroll drives the wipe.

## Config axes

- **`direction`** - `'north' | 'south' | 'east' | 'west'`, the edge the wipe starts from (`wipeIn`) or exits toward (`wipeOut`); `'south'` is the wipe-up reveal from the bottom.
- **`duration`** - total time in ms (default 1500).
- **`easing`** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
