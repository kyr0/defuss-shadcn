<PageHeader slug="search-filter" title="Search & Filter" component="search-filter">
  Two dedicated controls for narrowing a list. The <strong>search box</strong> frames a native <code>&lt;input type="search"&gt;</code> with an icon and a clear (×) button that appears only while there is text - the × and Escape empty the field through the same <code>input</code> event typing fires. The <strong>filter</strong> turns native radios and checkboxes into category chips: choose one and the others step aside behind a reset, CSS only - after daisyUI's filter.
</PageHeader>

```html example label="Live results" schema="none" hint="One input listener filters the list - typing and clearing alike - and an <output> announces the count."
<div class="flex flex-col gap-3" style="max-width:22rem;">
  <div class="search-box">
    <i data-lucide="search"></i>
    <input type="search" id="people-q" placeholder="Filter people" aria-label="Filter people" aria-controls="people">
    <button type="button" class="search-box-clear" aria-label="Clear search"></button>
  </div>
  <output for="people-q" class="text-sm text-muted-foreground" id="people-count">6 people</output>
  <ul id="people" class="text-sm m-0 ps-5 flex flex-col gap-1">
    <li>Ada Lovelace</li>
    <li>Alan Turing</li>
    <li>Grace Hopper</li>
    <li>Katherine Johnson</li>
    <li>Linus Torvalds</li>
    <li>Margaret Hamilton</li>
  </ul>
</div>
<script>
  document.getElementById('people-q').addEventListener('input', (e) => {
    const q = e.target.value.trim().toLowerCase();
    let shown = 0;
    document.querySelectorAll('#people li').forEach((li) => {
      const match = li.textContent.toLowerCase().includes(q);
      li.hidden = !match;
      if (match) shown++;
    });
    document.getElementById('people-count').value = shown === 1 ? '1 person' : `${shown} people`;
  });
</script>
```

```html example label="Searching" schema="none" hint="The searching state: a spinner stands in for the icon and the field is aria-busy while the lookup runs; the page ends it with filled. Here every keystroke waits 600 ms for the (pretend) server."
<div class="flex flex-col gap-3" style="max-width:22rem;">
  <div class="search-box" id="remote-search">
    <i data-lucide="search"></i>
    <input type="search" placeholder="Search the archive" aria-label="Search the archive">
    <button type="button" class="search-box-clear" aria-label="Clear search"></button>
  </div>
  <output class="text-sm text-muted-foreground" id="remote-result">Type to search 2,400 reports.</output>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const box = document.getElementById('remote-search');
    const out = document.getElementById('remote-result');
    let timer;
    box.querySelector('input').addEventListener('input', (e) => {
      clearTimeout(timer);
      const q = e.target.value.trim();
      if (!q) { out.value = 'Type to search 2,400 reports.'; return; }
      box.api.setState('searching');
      out.value = 'Searching…';
      timer = setTimeout(() => {
        box.api.setState('filled');
        out.value = `${(q.length * 37) % 211 + 3} reports match "${q}".`;
      }, 600);
    });
  });
</script>
```

```html example label="Search and filter together" schema="none" hint="Both narrow the same list: the chips pick a category, the box matches text. One function re-runs on the box's input event and the form's change and reset events."
<div class="flex flex-col gap-3" style="max-width:26rem;">
  <div class="search-box">
    <i data-lucide="search"></i>
    <input type="search" id="lib-q" placeholder="Search articles" aria-label="Search articles" aria-controls="lib">
    <button type="button" class="search-box-clear" aria-label="Clear search"></button>
  </div>
  <form class="filter" id="lib-filter" data-size="sm" aria-label="Category">
    <input type="radio" name="cat" value="guide" aria-label="Guides">
    <input type="radio" name="cat" value="api" aria-label="API">
    <input type="radio" name="cat" value="news" aria-label="News">
    <input type="reset" value="×" aria-label="Clear filter">
  </form>
  <output class="text-sm text-muted-foreground" id="lib-count">6 articles</output>
  <ul id="lib" class="text-sm m-0 ps-5 flex flex-col gap-1">
    <li data-cat="guide">Getting started with themes</li>
    <li data-cat="guide">Dark mode in one attribute</li>
    <li data-cat="api">The State API</li>
    <li data-cat="api">Schema contracts</li>
    <li data-cat="news">Release 0.9: chat and mockups</li>
    <li data-cat="news">Search & Filter lands</li>
  </ul>
</div>
<script>
  const form = document.getElementById('lib-filter');
  const apply = () => {
    const q = document.getElementById('lib-q').value.trim().toLowerCase();
    const cat = new FormData(form).get('cat');
    let shown = 0;
    document.querySelectorAll('#lib li').forEach((li) => {
      const match = (!cat || li.dataset.cat === cat) && li.textContent.toLowerCase().includes(q);
      li.hidden = !match;
      if (match) shown++;
    });
    document.getElementById('lib-count').value = shown === 1 ? '1 article' : `${shown} articles`;
  };
  document.getElementById('lib-q').addEventListener('input', apply);
  form.addEventListener('change', apply);
  // reset fires before the form clears - run after it
  form.addEventListener('reset', () => setTimeout(apply));
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states of the search box via the shared State API, driven per instance through the bound <code>api</code> (the filter is CSS only):</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - empty, no ×; setting it clears the field (<code>\{ value \}</code> presets one)</li>
    <li><code>filled</code> - has text, the × shows; entered automatically as you type</li>
    <li><code>searching</code> - a lookup is pending: a spinner replaces the icon and the field is <code>aria-busy</code>; the page ends it with <code>filled</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/search-filter-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/search-filter.schema.json"><code>search-filter.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `value` | `string` | `—` | `""` | The search text; set through the State API (`setState('default', { value })`), read from the input. |
| `filled` | `boolean` | `true`, `false` | `false` | Has text - the × shows; entered automatically as you type. |
| `searching` | `boolean` | `true`, `false` | `false` | A lookup is pending: spinner in place of the icon, `aria-busy` on the field. |
```
