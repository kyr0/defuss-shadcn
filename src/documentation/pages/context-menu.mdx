<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - closed (the authored state; right-click opens it)</li>
    <li><code>open</code> - menu shown; <code>setState('open', \{ x, y \})</code> positions it (viewport top-left by default, there is no pointer to anchor to)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/context-menu-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/context-menu.schema.json"><code>context-menu.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `open` | `boolean` | `true`, `false` | `false` | Shown - driven through the component's own State API. The runtime positions it at `x/y` (default 8/8) first. |
```
