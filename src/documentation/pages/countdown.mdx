<PageHeader slug="countdown" title="Countdown" component="countdown">
  Numbers that roll to their next value like an odometer. Set <code>--value</code> on a span (0-999) and CSS turns the digits - no JavaScript. Add <code>data-until</code> or <code>data-duration</code> to a group and the optional script makes it a live, accessible timer with running, paused and finished states.
</PageHeader>

```html example label="A value" schema="none" hint="The CSS-only pattern: one span with --value and the same number as text. Change both (here once a second through api.setState('default', { value })) and the digits roll." height="14"
<span class="countdown" id="cd-one" data-size="2xl">
  <span style="--value:59" aria-live="polite">59</span>
</span>
<script>
  const one = document.getElementById('cd-one');
  let n = 59;
  setInterval(() => { n = n === 0 ? 59 : n - 1; one.api.setState('default', { value: n }); }, 1000);
</script>
```

```html example label="Clock" schema="none" hint="Several values in one .countdown, separated by plain text. data-digits='2' keeps the leading zero. No component script needed: the page writes --value and the text of each unit - the CSS rolls the digits." height="14"
<span class="countdown" id="cd-clock" data-size="2xl" data-digits="2" style="font-family:var(--font-mono);">
  <span data-unit="hours" style="--value:10">10</span>:<span data-unit="minutes" style="--value:24">24</span>:<span data-unit="seconds" style="--value:59">59</span>
</span>
<script>
  const set = (unit, v) => {
    const s = document.querySelector(`#cd-clock [data-unit="${unit}"]`);
    s.style.setProperty('--value', v);
    s.textContent = v;
  };
  const tick = () => { const d = new Date(); set('hours', d.getHours()); set('minutes', d.getMinutes()); set('seconds', d.getSeconds()); };
  tick();
  setInterval(tick, 1000);
</script>
```

  const end = document.getElementById('cd-end');
  const msg = document.getElementById('cd-msg');
  end.addEventListener('countdown:finished', () => { msg.value = 'Time is up!'; });
  document.getElementById('cd-restart').addEventListener('click', () => { msg.value = ''; end.api.setState('default'); });
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on each timer (and each plain <code>.countdown</code>):</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - as authored: a timer restarts from <code>data-until</code> / <code>data-duration</code>; a plain countdown takes <code>config.value</code> / <code>config.values</code></li>
    <li><code>running</code> - ticking; resumes, or starts toward <code>config.until</code> / <code>config.duration</code></li>
    <li><code>paused</code> - frozen at the remaining time</li>
    <li><code>finished</code> - at zero, <code>countdown:finished</code> fired</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/countdown-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/countdown.schema.json"><code>countdown.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `remaining` | `number` | `—` | `0` | Seconds left - `setState('running', { duration })` restarts toward it; observed from `getState().config.remaining`. |
| `running` | `boolean` | `true`, `false` | `true` | The timer ticks (unchecking pauses it). |
| `paused` | `boolean` | `true`, `false` | `false` | Frozen at the remaining time. |
| `finished` | `boolean` | `true`, `false` | `false` | At zero; `countdown:finished` fired. |
```
