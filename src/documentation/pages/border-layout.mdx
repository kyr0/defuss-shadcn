<PageHeader slug="border-layout" title="Border Layout" component="border-layout">
  An application frame in five regions - north, south, west and east around a center - with every divider draggable. It reuses the <DocLink href="resizer.html">Resizer</DocLink>: each side is a <code>.resizer</code> wrapping its pane, and inside a border layout its handle becomes a full-length divider you drag or move with the arrow keys. Leave regions out and the same frame is a horizontal split, a vertical split or three columns; nest it for more. North/south or west/east dominant, grips, dashed / dotted / double / gap dividers, custom handles, collapsible and remembered panels - after shadcn's Resizable.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per layout through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - every region open; setting it restores the authored sizes</li>
    <li><code>collapsed</code> - one or more regions folded: <code>\{ regions: ['west', 'south'] \}</code> or <code>\{ region: 'west' \}</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/border-layout-\{state\}.png</code>.</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `collapsed` | `boolean` | `true`, `false` | `false` | One or more regions folded away (the schema folds west); `default` opens them all. |
```
