<PageHeader slug="data-grid" title="Data Grid" component="data-grid">
  A table for data no table can hold. Only the rows on screen exist in the DOM, and every query runs locally over all of them through <a class="link" href="https://www.npmjs.com/package/defuss-dataview">defuss-dataview</a>: sort by several columns at once, filter each column, lock columns that stay put while the rest scroll, page through, or load more as you reach the end. The query is the grid's state - <code>el.store</code> - so any code can follow it, drive it or keep it. Give rows a parent and it is a <a class="link" href="tree-grid.html">tree grid</a>.
</PageHeader>

<script>
  document.addEventListener('DOMContentLoaded', () => {
    const first = ['Sofia', 'Jackson', 'Isabella', 'William', 'Olivia', 'Liam', 'Mia', 'Noah', 'Emma', 'Lucas'];
    const countries = ['Germany', 'Portugal', 'Japan', 'Canada', 'Kenya', 'Peru', 'France', 'India'];
    const products = ['Desk lamp', 'Notebook', 'Headphones', 'Backpack', 'Mug', 'Keyboard', 'Monitor arm', 'Plant pot'];
    const statuses = ['open', 'paid', 'shipped', 'delivered', 'refunded'];
    const day = 86_400_000;
    const start = Date.UTC(2025, 0, 1);
    // deterministic synthetic data: order i always reads the same
    const orders = Array.from({ length: 100_000 }, (_, i) => {
      const quantity = 1 + ((i * 7) % 9);
      return {
        id: 100_001 + i,
        customer: first[i % 10] + ' ' + String.fromCharCode(65 + ((i * 11) % 26)) + '.',
        country: countries[(i * 3) % 8],
        product: products[(i * 5) % 8],
        quantity,
        total: Math.round(quantity * (4 + ((i * 7919) % 9600) / 100) * 100) / 100,
        status: statuses[(i * 13) % 5],
        date: start + ((i * 37) % 640) * day,
      };
    });
    const grid = document.getElementById('dg-orders');
    df$.shadcn.dataGrid.setSource(grid, orders);
    // the query IS the store: follow it
    const line = document.getElementById('dg-orders-query');
    const describe = ({ config }) => {
      const sort = config.sorters.map((s) => s.field + ' ' + s.direction).join(', ') || 'none';
      line.textContent = 'Sorted by: ' + sort + ' · filters: ' + config.filters.length + ' · locked: ' + config.locked.join(', ') + ' · selected: ' + config.selected.length;
    };
    grid.store.subscribe(describe);
    describe(grid.store.value);
  });
</script>

```html example label="Infinite scrolling" schema="none" hint="data-paging='infinite' adds a page as you near the end: first from the records it has, then from load(offset, size) - an async function (here a fake 400 ms network) that returns the next records, or none when there are no more. <div class="data-grid" id="dg-feed" aria-label="Event log" data-paging="infinite" data-page-size="50" style="height:20rem;max-width:36rem;">
  <div class="data-grid-viewport">
    <div class="data-grid-head">
      <div class="data-grid-row">
        <div class="data-grid-header" data-field="id" data-type="number" data-format="" data-width="5rem" data-sortable="false">#</div>
        <div class="data-grid-header" data-field="level" data-width="6rem" data-sortable="false">Level</div>
        <div class="data-grid-header" data-field="message" data-width="minmax(14rem, 1fr)" data-sortable="false">Message</div>
      </div>
    </div>
    <div class="data-grid-body"></div>
  </div>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const levels = ['info', 'info', 'info', 'warn', 'error'];
    const messages = ['User signed in', 'Cache warmed', 'Job queued', 'Slow query (812 ms)', 'Payment declined'];
    // a remote source: 1,000 events in pages, 400 ms per request
    const load = (offset, size) => new Promise((resolve) => setTimeout(() => {
      if (offset >= 1000) return resolve([]);
      resolve(Array.from({ length: Math.min(size, 1000 - offset) }, (_, i) => {
        const n = offset + i;
        return { id: n + 1, level: levels[(n * 7) % 5], message: messages[(n * 7) % 5] };
      }));
    }, 400));
    df$.shadcn.dataGrid.setSource(document.getElementById('dg-feed'), [], { load });
  });
</script>
```

```html example label="Custom cells" schema="none" hint="cells: { field: (el, record) } fills a column with anything - a badge, a meter. Cells are recycled with their rows; the function gets a fresh .data-grid-content element each time."
<div class="data-grid" id="dg-cells" aria-label="Deployments" style="height:16rem;max-width:40rem;">
  <div class="data-grid-viewport">
    <div class="data-grid-head">
      <div class="data-grid-row">
        <div class="data-grid-header" data-field="service" data-width="minmax(9rem, 1fr)">Service</div>
        <div class="data-grid-header" data-field="status" data-width="8rem">Status</div>

      </div>
    </div>
    <div class="data-grid-body"></div>
  </div>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const states = [['healthy', 'default'], ['degraded', 'secondary'], ['down', 'destructive']];
    const rows = Array.from({ length: 2000 }, (_, i) => ({ id: i + 1, service: 'service-' + String(i + 1).padStart(4, '0'), status: (i * 7) % 11 === 0 ? 2 : (i * 3) % 7 === 0 ? 1 : 0, coverage: 40 + ((i * 13) % 60) }));
    df$.shadcn.dataGrid.setSource(document.getElementById('dg-cells'), rows, {
      cells: {
        status: (el, record) => {
          const [label, variant] = states[record.status];
          const badge = document.createElement('span');
          badge.className = 'badge';
          badge.dataset.variant = variant;
          badge.textContent = label;
          el.append(badge);
        },
        coverage: (el, record) => {
          const meter = document.createElement('meter');
          meter.min = 0;
          meter.max = 100;
          meter.value = record.coverage;
          meter.style.width = '5rem';
          const text = document.createElement('span');
          text.textContent = ' ' + record.coverage + '%';
          el.append(meter, text);
        },
      },
    });
  });
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>; the config of every state is the query (<code>filters</code>, <code>sorters</code>, <code>locked</code>, <code>page</code>, <code>expanded</code>, <code>collapsed</code>, <code>selected</code>), merged on each <code>setState</code> and observable as <code>el.store</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the rows of the query; a query nothing matches lands in <code>empty</code></li>
    <li><code>loading</code> - <code>aria-busy="true"</code> and skeleton rows; a grid without records starts here</li>
    <li><code>empty</code> - no rows: the <code>data-empty-text</code> message</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/data-grid-\{state\}.png</code>.</p>

| `empty` | `boolean` | `true`, `false` | `false` | No rows - shows data-empty-text (`setState('empty')`). |
