<PageHeader slug="anim-skew" title="Skew" component="motion">
  A directional shear: the element leans in from a slant (or exits into one) while fading. Ships as the paired <code>skewIn</code>/<code>skewOut</code> channels, each with four orientation variants - <code>west</code>/<code>east</code> skew on the X axis, <code>north</code>/<code>south</code> on the Y axis. In-variants start skewed from the named edge, out-variants exit toward it. Everything is driven by <code>df$.anim.skewIn</code> and <code>df$.anim.skewOut</code>.
</PageHeader>

<script type="module">
  // bound lazily on first scroll so df$ is only touched at event time;
  // reset() unbinds the scroll link, so re-arm the flag afterwards.
  const scroller = document.getElementById('anim-skew-stage');
  const target = document.getElementById('anim-skew-scroll-target');
  let bound = false;
  scroller.addEventListener('scroll', () => {
    if (bound) return;
    bound = true;
    df$.anim.skewIn.play(target, { direction: 'west', scroll: { target: scroller, axis: 'y' } });
  }, { passive: true });
  document.getElementById('anim-skew-scroll-reset').addEventListener('click', () => {
    df$.anim.skewIn.reset(target);
    bound = false;
  });
</script>
```

Passing `scroll: { target: 'viewport' }` instead of an element binds progress to the page's own scroll - the parallax use for presentations, where elements un-skew as the section scrolls into view.

## Config axes

- **`direction`** - `'north' | 'south' | 'east' | 'west'` (default `'west'` here; the engine's own fallback is `'north'`). `west`/`east` shear on the X axis (`skewX`), `north`/`south` on the Y axis (`skewY`).
- **`duration`** - total duration in ms (default `1500`).
- **`easing`** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
