<PageHeader slug="anim-down" title="Slide Down" component="motion">
  The slide animation in depth: the element glides in from an edge (or out toward one) while fading - the imperative twin of the motion component's <code>data-df-entrance="down"</code>.
</PageHeader>

Slide Down is the directional slide animation: `slideIn` starts the element at the named edge and settles it into place, `slideOut` sends it back out toward that same edge - with `direction: 'north'` (the default) the element starts above and slides down, matching the motion component's `down` entrance. All four orientation variants (`north`, `south`, `east`, `west`) ship per variant, and everything is driven by the `df$.anim.slideIn.*()` / `df$.anim.slideOut.*()` channels - `play`, `pause`, `resume`, `finish`, `reset`, `state`.

        b.setAttribute('aria-pressed', String(b === btn)));

    df$.anim.slideIn.reset(target);
    df$.anim.slideOut.reset(target);
  });
</script>

The same binding with `{ target: 'viewport' }` (the default when `target` is omitted) ties progress to the page's own scroll position instead of a container - the parallax use for presentations.

## Config axes

- `direction` - `'north' | 'south' | 'east' | 'west'` (default `'north'`): the edge the in-variant starts at and the out-variant exits toward.
- `distance` - the slide travel as any CSS length (default `'24px'`), e.g. `'48px'` for a longer drift.
- `duration` - total time in ms (default `1500`).
- `easing` - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
