<PageHeader slug="dropdown" title="Dropdown Menu" component="dropdown" crumb="dropdown-menu">
  Context menu built on the <code>popover</code> API. Light-dismiss is automatic. Supports groups, shortcuts, separators, and destructive items. Animated with <code>@starting-style</code>.

  <SkillField label="Notes">
<SkillText dense>• Always use <code>popover</code> attribute for the menu — it renders in the top layer and avoids overflow clipping</SkillText>
  <SkillText dense>• CSS anchor positioning (<code>position-anchor</code>, <code>anchor()</code>) handles placement — no JS positioning needed</SkillText>
  <SkillText dense>• <code>position-try: flip-block</code> automatically flips the menu above the trigger if there's no room below</SkillText>
  <SkillText dense>• The <code>popover</code> API handles light-dismiss (click outside) automatically</SkillText>
  <SkillText dense>• For submenus, nest another <code>\[popover\]</code> element triggered by a <code>menuitem</code> with <code>aria-haspopup="menu"</code></SkillText>
  <SkillText dense>• Escape closes the menu and returns focus to the trigger</SkillText>
  <p class="text-muted-foreground m-0">• Menu items use <code>tabindex="-1"</code> — only arrow keys move focus (roving focus pattern)</p>
  </SkillField>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per menu through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — closed (the authored state; the trigger toggles it)</li>
    <li><code>open</code> — shown via the native <code>showPopover()</code>, first item highlighted</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first demo carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/dropdown-\{state\}.png</code>.</p>

```states
| --- | --- | --- | --- | --- |

```
