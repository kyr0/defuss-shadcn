<PageHeader slug="bibtex" title="BibTeX" component="bibtex">
  How to cite this: the BibTeX you author, shown the way the reader needs it - as BibTeX (normalized, the fields aligned, highlighted) or formatted as an APA, MLA, Chicago, Harvard or IEEE reference. Several entries become a reference list, sorted or numbered as the style wants. DOIs and URLs are clickable links; the copy button copies exactly what is shown - as plain text, never markup - and says so. Without JavaScript the source stays readable as-is. Used by the <DocLink href="paper.html">Modern Paper</DocLink> template.
</PageHeader>

## From script

```html example label="Driven from outside" sandbox="links" hint="df$.shadcn.bibtex.show(el, format) switches the format, .copy(el) copies, .format(text, style) formats without an element; bibtex-format and bibtex-copy report every change." previewStyle="align-items:stretch;"
<div class="grid gap-3" style="max-width:44rem">
  <div class="flex flex-wrap gap-2">
    <button class="btn" data-size="sm" data-variant="outline" id="cite-js-apa">Show APA</button>
    <button class="btn" data-size="sm" data-variant="outline" id="cite-js-ieee">Show IEEE</button>
    <button class="btn" data-size="sm" id="cite-js-copy">Copy</button>
  </div>
  <figure class="bibtex" id="cite-js" data-formats="bibtex apa ieee" aria-label="Attention Is All You Need">
    <pre><code class="bibtex-source">@inproceedings{vaswani2017attention,
  author = {Ashish Vaswani and Noam Shazeer and Niki Parmar and Jakob Uszkoreit and Llion Jones and Aidan N. Gomez and {\L}ukasz Kaiser and Illia Polosukhin},
  title = {Attention Is All You Need},
  booktitle = {Advances in Neural Information Processing Systems},
  volume = {30},
  pages = {5998--6008},
  year = {2017},
  publisher = {Curran Associates, Inc.}
}</code></pre>
  </figure>
  <output id="cite-js-log" class="text-sm text-muted-foreground">Events show up here.</output>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const lib = df$.shadcn.bibtex;
    const el = document.getElementById('cite-js');
    const log = document.getElementById('cite-js-log');
    document.getElementById('cite-js-apa').addEventListener('click', () => lib.show(el, 'apa'));
    document.getElementById('cite-js-ieee').addEventListener('click', () => lib.show(el, 'ieee'));
    document.getElementById('cite-js-copy').addEventListener('click', () => lib.copy(el));
    el.addEventListener('bibtex-format', (e) => { log.textContent = 'bibtex-format: ' + e.detail.format; });
    el.addEventListener('bibtex-copy', (e) => { log.textContent = 'bibtex-copy: ' + e.detail.format + (e.detail.ok ? ' - ' + e.detail.text.length + ' characters' : ' - selected for a manual copy'); });
  });
</script>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on each block:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the source in the format of <code>config.format</code> (<code>data-format</code> on the block)</li>
    <li><code>copied</code> - the copy feedback: the button says Copied (<code>data-copied</code>), the status announces it; back to <code>default</code> after two seconds</li>
  </ul>
  <p class="text-sm text-muted-foreground">The config is <code>&#123; format &#125;</code>. The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/bibtex-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/bibtex.schema.json"><code>bibtex.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `format` | `enum` | `bibtex`, `apa`, `mla`, `chicago`, `harvard`, `ieee` | `bibtex` | The format shown - `setState('default', { format: 'apa' })`; mirrored as `data-format` on the block. |
| `copied` | `boolean` | `true`, `false` | `false` | The copy feedback - `setState('copied')`; returns to `default` after two seconds. |
```
