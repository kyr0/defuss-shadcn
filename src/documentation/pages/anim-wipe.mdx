<PageHeader slug="anim-wipe" title="Wipe" component="motion">
  A wipe reveals - or hides - an element with an animated <code>clip-path</code> inset: the content never moves, only the visible window grows from one edge. It ships as the paired <code>wipeIn</code> / <code>wipeOut</code> channels in the four orientations <code>north</code>, <code>south</code>, <code>east</code> and <code>west</code>, and everything below is driven imperatively by <code>df$.anim.wipeIn</code> and <code>df$.anim.wipeOut</code>.
</PageHeader>

<script type="module">
  const target = document.getElementById('anim-wipe-target');
  const duration = document.getElementById('anim-wipe-duration');
  const easing = document.getElementById('anim-wipe-easing');
  let direction = 'west'; // default: reveal from the left, like motion.css 'wipe'
  let lastChannel = 'wipeIn';

  // df$ is referenced only at event time - core boots after this script parses
  const play = (channel) => {
    lastChannel = channel;
    df$.anim[channel].play(target, {
      direction,
      duration: Number(duration.value) || 1500,
      easing: easing.value,
    });
  };
  document.getElementById('anim-wipe-in').addEventListener('click', () => play('wipeIn'));
  document.getElementById('anim-wipe-out').addEventListener('click', () => play('wipeOut'));

  for (const btn of document.querySelectorAll('#anim-wipe-dirs [data-dir]')) {
    btn.addEventListener('click', () => {
      direction = btn.dataset.dir;
      document.querySelectorAll('#anim-wipe-dirs [data-dir]').forEach((b) =>
        b.setAttribute('aria-pressed', String(b === btn)));
    });
  }

  for (const action of ['pause', 'resume', 'finish', 'reset']) {
    document.getElementById(`anim-wipe-${action}`).addEventListener('click', () =>
      df$.anim[lastChannel][action](target));
  }
</script>
```

## Scroll binding

```html example label="Scroll-driven wipe" schema="none" hint="opts.scroll ties progress to a scroll position instead of time - here the element's own scroll container drives wipeIn, so the reveal scrubs as you scroll."

  <div id="anim-wipe-scroll-target" style="width:160px; height:100px; display:flex; align-items:center; justify-content:center; border:1px solid var(--border); border-radius:var(--radius-lg); background:var(--card); color:var(--card-foreground); font-weight:600;">Wipe</div>
  <div style="height: 80px;"></div>

<script type="module">
  // bind on load: core installs df$ after this script parses
  window.addEventListener('load', () => {
    df$.anim.wipeIn.play(document.getElementById('anim-wipe-scroll-target'), {
      direction: 'west',
      scroll: { target: document.getElementById('anim-wipe-scroller'), axis: 'y' },
    });
  });
</script>
```

Pass `{ target: 'viewport' }` instead of an element to bind the progress to the page's own scroll - the parallax use for presentations.

## Config

- `direction` - `'north' | 'south' | 'east' | 'west'`: the starting edge for `wipeIn`, the exit edge for `wipeOut` (this demo defaults to `'west'`, matching the `wipe` entrance of motion.css).
- `duration` - total animation time in milliseconds (default `1500`).
- `easing` - any CSS easing string (default `cubic-bezier(0.16, 1, 0.3, 1)`).
