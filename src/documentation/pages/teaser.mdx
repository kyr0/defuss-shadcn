<PageHeader slug="teaser" title="Teaser" component="teaser">
  A card that stands in for content that should not load yet - a slide deck, a video, an embedded app. The content waits in a <code>&lt;template&gt;</code>, where nothing loads or runs; the <DocLink href="play-button.html">Play Button</DocLink> - or a click anywhere on the card - morphs it into place through defuss-morph. Wrapped in the Shapes module's <DocLink href="shapes.html">aura</DocLink>, the teaser draws the eye until it is played.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the teaser: the play button, the title and the text (<code>setState('default')</code> brings it back)</li>
    <li><code>played</code> - the template's content in the teaser's place, <code>data-played</code> on the element</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/teaser-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/teaser.schema.json"><code>teaser.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `played` | `boolean` | `true`, `false` | `false` | The template's content in the teaser's place (`data-played`). |
```
