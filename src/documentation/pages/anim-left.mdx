<PageHeader slug="anim-left" title="Slide Left" component="motion">
  The imperative twin of the <code>left</code> entrance: the element starts at its right edge and travels left into place. Everything is driven by <code>df$.anim.slideIn</code> / <code>df$.anim.slideOut</code> - the two channels ship as an in/out pair, each directional with the four orientation variants (<code>north</code>, <code>south</code>, <code>east</code>, <code>west</code>; default <code>east</code>, matching motion.css <code>left</code>). In-variants start at the named edge, out-variants exit toward it.

  const target = document.getElementById('anim-left-target');
  const durationInput = document.getElementById('anim-left-duration');
  const easingSelect = document.getElementById('anim-left-easing');
  const dirButtons = {
    north: document.getElementById('anim-left-dir-n'),
    south: document.getElementById('anim-left-dir-s'),
    west: document.getElementById('anim-left-dir-w'),
    east: document.getElementById('anim-left-dir-e'),
  };
  let direction = 'east';    // default: starts right, travels left
  let lastChannel = 'slideIn';

  const config = () => ({
    direction,
    duration: Number(durationInput.value) || 1500,
    easing: easingSelect.value,
  });

  document.getElementById('anim-left-in').addEventListener('click', () => {
    lastChannel = 'slideIn';
    df$.anim.slideIn.play(target, config());
  });
  document.getElementById('anim-left-out').addEventListener('click', () => {
    lastChannel = 'slideOut';
    df$.anim.slideOut.play(target, config());
  });
  for (const [name, btn] of Object.entries(dirButtons)) {
    btn.addEventListener('click', () => {
      direction = name;
      for (const other of Object.values(dirButtons)) other.setAttribute('aria-pressed', String(other === btn));
    });
  }
  for (const method of ['pause', 'resume', 'finish', 'reset']) {
    document.getElementById(`anim-left-${method}`).addEventListener('click', () => {
      df$.anim[lastChannel][method](target);
    });
  }
</script>

Pass `{ target: 'viewport' }` (or omit `target`) instead of an element to bind progress to the page's own scroll position - the parallax use for presentations, where sections slide left as the reader scrolls.

## Config axes

- **direction** - `north` | `south` | `east` | `west`; the edge the in-variant starts at and the out-variant exits toward (default `east` for the slide-left pairing).
- **distance** - travel length, any CSS length (default `24px`), e.g. `distance: '64px'` for a longer drift.
- **duration** - total runtime in ms (default `1500`; collapses to ~1ms under `prefers-reduced-motion`).
- **easing** - any CSS easing (default `cubic-bezier(0.16, 1, 0.3, 1)`).
