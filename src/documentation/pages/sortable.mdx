<p class="text-sm font-medium mb-2 mt-8">Disabled Items</p>

<p class="text-muted-foreground text-sm mb-4">Set <code>aria-disabled="true"</code> to lock an item in place: it cannot be dragged, keyboard focus skips it, and it <strong>keeps its position</strong> while the other items move around it. A locked row in the middle is a fixed divider - move an item across it (drag it, or <code>Alt+↑</code>/<code>Alt+↓</code>) and the item steps over the locked slot while its neighbour on the other side shifts across, so the locked row stays put and both groups keep their size.</p>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - authored item order; <code>setState('default')</code> restores that order after any drag/keyboard moves, <code>\{ index \}</code> activates one item, and <code>getState().config</code> reports the live <code>order</code> + <code>activeIndex</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/sortable-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/sortable.schema.json"><code>sortable.schema.json</code></a> by <code>bun run verify</code>:


```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `activeIndex` | `number` | `—` | `-1` | Position of the active item (`-1` = none); `setState('default', { index })` activates one, drag/keyboard follow, mirrored as `data-active-index`. |
```
