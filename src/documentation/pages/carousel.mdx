<PageHeader slug="carousel" title="Carousel" component="carousel">

</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — showing a slide; <code>setState('default', \{ index \})</code> scrolls to that slide (loop-aware), and <code>getState().config.index</code> reports the live index</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/carousel-\{state\}.png</code>.</p>

Machine contract — verified against <a href="../schemas/carousel.schema.json"><code>carousel.schema.json</code></a> by <code>bun run verify</code>:

This component exposes no observable states — it is driven through its runtime API and native behavior.

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `activeSlide` | `number` | `—` | `0` | Index of the slide in view (`setState('default', { index })`); mirrored as `data-current-index` and updated by nav/dots/swipe. |
```
