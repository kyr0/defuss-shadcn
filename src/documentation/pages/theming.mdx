<PageHeader slug="theming" title="Theming" introStyle="max-width:38rem;">
  The theme is defined by semantic tokens — CSS custom properties that match the <a href="https://tweakcn.com" target="_blank" style="text-decoration:underline;">tweakcn.com</a> export format. Export a theme from tweakcn, replace <code>default-semantic-tokens.css</code> with the <code>:root</code> and <code>.dark</code> blocks, and every component rethemes instantly.
</PageHeader>

<H2>Customization</H2>

<p class="text-sm text-muted-foreground mb-5">There are two ways to customize the theme:</p>

<div class="flex flex-col gap-6 mb-10">
  <div>
    <h3 style="font-size:1rem;font-weight:500;margin:0 0 0.375rem;">1. Swap the entire theme</h3>
    <p class="text-sm text-muted-foreground mb-3">Go to <DocLink href="https://tweakcn.com" target="_blank">tweakcn.com</DocLink>, design a theme, copy the <code>:root</code> and <code>.dark</code> CSS variable blocks, and replace the contents of <code>default-semantic-tokens.css</code>. Every component updates instantly.</p>
  </div>
  <div>
    <h3 style="font-size:1rem;font-weight:500;margin:0 0 0.375rem;">2. Override individual tokens</h3>
    <p class="text-sm text-muted-foreground mb-3">Add a stylesheet <strong>after</strong><code>default-semantic-tokens.css</code> and override specific variables:</p>
    <pre><code class="language-markup">{"<link rel=\"stylesheet\" href=\"default-semantic-tokens.css\">\n<style>\n  :root {\n    --primary: oklch(0.55 0.2 250);\n    --primary-foreground: oklch(1 0 0);\n    --radius: 0.5rem;\n  }\n</style>"}</code></pre>
  </div>
</div>

<H2>Dark mode</H2>

<p class="text-sm text-muted-foreground mb-5">The theme file includes both <code>:root</code> (light) and <code>.dark</code> (dark) values. To toggle dark mode, add or remove <code>class="dark"</code> on the <code>&lt;html&gt;</code> element. Every token switches automatically — no per-component overrides needed. See the <a href="dark-mode.html" class="btn" data-variant="link">Dark Mode</a> page for system preference detection, localStorage persistence, and a step-by-step toggle implementation.</p>
