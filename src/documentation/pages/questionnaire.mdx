<PageHeader slug="questionnaire" title="Questionnaire" component="questionnaire">
  One question at a time, the next one chosen by the answers. The questionnaire is a single native <code>&lt;form&gt;</code> whose steps are <code>&lt;fieldset&gt;</code>s, grouped into blocks; the controller walks a <a href="questionnaire-branching.html">flow graph</a>, <a href="questionnaire-validation.html">validates</a> each step before it is left, keeps the <a href="questionnaire-drafts.html">branch history and a draft</a> that survives a reload, <a href="questionnaire-dependencies.html">clears answers</a> a changed answer cut off, and can <a href="questionnaire-graph.html">check and draw its own graph</a>. Without JavaScript it is a plain long form.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API; the config is the walk - <code>\{ step, answers, history, index, skipped \}</code> - observable as <code>el.store</code> (every keystroke included):</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - at the start step</li>
    <li><code>answering</code> - on a later step; <code>setState('answering', \{ step \})</code> jumps there</li>
    <li><code>review</code> - on an end step: the summary and Send</li>
    <li><code>submitted</code> - sent: the steps give way to <code>.questionnaire-complete</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/questionnaire-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/questionnaire.schema.json"><code>questionnaire.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `answering` | `boolean` | `true`, `false` | `false` | On a step after the start (`setState('answering')`). |
| `review` | `boolean` | `true`, `false` | `false` | On an end step - the summary and Send (`setState('review')`). |
| `submitted` | `boolean` | `true`, `false` | `false` | Sent - the completion shows (`setState('submitted')`). |
```
