<PageHeader slug="separator" title="Separator" component="separator">
  Visually or semantically separates content. Built on the native <code>&lt;hr&gt;</code> element with support for vertical orientation and labeled separators. No JavaScript required.
</PageHeader>

  <SkillField label="Notes">
<SkillText dense>• The vertical separator requires the parent to be a flex container.</SkillText>
  <SkillText dense>• Text inside a <code>&lt;div class="separator"&gt;</code> sits on the line (two pseudo-element lines flank it). An empty separator must be truly empty - even a space turns it into a text separator.</SkillText>
  <SkillText dense>• With meaningful text ("or"), leave <code>role="separator"</code> off - that role hides its text from screen readers - or name it with <code>aria-label</code>.</SkillText>
  <SkillText dense>• The older <code>.separator-label</code> wrapper (two <code>&lt;hr&gt;</code> around a span) keeps working.</SkillText>
  <SkillText dense>• Decorative separators should use <code>role="none"</code> or <code>aria-hidden="true"</code>.</SkillText>
  <SkillText dense>• In <code>forced-colors</code> mode, the separator uses <code>CanvasText</code> system color.</SkillText>
  <SkillText dense>• In <code>prefers-contrast: more</code> mode, an unsized separator is 2px thick and an uncolored one takes <code>--foreground</code>.</SkillText>
  <p class="text-muted-foreground m-0">• Separators are purely visual - no JavaScript required.</p>
  </SkillField>
