<PageHeader slug="separator" title="Separator" component="separator">
  Visually or semantically separates content. Built on the native <code>&lt;hr&gt;</code> element with support for vertical orientation and labeled separators. No JavaScript required.
</PageHeader>

<SkillPanel component="separator">
  <SkillField label="Native basis">
<SkillText><code>&lt;hr&gt;</code> element (horizontal rule) and <code>&lt;div role="separator"&gt;</code> for vertical orientation.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/hr" title="thematic break / horizontal rule with implicit role=&quot;separator&quot;"><code>&lt;hr&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/separator_role" title="ARIA separator role for non-<hr> elements (vertical orientation)"><code>role="separator"</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="Windows High Contrast Mode support with system colors"><code>forced-colors</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-contrast" title="increased contrast when requested by the user"><code>prefers-contrast</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.separator</code>
    <code>.separator-label</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText>• <code>data-orientation</code> — values: <code>vertical</code></SkillText>
  </SkillField>

  <SkillField label="Variants">
<SkillGrid>
    <Variant name="data-orientation" description="Direction — Element" />
    <Variant name="*(default)*" description="Horizontal — &lt;hr&gt;" />
    <Variant name="vertical" description="Vertical — &lt;div role=&quot;separator&quot;&gt;" />
  </SkillGrid>
  </SkillField>

  <SkillField label="ARIA">
<div style="display:grid;grid-template-columns:auto auto 1fr;gap:0.25rem 1rem;margin-bottom:1.25rem;">
    <code>role="separator"</code>
    <span class="text-muted-foreground">&lt;div&gt;</span>
    <span class="text-muted-foreground">Required on vertical separators</span>
    <code>role="none"</code>
    <span class="text-muted-foreground">&lt;hr&gt;</span>
    <span class="text-muted-foreground">Marks decorative separators — hidden from AT</span>
    <code>aria-hidden="true"</code>
    <span class="text-muted-foreground">&lt;hr&gt;</span>
    <span class="text-muted-foreground">Alternative for decorative separators</span>
  </div>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• The vertical separator requires the parent to be a flex container.</SkillText>
  <SkillText dense>• The labeled separator uses a flex layout with two <code>&lt;hr&gt;</code> elements flanking the label text.</SkillText>
  <SkillText dense>• Decorative separators should use <code>role="none"</code> or <code>aria-hidden="true"</code>.</SkillText>
  <SkillText dense>• In <code>forced-colors</code> mode, the separator uses <code>CanvasText</code> system color.</SkillText>
  <SkillText dense>• In <code>prefers-contrast: more</code> mode, thickness doubles to 2px.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• Separators are purely visual — no JavaScript required.</p>
  </SkillField>
</SkillPanel>
