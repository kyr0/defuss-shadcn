<DocText>Start with <code>flex</code> or <code>inline-flex</code> — they only select the formatting context; direction, wrapping, alignment and spacing are added explicitly. <code>stack</code> is the convenience column with a default four-unit, density-aware gap. <h2 id="distribution" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Distribution with justify-\*</h2>

<DocText><code>justify-\*</code> distributes items on the main axis. <code>justify-between</code> pins the edges, <code>justify-around</code> gives every item equal half-margins, <code>justify-evenly</code> equal full gaps. It distributes spare space — it is not a substitute for a minimum <code>gap-\*</code>. Resize the demo with the toolbar to see the spare space come and go.</DocText>

<h2 id="alignment" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Cross-axis alignment with items-\* and self-\*</h2>

<DocText><code>items-\*</code> aligns the row's children on the cross axis; <code>self-\*</code> overrides one child. <code>items-baseline</code> lines up text, <code>self-stretch</code> lets one panel fill the row's height.</DocText>

<h2 id="flexibility" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Flexible sizing: grow, shrink, basis</h2>

<DocText><code>flex-1</code> lets an item grow and shrink from a zero basis — the fluid column. <code>flex-none</code> (<code>shrink-0</code> + fixed size) pins an item — the icon, the thumbnail, the sidebar. <code>grow</code> / <code>grow-0</code> and <code>shrink</code> / <code>shrink-0</code> tune the factors individually; <code>basis-0/auto/full</code> sets the starting size. Resize the demo: the <code>flex-1</code> columns absorb whatever the fixed <code>w-24</code> box leaves.</DocText>

<h2 id="wrapping" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Wrapping rows of chips and cards</h2>

<DocText><code>flex-wrap</code> lets items flow onto new lines following the available width — tag lists, filter chips, card walls. <code>flex-nowrap</code> is the native default; keep it for toolbars that must never break. Resize the demo to watch the chips wrap and unwrap.</DocText>

<h2 id="overflow" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Handle the real overflow source</h2>

<DocText>A flex item's automatic minimum can resist shrinking. Apply <code>min-w-0</code> to the flexible content region and choose text wrapping or scrolling — as in the label/content row of the first demo. Do not fix overflow by clipping the entire layout.</DocText>

<h2 id="advanced" style="font-family:var(--font-display);font-size:1.375rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.875rem;">Real world: a chat thread</h2>

<DocText>A messaging panel is a stack of flex rows. Incoming rows pair a pinned avatar (<code>size-8 shrink-0</code>) with a fluid bubble (<code>flex-1 min-w-0 p-3</code>), bottom-aligned with <code>items-end</code>; the outgoing row flips to <code>justify-end</code>; the composer pins its button (<code>shrink-0</code>) against a fluid field (<code>flex-1 min-w-0</code>). The <code>min-w-0</code> is what lets a bubble shrink below its content width — without it, a long unbroken word would stretch the row past the panel instead of wrapping. Resize with the toolbar: the avatars and the Send button hold their size while the bubbles and the field give.</DocText>
