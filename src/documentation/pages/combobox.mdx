<PageHeader slug="combobox" title="Combobox" component="combobox">
  A searchable select triggered by an outline button. Opens a popover with a search input and a scrollable list of options. Keyboard navigable via <code>aria-activedescendant</code>. Uses the <code>popover</code> API for top-layer rendering.
</PageHeader>

  <SkillField label="Notes">
<SkillText dense>• The trigger is a <code>.btn\[data-variant="outline"\]</code> — styled by the button system</SkillText>
  <SkillText dense>• When the popover opens, focus moves to the search input inside</SkillText>
  <SkillText dense>• When the popover closes, focus returns to the trigger button</SkillText>
  <SkillText dense>• Use <code>aria-activedescendant</code> to communicate the highlighted item to screen readers</SkillText>
  <SkillText dense>• The <code>popover</code> attribute enables top-layer rendering and light-dismiss</SkillText>
  <SkillText dense>• CSS anchor positioning places the popover below the trigger; no JS positioning needed</SkillText>
  <SkillText dense>• The popover animates in via <code>@starting-style</code> + <code>transition-behavior: allow-discrete</code></SkillText>
  <SkillText dense>• The check icon for selected items uses a CSS <code>::before</code> pseudo-element</SkillText>
  <SkillText dense>• Filter matching is case-insensitive and supports substring matching</SkillText>
  <SkillText dense>• A clear (✕) button is injected on the trigger once a value is selected, replacing the chevron; clicking it restores the placeholder</SkillText>
  <SkillText dense>• Group labels and separators auto-hide when their group has no visible items</SkillText>
  <SkillText dense>• <code>overscroll-behavior: contain</code> prevents scroll chaining from the listbox</SkillText>
  <SkillText dense>• <code>prefers-reduced-motion: reduce</code> disables all transitions</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• <code>forced-colors: active</code> supports Windows High Contrast Mode</p>
  </SkillField>

  <p class="text-sm text-muted-foreground" style="margin:0 0 0.75rem;">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground" style="margin:0 0 0.75rem;padding-left:1.25rem;">
    <li><code>default</code> — closed (the authored state; the trigger toggles it)</li>

  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/combobox-\{state\}.png</code>.</p>
