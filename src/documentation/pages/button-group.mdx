<PageHeader slug="button-group" title="Button Group" component="button-group">
  Groups related buttons with connected borders. Built on a <code>&lt;div&gt;</code> container that merges adjacent button edges. CSS only — no JavaScript.
</PageHeader>

<SkillPanel component="button-group">
  <SkillField label="Native basis">
<SkillText><code>&lt;div&gt;</code> container with <code>.btn</code> buttons. Visually merges adjacent buttons with connected borders.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/group_role" title="groups related buttons"><code>role="group"</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-label" title="accessible name for the group"><code>aria-label</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/separator_role" title="visually divides buttons within a group"><code>role="separator"</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/:has" title="restores radius on buttons adjacent to separators"><code>:has()</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_logical_properties_and_values" title="RTL support via logical properties"><code>Logical properties</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="maps separator to system ButtonText"><code>forced-colors</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.btn-group</code>
    <code>.btn</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText>• <code>data-orientation</code> — values: <code>vertical</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Button groups work best with the <code>outline</code> variant — the connected borders create a cohesive unit.</SkillText>
  <SkillText dense>• Adjacent button borders collapse so only one border renders between buttons.</SkillText>
  <SkillText dense>• The group removes internal border-radii to create seamless joins.</SkillText>
  <SkillText dense>• Use <code>&lt;hr role="separator"&gt;</code> in Split buttons to divide the primary action from its dropdown trigger.</SkillText>
  <SkillText dense>• Uses CSS logical properties for automatic RTL support.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• No JavaScript required — this is purely a CSS layout component.</p>
  </SkillField>
</SkillPanel>
