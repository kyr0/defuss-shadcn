<PageHeader slug="tooltip" title="Tooltip" component="tooltip">
  A popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it. Uses the Popover API with CSS anchor positioning for placement.
</PageHeader>

<SkillPanel component="tooltip">
  <SkillField label="Native basis">
<SkillText>Popover API (<code>popover="hint"</code>) for hover/focus hint popups with CSS anchor positioning for placement.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Global_attributes/popover" title="native popover with light dismiss"><code>popover (hint)</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_anchor_positioning" title="tether tooltip to trigger"><code>CSS Anchor Positioning</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/position-area" title="declarative anchor-relative placement"><code>position-area</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/position-try-fallbacks" title="automatic collision avoidance"><code>position-try-fallbacks</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@starting-style" title="entry animation"><code>@starting-style</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.tooltip</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-tooltip-trigger</code> - on trigger element, value is the tooltip ID</SkillText>
  <SkillText dense>• <code>data-side</code> - on tooltip: <code>top</code> | <code>bottom</code> | <code>left</code> | <code>right</code></SkillText>
  <SkillText dense>• <code>data-align</code> - on tooltip: <code>start</code> | <code>center</code> | <code>end</code></SkillText>
  <SkillText dense>• <code>data-arrow</code> - on a child <code>&lt;div&gt;</code> inside tooltip for connecting caret</SkillText>
  <SkillText dense>• <code>data-delay</code> - on trigger element, open delay in ms (default: 700)</SkillText>
  <SkillText>• <code>data-close-delay</code> - on trigger element, close delay in ms (default: 0)</SkillText>
  </SkillField>

  <SkillField label="Wiring conventions">
<SkillText>• <code>data-tooltip-trigger</code> on any element - opens the component</SkillText>
  </SkillField>
</SkillPanel>

```html example label="Default" height="14"
<div style="display:flex;align-items:center;justify-content:center;gap:1.0rem;padding:2.5rem 0;">
  <button class="btn" data-variant="outline" data-tooltip-trigger="tip-default">Hover me</button>
  <div class="tooltip" id="tip-default" popover="hint" role="tooltip">Add to library</div>
</div>
```

<p class="text-sm font-medium mb-2 mt-8">Disabled Button</p>

<p class="text-muted-foreground text-sm mb-4">Wrap a disabled button in a <code>&lt;span&gt;</code> with the trigger attribute, since disabled elements don't fire mouse events.</p>

```html example height="14"
<div style="display:flex;align-items:center;justify-content:center;gap:1.0rem;padding:2.5rem 0;">
  <span data-tooltip-trigger="tip-disabled" style="cursor:not-allowed;">
    <button class="btn" data-variant="outline" disabled style="pointer-events:none;">Disabled</button>
  </span>
  <div class="tooltip" id="tip-disabled" popover="hint" role="tooltip">This action is unavailable</div>
</div>
```

<p class="text-sm font-medium mb-2 mt-8">Custom Delay</p>

<p class="text-muted-foreground text-sm mb-4">Use <code>data-delay</code> on the trigger to override the default 700 ms open delay.</p>

```html example height="14"
<div style="display:flex;align-items:center;justify-content:center;gap:1.0rem;flex-wrap:wrap;padding:2.5rem 0;">
  <button class="btn" data-variant="outline" data-tooltip-trigger="tip-instant" data-delay="0">Instant (0 ms)</button>
  <div class="tooltip" id="tip-instant" popover="hint" role="tooltip">No delay!</div>
  <button class="btn" data-variant="outline" data-tooltip-trigger="tip-fast" data-delay="200">Fast (200 ms)</button>
  <div class="tooltip" id="tip-fast" popover="hint" role="tooltip">Fast tooltip</div>
  <button class="btn" data-variant="outline" data-tooltip-trigger="tip-slow" data-delay="1500">Slow (1500 ms)</button>
  <div class="tooltip" id="tip-slow" popover="hint" role="tooltip">Slow tooltip</div>
</div>
```

<p class="text-sm font-medium mb-2 mt-8">Group Behavior</p>

<p class="text-muted-foreground text-sm mb-4">Once any tooltip opens, subsequent tooltips in the page skip the delay and appear instantly. After 400 ms with no tooltip visible, the delay resets. Hover across the buttons below to see the effect.</p>

```html example height="14"
<div style="display:flex;align-items:center;justify-content:center;gap:0.5rem;padding:2.5rem 0;">
  <button class="btn" data-variant="outline" data-size="sm" data-tooltip-trigger="tip-g1">
    <i data-lucide="bold" style="width:14px;height:14px;"></i>
  </button>
  <div class="tooltip" id="tip-g1" popover="hint" role="tooltip">Bold</div>
  <button class="btn" data-variant="outline" data-size="sm" data-tooltip-trigger="tip-g2">
    <i data-lucide="italic" style="width:14px;height:14px;"></i>

  <div class="tooltip" id="tip-g2" popover="hint" role="tooltip">Italic</div>
```

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per tooltip through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - hidden (the authored state; hover/focus reveal with delay)</li>
    <li><code>visible</code> - shown immediately, bypassing the hover delay</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first demo carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/tooltip-\{state\}.png</code>.</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `visible` | `boolean` | `true`, `false` | `false` | Hint shown (`popover="hint"` - opening a hint does not dismiss other popovers). |
```
