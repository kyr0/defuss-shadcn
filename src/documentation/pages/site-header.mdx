<PageHeader slug="site-header" title="Site Header" component="site-header">
  A marketing page header: brand, container-aware dropdown nav, and actions. The nav collapses below 30rem container width — pure CSS, popovers native.
</PageHeader>

<SkillPanel component="site-header">
  <SkillField label="Native basis">
<SkillText><code>&lt;header&gt;</code> landmark with <code>&lt;nav&gt;</code>; no script. The nav collapses via a container query (<code>@container</code>), so the block adapts to the width it is placed in, not the viewport. Dropdowns compose the \[navigation-menu\](../navigation-menu/component-skill.md) component: trigger buttons wired with <code>popovertarget</code> and <code>popover</code> panels — the Popover API handles open/close, Escape, and light dismiss natively.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/header" title="banner landmark"><code>&lt;header&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/nav" title="navigation landmark with `aria-label`"><code>&lt;nav&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/position#sticky_positioning" title="opt-in sticky header, no scroll JS"><code>position: sticky</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_containment/Container_queries" title="width-aware nav collapse"><code>Container queries</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/API/Popover_API" title="declarative dropdown triggers, zero JS"><code>popovertarget\` / \`popover</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_anchor_positioning" title="panels place below their trigger (from navigation-menu)"><code>CSS anchor positioning</code></ApiPill>
