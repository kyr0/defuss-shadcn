  A marketing page header: brand, container-aware dropdown nav, and actions. The nav collapses below 30rem container width — pure CSS, popovers native.
</PageHeader>

<SkillPanel component="site-header">
  <SkillField label="Native basis">
<SkillText><code>&lt;header&gt;</code> landmark with <code>&lt;nav&gt;</code>; no script. The nav collapses via a container query (<code>@container</code>), so the block adapts to the width it is placed in, not the viewport. Dropdowns compose the <DocLink href="navigation-menu.html">Navigation Menu</DocLink> component: trigger buttons wired with <code>popovertarget</code> and <code>popover</code> panels — the Popover API handles open/close, Escape, and light dismiss natively.</SkillText>
  </SkillField>
