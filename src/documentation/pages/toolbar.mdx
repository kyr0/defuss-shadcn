<PageHeader slug="toolbar" title="Toolbar" component="toolbar">
  Groups related controls into a single keyboard-navigable bar. Composes Toggle Groups, Buttons, and Separators with roving tabindex navigation.
</PageHeader>

<SkillPanel component="toolbar">
  <SkillField label="Native basis">
<SkillText><code>role="toolbar"</code> container. Groups related controls (buttons, toggles, separators) into a single keyboard-navigable bar.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Roles/toolbar_role" title="a container for grouped controls"><code>role="toolbar"</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-orientation" title="declares layout direction"><code>aria-orientation</code></ApiPill>
    <ApiPill href="https://www.w3.org/WAI/ARIA/apg/patterns/toolbar/" title="keyboard navigation specification"><code>WAI-ARIA Toolbar Pattern</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@media/forced-colors" title="maps toolbar border to system ButtonText"><code>forced-colors</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.toolbar</code>
    <code>.separator</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText>• <code>data-orientation</code> - values: <code>vertical</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• Toolbars compose Toggle Groups, Button Groups, Buttons, and Separators.</SkillText>
  <SkillText dense>• The toolbar handles roving tabindex - only one item is in the tab order at a time.</SkillText>
  <SkillText dense>• Use vertical separators between logical groups of controls.</SkillText>
  <p class="text-muted-foreground m-0">• The toolbar does not enforce selection logic - that's handled by the child components.</p>
  </SkillField>
</SkillPanel>

    <li><code>default</code> - roving tabindex at the authored position (first item); <code>setState('default', \{ focus: n \})</code> parks the roving stop on item <em>n</em> instead, and <code>getState().config.rovingIndex</code> reports where it currently is</li>
  </ul>
