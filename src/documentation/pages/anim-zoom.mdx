<PageHeader slug="anim-zoom" title="Zoom" component="motion">
  The scale entrance/exit pair of the imperative animation engine: <code>zoomIn</code> grows the element from <code>scale(0.8)</code> (configurable) and transparent to full size, <code>zoomOut</code> shrinks it away again - both around a configurable <code>transform-origin</code>. Zoom is not directional; its geometry axis is the origin point. Everything below is driven by <code>df$.anim.zoomIn</code> and <code>df$.anim.zoomOut</code> - Web Animations API under the hood, no CSS class toggling.
</PageHeader>

<script type="module">
  const target = document.getElementById('anim-zoom-target');
  const opts = () => ({
    duration: Number(document.getElementById('anim-zoom-duration').value) || undefined,
    origin: document.getElementById('anim-zoom-origin').value,
    easing: document.getElementById('anim-zoom-easing').value,
  });
  // the lifecycle buttons act on whichever channel played last
  let last = 'zoomIn';
  const on = (id, fn) => document.getElementById(id).addEventListener('click', fn);
  on('anim-zoom-in', () => { last = 'zoomIn'; df$.anim.zoomIn.play(target, opts()); });
  on('anim-zoom-out', () => { last = 'zoomOut'; df$.anim.zoomOut.play(target, opts()); });
  on('anim-zoom-pause', () => df$.anim[last].pause(target));
  on('anim-zoom-resume', () => df$.anim[last].resume(target));
  on('anim-zoom-finish', () => df$.anim[last].finish(target));
  on('anim-zoom-reset', () => df$.anim[last].reset(target));
</script>

<p class="text-sm text-muted-foreground m-0 mb-3">Passing <code>{`scroll: { target: 'viewport' }`}</code> instead of an element binds progress to the page's own scroll - the parallax use for presentations and long-form pages.</p>

## Config axes

<ul>
  <li><code>origin</code> - the <code>transform-origin</code> the scale grows from / shrinks toward, e.g. <code>'50% 50%'</code> (default) or <code>'0% 0%'</code>.</li>
  <li><code>scale</code> - the scale factor at the hidden end (default <code>0.8</code>; a value above 1, e.g. <code>1.1</code>, turns the pair into a shrink-in / grow-out effect).</li>
  <li><code>duration</code> - total duration in ms (default 1500; 1ms under <code>prefers-reduced-motion</code>).</li>
  <li><code>easing</code> - any CSS easing (default <code>cubic-bezier(0.16, 1, 0.3, 1)</code>).</li>
</ul>
