<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">The runtime declares the single <code>default</code> state; the editable contract below lives on the nav/list as <code>data-*</code> attributes, driven per instance through the bound <code>api</code> or the State tab:</p>
  <p class="text-sm text-muted-foreground">Machine contract - verified against <a href="../schemas/pagination.schema.json"><code>pagination.schema.json</code></a> by <code>bun run verify</code>:</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `activePage` | `number` | `—` | `3` | Current page - rendered `aria-current="page"`; changed by links, `next()`/`prev()` actions or the panel. |
| `minPage` | `number` | `—` | `1` | First selectable page (panel edits re-render the links). |
| `maxPage` | `number` | `—` | `20` | Last selectable page (panel edits re-render the links). |
| `pageDisplayCount` | `number` | `—` | `3` | How many page links the window shows around the active page (rest collapse to ellipsis). |
| `size` | `enum` | `xs`, `sm`, `md`, `lg`, `xl` | `"md"` | Link scale (display sizes). |
```

</StatesSection>
