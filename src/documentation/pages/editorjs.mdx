<PageHeader slug="editorjs" title="Editor.js" component="editorjs">
  The official <a class="link" href="https://editorjs.io" target="_blank" rel="noopener">Editor.js</a> block editor as a component: write the document as Markdown (or as Editor.js JSON) inside the element, the runtime loads the pinned builds of the editor and its tools on the first editor of a page, mounts it in the theme's tokens and hands the document back as Markdown or as blocks. A <DocLink href="toolbar.html">Toolbar</DocLink> drives the formatting through <code>data-editor-command</code> buttons. The <DocLink href="scaffold-document-editor.html">Document Editor</DocLink> scaffold builds a Google-Docs-style editor with a comment column on it.
</PageHeader>

```html example label="Editor.js JSON, read only" hint="A saved document - Editor.js output data with its block ids - authored as application/json. data-readonly shows it without editing; the readonly state toggles both the attribute and the editor's mode." previewStyle="justify-content:flex-start;"

  </div>
  <div class="flex items-center gap-2">
    <button class="btn" data-variant="outline" data-size="sm" type="button" id="ed-json-toggle">Make editable</button>
    <span class="badge" data-variant="secondary" id="ed-json-state">readonly</span>
  </div>
</div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    df$('#ed-json-toggle').on('click', () => {
      const el = df$('#ed-json').get(0);
      const next = el.api.getState().name === 'readonly' ? 'default' : 'readonly';
      el.api.setState(next);
      df$('#ed-json-state').text(next);
      df$('#ed-json-toggle').text(next === 'readonly' ? 'Make editable' : 'Make read only');

  document.addEventListener('DOMContentLoaded', () => {

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - editable: the editor accepts input, the toolbar commands apply</li>
    <li><code>readonly</code> - <code>data-readonly</code> on the element and the editor's read-only mode: the document shows, its toolbars are hidden, nothing edits it</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/editorjs-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/editorjs.schema.json"><code>editorjs.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `readonly` | `boolean` | `true`, `false` | `false` | Read only: `data-readonly` on the element, the editor in read-only mode. |
```
