<PageHeader slug="calendar" title="Calendar" component="calendar">
  A month-view calendar for date selection. Features navigation, today highlighting, and day selection. Built with vanilla JS rendering into a <code>&lt;table&gt;</code> grid.
</PageHeader>

  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> — reset to today's month with no selection; <code>setState('default', \{ year, month, day \})</code> (0-based month) navigates and optionally selects, and <code>getState().config</code> reports the live view</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/calendar-\{state\}.png</code>.</p>
