```html example label="Prices per night" hint="A note is a second line under the number - here each night's price; the cells grow to fit. The data is loaded per month: calendar:view fires whenever the visible month changes (arrows, month / year picker, setState) and the page answers with api.setDays() for exactly that month (fetch it from your API; this one computes it). Booked nights are mark: booked + disabled, so a stay can't start on them." height="28"
<div class="calendar" data-mode="range" data-min-date="2026-10-01" data-current-date="2026-10" id="nightly" aria-label="Stay dates">
  <div class="calendar-header">
    <button class="calendar-nav" data-action="prev-month" aria-label="Previous month"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m15 18-6-6 6-6"></path></svg></button>
    <button type="button" class="calendar-heading" aria-live="polite"></button>
    <button class="calendar-nav" data-action="next-month" aria-label="Next month"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="m9 18 6-6-6-6"></path></svg></button>
  </div>
  <table class="calendar-grid" role="grid"></table>
</div>
<p class="text-sm text-muted-foreground" style="margin:0.75rem 0 0;">Stay: <output id="nightly-out">pick arrival and departure</output></p>
<script type="module">
  const cal = document.getElementById('nightly');
  const money = new Intl.NumberFormat('en', { style: 'currency', currency: 'EUR', maximumFractionDigits: 0 });
  const priceOf = (d) => (d.getDay() === 5 || d.getDay() === 6 ? 149 : 119) + (d.getMonth() === 11 ? 40 : 0);
  const booked = (d) => [3, 4, 5, 17, 18].includes(d.getDate());
  // one month's day data - in an app this is a fetch
  const monthDays = (year, month) => {
    const days = {};
    for (let day = 1; day <= new Date(year, month + 1, 0).getDate(); day++) {
      const d = new Date(year, month, day);
      const iso = year + '-' + String(month + 1).padStart(2, '0') + '-' + String(day).padStart(2, '0');
      days[iso] = booked(d)
        ? { mark: 'booked', label: 'Booked', disabled: true }
        : { note: money.format(priceOf(d)) };
    }
    return days;
  };
  cal.addEventListener('calendar:view', (e) => cal.api.setDays(monthDays(e.detail.year, e.detail.month), { merge: true }));
  const { year, month } = cal.api.getState().config;
  cal.api.setDays(monthDays(year, month));
  cal.addEventListener('calendar:range', (e) => {
    const { start, end } = e.detail;
    if (!end) return (document.getElementById('nightly-out').textContent = 'pick a departure date');
    let total = 0;
    for (const d = new Date(start); d < end; d.setDate(d.getDate() + 1)) total += priceOf(d);
    const nights = Math.round((end - start) / 864e5);
    document.getElementById('nightly-out').textContent = nights + (nights === 1 ? ' night, ' : ' nights, ') + money.format(total);
  });
</script>
```

  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - reset to today's month with no selection; <code>setState('default', \{ year, month, day \})</code> (0-based month) navigates and optionally selects, and <code>getState().config</code> reports the live view</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/calendar-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/calendar.schema.json"><code>calendar.schema.json</code></a> by <code>bun run verify</code>:


```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `currentDate` | `string` | `—` | `""` | Selected day as ISO `YYYY-MM-DD` (first of the month when nothing is selected); `setState('default', { date })` navigates and selects. Mirrored as `data-current-date`.
| `minDate` | `string` | `—` | `""` | Lower bound of the selectable range (`YYYY`/`YYYY-MM`/`YYYY-MM-DD`, `""` clears); days outside it render `data-disabled`. Mirrored as `data-min-date`.
| `maxDate` | `string` | `—` | `""` | Upper bound of the selectable range (same formats, `""` clears). Mirrored as `data-max-date`.
```
