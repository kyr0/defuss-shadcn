<h2 style="font-family:var(--font-display);font-size:1.5rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 1rem;">Quick start</h2>

<p class="text-sm text-muted-foreground mb-6">All files are served via <DocLink href="https://www.jsdelivr.com" target="_blank">jsDelivr</DocLink> CDN directly from the GitHub repo. No download or install required — just reference the URLs in your HTML.</p>

Prefer a smaller payload? Each component also lives in <code>components/\{name\}/</code> with its own <code>.css</code> and <code>.js</code> when needed — include only the components you use, they're independent of each other.</p>

  <pre><code>{"components/\n├-- all.css      ← bundle: every component stylesheet (readable)\n├-- all.min.css  ← minified bundle\n├-- all.min.css.map\n├-- all.js       ← bundle: every component's behavior (readable)\n├-- all.js.map   ← source map back to the .ts sources\n├-- all.min.js   ← minified bundle\n├-- all.min.js.map\n└-- dialog/\n    ├-- component-skill.md    ← HTML structure, attributes, ARIA (read this first)\n    ├-- dialog.css   ← stylesheet (include via <link>)\n    ├-- dialog.min.css       ← minified stylesheet\n    ├-- dialog.js    ← interaction behavior (include via <script type=\"module\">)\n    ├-- dialog.js.map        ← source map for dialog.js\n    ├-- dialog.min.js        ← minified behavior\n    └-- dialog.min.js.map    ← source map for dialog.min.js"}</code></pre>
  <p class="text-sm text-muted-foreground mt-2">Some components — like Button and Badge — are CSS-only. No JavaScript needed.</p>

<div style="margin-top:3rem;padding-top:2rem;border-top:1px solid var(--border);">
  <h2 style="font-family:var(--font-display);font-size:1.5rem;font-weight:400;letter-spacing:-0.02em;margin:0 0 0.75rem;">Minified builds &amp; source maps</h2>
  <p class="text-sm text-muted-foreground mb-3">Every component also ships minified twins, generated at build time with <DocLink href="https://oxc.rs" target="_blank">oxc-minify</DocLink> (JS) and <DocLink href="https://lightningcss.dev" target="_blank">Lightning CSS</DocLink> (CSS). Swap the extension to <code>.min.css</code> / <code>.min.js</code> in any URL:</p>
  <pre><code class="language-markup">{"<link rel=\"stylesheet\" href=\"https://cdn.jsdelivr.net/gh/kyr0/defuss-shadcn@latest/dist/components/dialog/dialog.min.css\">\n<script type=\"module\" src=\"https://cdn.jsdelivr.net/gh/kyr0/defuss-shadcn@latest/dist/components/dialog/dialog.min.js\"></script>"}</code></pre>
  <p class="text-sm text-muted-foreground mt-2">Minification changes no behavior — the State API (<code>el.api.setState()</code>), globals and <code>data-\*</code> attributes work identically. Debugging stays intact: <code>dialog.js.map</code> maps the readable file back to its source and <code>dialog.min.js.map</code> maps the minified file through it; devtools pick both up automatically via <code>sourceMappingURL</code>, so you can set breakpoints in the original source even when loading the <code>.min.js</code>.</p>
  <p class="text-sm text-muted-foreground" style="margin-top:0.75rem;">The bundle ships the same way: <code>all.min.css</code> (+ <code>all.min.css.map</code>) and <code>all.min.js</code> (+ <code>all.min.js.map</code>) are the minified twins of <code>all.css</code> / <code>all.js</code> — swap them in by URL alone:</p>
  <pre><code class="language-markup">{"<link rel=\"stylesheet\" href=\"https://cdn.jsdelivr.net/gh/kyr0/defuss-shadcn@latest/dist/components/all.min.css\">\n<script type=\"module\" src=\"https://cdn.jsdelivr.net/gh/kyr0/defuss-shadcn@latest/dist/components/all.min.js\"></script>"}</code></pre>
  <p class="text-sm text-muted-foreground" style="margin-top:0.75rem;">Readable and minified files ship from the same source per release, so you can mix them freely — minified in production, readable while developing — and switch back by URL alone.</p>
</div>
