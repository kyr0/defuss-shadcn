<PageHeader slug="file-input" title="File Input" component="file-input">
  A styled file picker - as a compact field, or as a drag &amp; drop card. Built on native <code>&lt;input type="file"&gt;</code>: in the card the invisible input takes both the click and the drop, and a small script filters, appends and lists the files.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states of the drop zone, bound on each <code>.file-drop</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - no files (setState clears the selection)</li>
    <li><code>dragover</code> - files are dragged over the zone</li>
    <li><code>selected</code> - files chosen (<code>config.files</code> sets placeholders)</li>
    <li><code>error</code> - some files were rejected (<code>config.message</code>)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/file-input-\{state\}.png</code>.</p>
  <p class="text-sm text-muted-foreground">Machine contract - verified against <a href="../schemas/file-input.schema.json"><code>file-input.schema.json</code></a> by <code>bun run verify</code>:</p>

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `disabled` | `boolean` | `true`, `false` | `false` | Picker off (native `disabled` attribute). |
| `size` | `enum` | `sm`, `md`, `lg` | `"md"` | Control scale (display sizes). |
| `dragover` | `boolean` | `true`, `false` | `false` | Drop zone: files hover it. |
| `selected` | `boolean` | `true`, `false` | `false` | Drop zone: files chosen. |
| `error` | `boolean` | `true`, `false` | `false` | Drop zone: some files rejected. |
```

</StatesSection>
