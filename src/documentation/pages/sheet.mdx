<PageHeader slug="sheet" title="Sheet" component="sheet">
  Extends the dialog pattern to display content that slides in from the edge of the screen. Built on native <code>&lt;dialog&gt;</code> + <code>showModal()</code> with CSS-only slide animations via <code>@starting-style</code>. Supports four sides: <code>right</code>, <code>left</code>, <code>top</code>, <code>bottom</code>.
</PageHeader>

<SkillText dense>• <code>data-side</code> — values: <code>right</code>, <code>left</code>, <code>top</code>, <code>bottom</code></SkillText>
  <SkillText dense>• <code>data-sheet-trigger</code></SkillText>
  <SkillText>• <code>data-sheet-close</code></SkillText>
  </SkillField>

  <SkillField label="Wiring conventions">
<SkillText dense>• <code>data-sheet-trigger="\[id\]"</code> on any element → opens that sheet</SkillText>
  <SkillText dense>• <code>data-sheet-close</code> on any element inside → closes the sheet</SkillText>
  <SkillText dense>• Click on backdrop → closes (click lands on <code>&lt;dialog&gt;</code> itself)</SkillText>
  <SkillText>• Place <code>&lt;dialog&gt;</code> elements as direct children of <code>&lt;body&gt;</code></SkillText>
  </SkillField>

  <SkillField label="Notes">
<SkillText dense>• While a sheet is modal, <code>html:has(dialog.sheet:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> — the page behind cannot scroll and its position is preserved for when the sheet closes (no JS scroll-lock).</SkillText>
  <SkillText dense>• Right/left sheets have a fixed width of <code>24rem</code> with <code>max-width: 100vw</code> for small screens.</SkillText>
  <SkillText dense>• Top/bottom sheets are full width with <code>height: auto</code> — they size to their content.</SkillText>
  <SkillText dense>• The selector is <code>dialog.sheet</code> (element + class) to avoid conflicts with <code>dialog.dialog</code>.</SkillText>
  <p class="text-muted-foreground" style="margin:0 0 0;">• The <code>sheet-header</code> has <code>padding-right: 2rem</code> to avoid overlapping the close button.</p>
  </SkillField>
</SkillPanel>

  <ul class="text-sm text-muted-foreground" style="margin:0 0 0.75rem;padding-left:1.25rem;">
    <li><code>default</code> — closed, off-screen (the authored state; the trigger opens it)</li>
