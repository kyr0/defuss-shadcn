<PageHeader slug="collapsible" title="Collapsible" component="collapsible">
  An interactive panel that expands/collapses content. Built on native <code>&lt;details&gt;</code> with animated transitions.
</PageHeader>

```html example label="Basic" hint="Simple collapsible with a trigger and content."
<details class="collapsible">
  <summary class="collapsible-trigger">
    <span>Can I use this?</span>
    <svg class="collapsible-chevron">...</svg>
  </summary>
  <div class="collapsible-content">
    <p>Yes, it's free to use.</p>
  </div>
</details>
```

```html example label="Open by Default" hint="Use the open attribute to start expanded."
<details class="collapsible" open>
  <summary class="collapsible-trigger">...</summary>
  <div class="collapsible-content">...</div>
</details>
```
