<PageHeader slug="badge" title="Badge" component="badge">
  A small visual indicator for status, labels, or counts. Built on a <code>&lt;span&gt;</code> element with variant styling via <code>data-variant</code>. No JavaScript required.
</PageHeader>

```html example label="Default" hint="High emphasis with primary background."
<span class="badge" data-variant="default">New</span>
```

```html example label="Secondary" hint="Medium emphasis with secondary background."
<span class="badge" data-variant="secondary">Draft</span>
```

```html example label="Outline" hint="Low emphasis with border only."
<span class="badge" data-variant="outline">v0.1.0</span>
```

```html example label="All Variants" hint="Side-by-side comparison."
<span class="badge" data-variant="default">Default</span>
<span class="badge" data-variant="secondary">Secondary</span>
<span class="badge" data-variant="outline">Outline</span>
```

```html example label="Decorative" hint="If a badge is purely visual, hide it from screen readers with aria-hidden."
<span class="badge" data-variant="default"
      aria-hidden="true">5</span>
```

```html example label="On a Button" hint="Badge inside a .btn for notification counts."
<button class="btn" data-variant="outline">
  Inbox
  <span class="badge" data-variant="default">3</span>
</button>
```

```html example label="In a Card" hint="Badge in a .card header for status display."
<article class="card" style="width:20rem;">

```
