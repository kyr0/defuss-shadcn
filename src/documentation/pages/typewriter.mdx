<PageHeader slug="typewriter" title="Typewriter" component="typewriter">
  A line that types itself: character by character behind a cursor, held, deleted and on to the next string. The strings are authored as elements - without script the first one shows as text, and a screen reader hears the whole list once, never a keystroke at a time; the typed copy is <code>aria-hidden</code>. The cursor is solid while typing and blinks while idle, like a real one. Next to <DocLink href="text-rotate.html">Text Rotate</DocLink>, which rolls words without typing.
</PageHeader>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - running; restarts from the first string (or <code>\{ index \}</code>), resumes when coming from <code>paused</code></li>
    <li><code>paused</code> - frozen where it is, the cursor blinks</li>
    <li><code>done</code> - stopped with a string in full (<code>\{ index \}</code>); entered by itself at the end of a run without <code>data-loop</code></li>
  </ul>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/typewriter-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/typewriter.schema.json"><code>typewriter.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `index` | `number` | `—` | `0` | The string on screen; `setState('default', { index })` restarts from it. |
| `paused` | `boolean` | `true`, `false` | `false` | Frozen where it is; the cursor blinks. |
| `done` | `boolean` | `true`, `false` | `false` | Stopped with a string in full; entered at the end of a run without `data-loop`. |
```
