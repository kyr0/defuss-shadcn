<PageHeader slug="image" title="Image" component="image">
  A figure-based image component with fallback, lightbox preview, aspect ratio control, and caption. Built on <code>&lt;figure&gt;</code>, <code>&lt;dialog&gt;</code>, and native CSS.
</PageHeader>

<p class="text-sm text-muted-foreground mb-6">Sub-pages: <DocLink href="image-gallery.html">Image Gallery</DocLink> - an auto-advancing gallery composed from <code>figure.image</code> slides, with per-slide dwell times and every DOM write routed through defuss-query.</p>

<SkillPanel component="image">
  <SkillField label="Native basis">
<SkillText><code>&lt;figure&gt;</code> wrapping <code>&lt;img&gt;</code> with optional <code>&lt;figcaption&gt;</code>. Uses <code>&lt;dialog&gt;</code> for fullscreen lightbox.</SkillText>
  </SkillField>

  <SkillField label="Web Platform APIs">
<SkillRow>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/figure" title="self-contained content with optional caption"><code>&lt;figure&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/HTML/Element/dialog" title="native modal for lightbox preview"><code>&lt;dialog&gt;</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/aspect-ratio" title="intrinsic aspect ratio control"><code>aspect-ratio</code></ApiPill>
    <ApiPill href="https://developer.mozilla.org/en-US/docs/Web/CSS/@starting-style" title="entry animation for lightbox"><code>@starting-style</code></ApiPill>
  </SkillRow>
  </SkillField>

  <SkillField label="Classes">
<SkillRow>
    <code>.image</code>
    <code>.image-caption</code>
    <code>.image-fallback</code>
    <code>.image-lightbox</code>
  </SkillRow>
  </SkillField>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-preview</code> - enables click-to-preview lightbox</SkillText>
  <SkillText dense>• <code>data-ratio</code> - values: <code>1/1</code>, <code>4/3</code>, <code>3/2</code>, <code>16/9</code>, <code>21/9</code>, <code>3/4</code></SkillText>
  <SkillText dense>• <code>data-fit</code> - values: <code>contain</code>, <code>fill</code>, <code>none</code></SkillText>
  <SkillText dense>• <code>data-radius</code> - values: <code>none</code>, <code>sm</code>, <code>md</code>, <code>full</code></SkillText>
  <SkillText dense>• <code>data-src-low</code> - low-res placeholder, swapped for the real source once preloaded</SkillText>
  <SkillText dense>• <code>data-src-high</code> - high-res source: used on ≥2dppx displays, or on the first lightbox zoom-in</SkillText>
  </SkillField>

  <SkillField label="Notes">
<p class="text-muted-foreground m-0">• While the lightbox is modal, <code>html:has(dialog.image-lightbox:modal)</code> sets <code>overflow: hidden</code> + <code>scrollbar-gutter: stable</code> - the page behind cannot scroll and its position is preserved for when the lightbox closes (no JS scroll-lock).</p>
  </SkillField>
</SkillPanel>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, driven per instance through the bound <code>api</code>:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - image loaded, caption/fallback hidden</li>
    <li><code>error</code> - <code>.image-fallback</code> revealed (the same state a failed network load produces)</li>
  </ul>
  <p class="text-sm text-muted-foreground">The demo element carries <code>data-state-demo</code>; <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/image-\{state\}.png</code>.</p>

Machine contract - verified against <a href="../schemas/image.schema.json"><code>image.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `error` | `boolean` | `true`, `false` | `false` | Broken-image fallback styling (`img[data-error]`). |
```
