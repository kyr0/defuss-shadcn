<PageHeader slug="media-timeline" title="Media Timeline" component="media-timeline">
  The time of a recording, laid out from one JSON: tracks of regions (scenes, speakers, sounds), markers (cuts) and spans (a region derived from others), drawn under a ruler with a playhead. It drives a <DocLink href="video.html">Video</DocLink>, an <DocLink href="audio.html">Audio</DocLink> or a bare media element both ways - the media moves the playhead, a click, a drag or a key on the timeline moves the media - turns its text rows into keyed text tracks of the media (subtitles, captions, picture descriptions - a Video offers them in its captions menu), and fills outlets anywhere on the page with the items under the playhead and a log of timed events. Annotation rows sit above the content row they name, the ruler may stack several scales, and a drag on it loops a region. New data re-renders it; the playhead stays where it is. Not the <DocLink href="timeline.html">Timeline</DocLink> of dated events.
</PageHeader>

  <SkillField label="Data attributes">
<SkillText dense>• <code>data-media="id"</code> - the Video, Audio or bare <code>&lt;video&gt;</code> / <code>&lt;audio&gt;</code> it drives</SkillText>
  <SkillText dense>• <code>data-zoom</code> - pixels per second to start with (default: fit the width)</SkillText>
  <SkillText dense>• <code>data-media-timeline-action</code> - <code>zoom-in</code>, <code>zoom-out</code>, <code>fit</code>, <code>toggle</code>; <code>data-media-timeline-output</code> - <code>time</code>, <code>duration</code>, <code>active</code></SkillText>
  <SkillText dense>• <code>data-media-timeline-for="id"</code> + <code>data-media-timeline-outlet="info"</code> - an info outlet anywhere on the page: a Card per item under the playhead that carries <code>info</code></SkillText>
  <SkillText dense>• <code>data-media-timeline-outlet="events"</code> - the data's <code>events</code> as a list, each time a link that seeks there and pauses</SkillText>
  <SkillText dense>• <code>data-media-timeline-action="loop-clear"</code>, <code>"seek"</code> (+ <code>data-value</code>); <code>data-media-timeline-output="loop"</code></SkillText>
  <SkillText>In the JSON: <code>for</code> puts a row above the row it names, <code>background</code> tints it, <code>color</code> takes a theme name or a CSS colour, <code>scales</code> stacks ruler rows (h, min, s, frame), <code>kind</code> <code>video</code> / <code>audio</code> marks content rows and <code>subtitles</code> / <code>captions</code> / <code>descriptions</code> text rows</SkillText>
  </SkillField>

  <SkillField label="Keyboard">
<SkillText dense>• <kbd>Left</kbd> / <kbd>Right</kbd> - 1 second (<kbd>Shift</kbd>: 5)</SkillText>
  <SkillText dense>• <kbd>Page Up</kbd> / <kbd>Page Down</kbd> - 10 seconds</SkillText>
  <SkillText dense>• <kbd>Home</kbd> / <kbd>End</kbd> - the start, the end</SkillText>
  <SkillText dense>• <kbd>[</kbd> / <kbd>]</kbd> - the loop starts / ends at the playhead; <kbd>Escape</kbd> clears it</SkillText>
  <SkillText>• A drag on the ruler draws a loop, a double click there clears it</SkillText>
  </SkillField>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">Named states via the shared State API, bound on each <code>.media-timeline</code> - it mirrors the media it drives:</p>
  <ul class="text-sm text-muted-foreground m-0 mb-3 ps-5">
    <li><code>default</code> - the media is paused (without media: the timeline's own clock stands) - the playhead stands</li>
    <li><code>playing</code> - the media plays and the playhead moves with it; without media the timeline's own clock runs to the end of the length and lands in <code>default</code>; a browser may refuse to start sound without a click (autoplay rules), and the state then stays <code>default</code></li>
  </ul>
  <p class="text-sm text-muted-foreground m-0 mb-3">Both take the same config, merged into the current one - only the keys passed change something: <code>time</code> (the media seeks there), <code>zoom</code> (pixels per second, 0 fits), <code>data</code> (re-renders, the playhead stays), <code>loop</code> (<code>\{ start, end \}</code> - playback stays inside it - or <code>null</code>). The event <code>media-timeline-change</code> reports the items under the playhead whenever they change, <code>media-timeline-loop</code> the loop.</p>
  <p class="text-sm text-muted-foreground">The first example carries <code>data-state-demo</code> (its own clock plays it); <code>bun run screenshots</code> drives it via <code>el.api.setState(name)</code> and captures <code>screenshots/\{mode\}/media-timeline-\{state\}.png</code>.</p>

Machine contract - verified against <a class="link" href="../schemas/media-timeline.schema.json"><code>media-timeline.schema.json</code></a> by <code>bun run verify</code>:

```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `playing` | `boolean` | `true`, `false` | `false` | The controlled media plays (`setState('playing')`); unchecked it pauses. |
| `time` | `number` | | `0` | The playhead's time in seconds - the media seeks there; observed from `getState().config.time`. |
| `zoom` | `number` | | `0` | Pixels per second; 0 fits the whole length into the width. |
```
