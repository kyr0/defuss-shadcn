<PageHeader slug="resizer" title="Resizer" component="resizer">
  Wraps <strong>one</strong> container element and makes it resizable via draggable handles on
  any subset of its sides and corners - either pixel-perfect (inline styles) or class-based
  (the <code>w-\*</code>/<code>h-\*</code> utilities stay the source of truth). This documentation
  site dogfoods it: the preview box of every <DocLink href="code-example.html">CodeExample</DocLink>
  carries resizer handles on all 8 positions.
</PageHeader>

<SkillText dense>• <code>data-handles</code> - space list of <code>n e s w ne nw se sw</code>, or <code>all</code> (default <code>se</code>)</SkillText>
  <SkillText dense>• <code>data-resize-mode</code> - <code>px</code> (default) | <code>classes</code> | <code>controlled</code></SkillText>
  <SkillText dense>• <code>data-axis</code> - <code>both</code> (default) | <code>w</code> | <code>h</code>; handles the axis forbids are never placed</SkillText>
  <SkillText dense>• <code>data-min</code>/<code>data-max</code> - clamp in px (80 / 2000; per-axis <code>data-min-w</code> ... override), <code>data-step</code> quantizes drags</SkillText>

  <SkillField label="Accessibility">

  <p class="text-muted-foreground m-0">• While dragging, the wrapper carries <code>data-resizing</code> - a dashed outline plus a filled handle</p>

<script type="module">
  const wrap = document.querySelector(".resizer");
  const out = document.getElementById("rs-controlled");
  const box = wrap.firstElementChild;
  wrap.addEventListener("resizer-resize", (e) => {
    box.style.width = e.detail.width + "px";
    box.style.height = e.detail.height + "px";
    out.textContent = e.detail.width + " × " + e.detail.height;
  });
</script>

<StatesSection>
  <p class="text-sm text-muted-foreground m-0 mb-3">The <code>default</code> state restores the size the markup was authored with (snapshotted at init); <code>setState('default', \{ width, height \})</code> applies an explicit px size instead, and <code>getState().config</code> always reports the live box plus the active mode. The wrapper mirrors the live size onto <code>data-width</code>/<code>data-height</code>, and external writes to those attributes are applied back - that is the loop the State tab uses.</p>

Machine contract - verified against <a href="../schemas/resizer.schema.json"><code>resizer.schema.json</code></a> by <code>bun run verify</code>:


```states
| State | Type | Values | Default | Description |
| --- | --- | --- | --- | --- |
| `width` | `number` | `—` | `320` | Live width in px, mirrored on `data-width` (drags and keyboard write it; panel edits apply back). |
| `height` | `number` | `—` | `160` | Live height in px, mirrored on `data-height` (dropped while `data-axis="w"`). |
```

The action `reset` dispatches <code>resizer-reset</code> on the wrapper - equivalent to <code>setState('default')</code>.
