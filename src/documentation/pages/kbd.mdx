<PageHeader slug="kbd" title="Kbd" component="kbd">
  A keyboard key - for a shortcut in a menu item, a tooltip, a command palette row or a sentence. Built on the native <code>&lt;kbd&gt;</code> element; a combination is a <code>&lt;kbd&gt;</code> holding one <code>&lt;kbd&gt;</code> per key, exactly as the HTML spec prescribes, so the markup already says "these keys together". The thicker bottom edge is what makes a rectangle read as a key. CSS only.
</PageHeader>

```html example label="In a control" schema="none" hint="Inside a button the key drops its own surface and borrows the button's text colour through color-mix - legible on the dark primary button and the outline one alike. The shortcuts work: click into the preview, then press ⌘K, ⌘S or ⌘Z (Ctrl on Windows / Linux) - the page registers them with the shared global key API (df$.shadcn.shared.bindGlobalKeys), the key goes down (data-pressed) and the button's action runs."
<div class="flex flex-wrap items-center gap-3">
  <button class="btn" data-variant="outline" data-action="k">Search <kbd class="kbd" data-size="sm" data-shortcut="k">⌘K</kbd></button>
  <button class="btn" data-variant="default" data-action="s">Save <kbd class="kbd" data-size="sm" data-shortcut="s">⌘S</kbd></button>
  <button class="btn" data-variant="ghost" data-action="z">Undo <kbd class="kbd" data-size="sm" data-shortcut="z">⌘Z</kbd></button>
</div>
<output id="kbd-control-log" class="text-sm text-muted-foreground" style="display:block;margin-top:0.75rem;">Click into the preview, then press ⌘K, ⌘S or ⌘Z.</output>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const actions = {
      k: 'Search opened',
      s: 'Saved',
      z: 'Last change undone',
    };
    const run = (key) => {
      // the key goes down while the action runs - the reader sees it was heard
      const keys = df$('[data-shortcut="' + key + '"]').attr('data-pressed', '');
      setTimeout(() => keys.attr('data-pressed', null), 160);
      df$('#kbd-control-log').text(actions[key] + ' at ' + new Date().toLocaleTimeString('en'));
    };
    df$('[data-action]').on('click', (e) => run(e.currentTarget.dataset.action));
    // one shared, typing-safe listener for the whole page; ⌘ on macOS, Ctrl elsewhere
    df$.shadcn.shared.bindGlobalKeys((e) => {
      const key = e.key.toLowerCase();
      if (!(e.metaKey || e.ctrlKey) || e.shiftKey || e.altKey || !(key in actions)) return;
      e.preventDefault(); // ⌘S would save the page, ⌘K focus the address bar
      run(key);
      return true;
    });
  });
</script>
```

<script>
  document.addEventListener('DOMContentLoaded', () => {
    // the palette's ⌘K runs through df$.shadcn.shared.bindGlobalKeys (the command
    // component registers it); the keys in the sentence go down as they are pressed
    const press = (key) => {
      const keys = df$('[data-shortcut="' + key + '"]').attr('data-pressed', '');
      setTimeout(() => keys.attr('data-pressed', null), 160);

      if ((e.metaKey || e.ctrlKey) && e.key.toLowerCase() === 'k') press('k');
      if (e.key === 'Escape') press('escape');

  });
</script>

```html example label="In a menu" schema="none" hint="Shortcuts in dropdown items blend in the same way - the key takes the item's colour, including the highlighted and destructive states. They work as written: click into the preview, then ⌫ deletes the last tag, ⌘Z brings it back, ⌘⇧Z deletes it again - the same actions the menu items run." height="24"
<div class="flex flex-wrap items-center gap-3">
  <button class="btn" data-variant="outline" data-dropdown-trigger="kbd-menu">Edit</button>
  <span id="kbd-tags" class="flex flex-wrap gap-2"></span>
</div>
<div id="kbd-menu" role="menu" popover class="dropdown-content" aria-label="Edit" style="min-width:13rem;">
  <button role="menuitem" class="dropdown-item" tabindex="-1" data-edit="undo">Undo <span class="dropdown-shortcut"><kbd class="kbd-group"><kbd class="kbd" data-size="sm" data-shortcut="undo">⌘</kbd><kbd class="kbd" data-size="sm" data-shortcut="undo">Z</kbd></kbd></span></button>
  <button role="menuitem" class="dropdown-item" tabindex="-1" data-edit="redo">Redo <span class="dropdown-shortcut"><kbd class="kbd-group"><kbd class="kbd" data-size="sm" data-shortcut="redo">⌘</kbd><kbd class="kbd" data-size="sm" data-shortcut="redo">⇧</kbd><kbd class="kbd" data-size="sm" data-shortcut="redo">Z</kbd></kbd></span></button>
  <div class="dropdown-separator" role="separator"></div>
  <button role="menuitem" class="dropdown-item" data-variant="destructive" tabindex="-1" data-edit="delete">Delete <span class="dropdown-shortcut"><kbd class="kbd" data-size="sm" data-shortcut="delete">⌫</kbd></span></button>
</div>
<output id="kbd-menu-log" class="text-sm text-muted-foreground" style="display:block;margin-top:0.75rem;">Click into the preview, then press ⌫, ⌘Z or ⌘⇧Z.</output>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const tags = ['design', 'review', 'ship'];
    const removed = [];
    const render = () => df$('#kbd-tags').html(tags.map((t) => '<span class="badge" data-variant="secondary">' + t + '</span>').join(''));
    const edits = {
      delete: () => { if (tags.length) removed.push(tags.pop()); return 'Deleted the last tag'; },
      undo: () => { if (removed.length) tags.push(removed.pop()); return 'Undone'; },
      redo: () => { if (tags.length) removed.push(tags.pop()); return 'Redone'; },
    };
    const run = (name) => {
      const keys = df$('[data-shortcut="' + name + '"]').attr('data-pressed', '');
      setTimeout(() => keys.attr('data-pressed', null), 160);
      df$('#kbd-menu-log').text(edits[name]() + ' - ' + tags.length + ' of 3 tags left');
      render();
    };
    render();
    df$('[data-edit]').on('click', (e) => run(e.currentTarget.dataset.edit));
    df$.shadcn.shared.bindGlobalKeys((e) => {
      const mod = e.metaKey || e.ctrlKey;
      const name = mod && e.key.toLowerCase() === 'z' ? (e.shiftKey ? 'redo' : 'undo') : !mod && (e.key === 'Backspace' || e.key === 'Delete') ? 'delete' : null;
      if (!name) return;
      e.preventDefault();
      run(name);
      return true;
    });
  });
</script>
```

```html example label="In a tooltip" schema="none" hint="On a tooltip's inverted surface the key borrows the tooltip's colours too - hover or focus the button. And ⌘B (Ctrl+B) does what the tooltip says: click into the preview and press it - registered with the shared global key API, the button and the text follow."
<div class="flex flex-wrap items-center gap-3">
  <button class="btn" data-variant="outline" data-tooltip-trigger="kbd-tip" aria-pressed="false" id="kbd-bold">Bold</button>

<div class="tooltip" id="kbd-tip" popover="hint" role="tooltip">Bold <kbd class="kbd-group"><kbd class="kbd" data-size="sm" data-shortcut="b">⌘</kbd><kbd class="kbd" data-size="sm" data-shortcut="b">B</kbd></kbd></div>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const toggle = () => {
      const on = df$('#kbd-bold').attr('aria-pressed') !== 'true';
      df$('#kbd-bold').attr('aria-pressed', String(on));
      df$('#kbd-bold-text').get(0).style.fontWeight = on ? '700' : '';
      const keys = df$('[data-shortcut="b"]').attr('data-pressed', '');
      setTimeout(() => keys.attr('data-pressed', null), 160);
    };
    df$('#kbd-bold').on('click', toggle);
    df$.shadcn.shared.bindGlobalKeys((e) => {
      if (!(e.metaKey || e.ctrlKey) || e.shiftKey || e.altKey || e.key.toLowerCase() !== 'b') return;
      e.preventDefault();
      toggle();
      return true;
    });
  });
</script>
```
