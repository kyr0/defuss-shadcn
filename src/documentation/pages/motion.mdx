<PageHeader slug="motion" title="Motion" component="motion">
  The shared entrance vocabulary for every component - decks, cards, lists, dialogs. CSS <code>@keyframes</code> are the source of truth (geometry, easing, reduced-motion); one attribute applies them declaratively, and a ~60-line controller (<code>ddf$.entrance()</code>) owns trigger/replay, timing overrides and the <code>finished</code>/<code>cancel</code> lifecycle through the browser's own <code>CSSAnimation</code> objects. No animation library.
</PageHeader>

<p class="text-sm text-muted-foreground m-0 mb-3">Motion is a static stylesheet plus a core-embedded controller - no per-element State API and no JavaScript file of its own; the runtime declares only <code>default</code>.</p>
