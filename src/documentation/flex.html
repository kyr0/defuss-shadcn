Flex

Direction, wrapping, alignment and flexible sizing using native Flexbox. No implicit gap and no visual reordering helpers.

One-dimensional composition

Start with flex or inline-flex. Add direction, wrapping, alignment and spacing explicitly. stack is a convenience for a column with a default four-unit, density-aware gap.

Handle the real overflow source

A flex item’s automatic minimum can resist shrinking. Apply min-w-0 to the flexible content region and choose text wrapping or scrolling. Do not fix overflow by clipping the entire layout. justify-between distributes spare space; it is not a substitute for a minimum gap.

HTML
<div class="flex gap-4">
  <span class="w-16 shrink-0">Label</span>
  <div class="flex-1 min-w-0" style="overflow-wrap:anywhere;">
    LongContentCanNowWrapWithoutWideningItsParent
  </div>
</div>

Change structure with a named query

HTML
<section class="query">
  <div class="flex flex-col gap-4 action-row">
    <button class="btn" type="button">First</button>
    <button class="btn" type="button">Second</button>
  </div>
</section>
CSS
@container layout (inline-size >= 30rem) {
  .action-row { flex-direction: row; }
}

The custom rule is unlayered, so it overrides the helper intentionally. No reverse-direction or order helpers are shipped: preserve the relationship between visual, reading and keyboard order.
