SwapATM

Swaps between two (or three) faces in place — icons, glyphs, or words. A hidden <input type="checkbox"> inside a <label> holds the state and :has() picks the visible face. No JavaScript.

Component Skill — components/swap/component-skill.md

Native basis

<label> wrapping a hidden <input type="checkbox"> plus the face elements. The checkbox holds the state; CSS decides which face is visible.

Web Platform APIs

<label> <input type="checkbox"> :checked :indeterminate :has() rotate backface-visibility prefers-reduced-motion

Classes

.swap .swap-on .swap-off .swap-indeterminate

Variants (data-variant)

rotateCrossfade plus a ±45° rotation flipCrossfade plus a 180° flip around the Y axis

Sizes (data-size)

sm2rem floor, 0.75rem type, 1rem icons lg2.75rem floor, 1.125rem type, 1.5rem icons

Default

Crossfade between two faces. Click it — the checkbox is the state.

<label class="swap">
  <input type="checkbox" aria-label="Toggle text">
  <span class="swap-on">ON</span>
  <span class="swap-off">OFF</span>
</label>

Icons

Any content works as a face. Mark decorative glyphs aria-hidden and name the checkbox.

<label class="swap">
  <input type="checkbox" aria-label="Toggle sound">
  <span class="swap-on" aria-hidden="true"><svg>…</svg></span>
  <span class="swap-off" aria-hidden="true"><svg>…</svg></span>
</label>

Rotate

data-variant="rotate" swings the faces in and out over ±45°.

<label class="swap" data-variant="rotate">
  <input type="checkbox" aria-label="Toggle theme">
  <span class="swap-on" aria-hidden="true"><svg>…</svg></span>
  <span class="swap-off" aria-hidden="true"><svg>…</svg></span>
</label>

Flip

data-variant="flip" turns the control over on its Y axis.

<label class="swap" data-variant="flip" data-size="lg">
  <input type="checkbox" aria-label="Toggle mood">
  <span class="swap-on" aria-hidden="true">😇</span>
  <span class="swap-off" aria-hidden="true">😈</span>
</label>

Sizes

data-size sets the minimum box plus the type and icon scale. The control still grows to fit its widest face.

<label class="swap" data-size="sm">…</label>
<label class="swap">…</label>
<label class="swap" data-size="lg">…</label>

Third face (indeterminate)

A .swap-indeterminate face shows while the checkbox is indeterminate. indeterminate is an IDL property only — set it from script.

<label class="swap">
  <input type="checkbox" id="tri" aria-label="Selection">
  <span class="swap-on">All</span>
  <span class="swap-indeterminate">Some</span>
  <span class="swap-off">None</span>
</label>
<script>document.getElementById('tri').indeterminate = true;</script>

Forced on

data-active on the label shows the on face regardless of the checkbox — for rendering server-side state without a checked input.

<label class="swap" data-active>
  <input type="checkbox" aria-label="Forced on">
  <span class="swap-on">ON</span>
  <span class="swap-off">OFF</span>
</label>

Disabled

A disabled checkbox dims the label and blocks pointer events — native, no extra class.

<label class="swap">
  <input type="checkbox" disabled aria-label="Disabled swap">
  <span class="swap-on">ON</span>
  <span class="swap-off">OFF</span>
</label>

States

Swap is CSS-only, so it declares a single State API state: default. The visible face follows the checkbox's DOM state rather than an api.setState() call.

defaultRendered by CSS; the face follows the checkbox

The DOM-level axes layered on top of it:

inputunchecked → .swap-off input:checked→ .swap-on input:indeterminate→ .swap-indeterminate [data-active]forces .swap-on, overriding the checkbox input:disabledcurrent face, dimmed and non-interactive 
// CSS-only: drive the checkbox, not api.setState()
document.querySelector('.swap input').checked = true;         // on face
document.querySelector('.swap input').indeterminate = true;   // third face

The first demo carries data-state-demo; bun run screenshots uses it as the state-capture anchor and captures screenshots/{mode}/swap.png.

CSS view file

/* -- Swap component -------------------------------------------- */

@layer components {
  .swap {
    /* the faces stack in one grid cell, so the box sizes to the widest one
       and no absolute positioning / JS measurement is needed */
    position: relative;
    display: inline-grid;
    place-items: center;
    min-width: 2.25rem;
    min-height: 2.25rem;
    border-radius: var(--radius-md);
    font-family: var(--font-sans);
    font-size: 0.875rem;
    font-weight: 500;
    line-height: 1;
    color: var(--foreground);
    cursor: pointer;
    user-select: none;
    vertical-align: middle;
    /* flip needs depth; harmless for the other variants */
    perspective: 40rem;

    /* the checkbox IS the state — visually hidden but focusable and
       hit-testable across the whole control (no .sr-only dependency) */
    & > input[type="checkbox"] {
      grid-area: 1 / 1;
      appearance: none;
      -webkit-appearance: none;
      width: 100%;
      height: 100%;
      margin: 0;
      padding: 0;
      border: 0;
      opacity: 0;
      cursor: inherit;
    }

    & .swap-on,
    & .swap-off,
    & .swap-indeterminate {
      grid-area: 1 / 1;
      display: inline-flex;
      align-items: center;
      justify-content: center;
      opacity: 0;
      pointer-events: none;
      backface-visibility: hidden;
      transition:
        opacity 300ms cubic-bezier(0.4, 0, 0.2, 1),
        rotate 300ms cubic-bezier(0.4, 0, 0.2, 1),
        scale 300ms cubic-bezier(0.4, 0, 0.2, 1);
    }

    & svg:not([class*="size-"]) {
      width: 1.25rem;
      height: 1.25rem;
      flex-shrink: 0;
    }

    /* -- Faces: default (off) ------------------------------- */
    & .swap-off { opacity: 1; }

    /* -- Faces: indeterminate ------------------------------- */
    &:has(> input:indeterminate) {
      & .swap-off { opacity: 0; }
      & .swap-indeterminate { opacity: 1; }
    }

    /* -- Faces: on (checked, or forced via data-active) ------ */
    &:has(> input:checked),
    &[data-active] {
      & .swap-off,
      & .swap-indeterminate { opacity: 0; }
      & .swap-on { opacity: 1; }
    }

    /* -- Variant: rotate ------------------------------------ */
    &[data-variant="rotate"] {
      & .swap-on,
      & .swap-indeterminate { rotate: -45deg; }

      &:has(> input:indeterminate) {
        & .swap-off { rotate: 45deg; }
        & .swap-indeterminate { rotate: 0deg; }
      }

      &:has(> input:checked),
      &[data-active] {
        & .swap-off,
        & .swap-indeterminate { rotate: 45deg; }
        & .swap-on { rotate: 0deg; }
      }
    }

    /* -- Variant: flip -------------------------------------- */
    &[data-variant="flip"] {
      & .swap-on,
      & .swap-indeterminate { rotate: y 180deg; }

      &:has(> input:indeterminate) {
        & .swap-off { rotate: y -180deg; }
        & .swap-indeterminate { rotate: y 0deg; }
      }

      &:has(> input:checked),
      &[data-active] {
        & .swap-off,
        & .swap-indeterminate { rotate: y -180deg; }
        & .swap-on { rotate: y 0deg; }
      }
    }

    /* -- Sizes ---------------------------------------------- */
    &[data-size="sm"] {
      min-width: 2rem;
      min-height: 2rem;
      font-size: 0.75rem;

      & svg:not([class*="size-"]) { width: 1rem; height: 1rem; }
    }

    &[data-size="lg"] {
      min-width: 2.75rem;
      min-height: 2.75rem;
      font-size: 1.125rem;

      & svg:not([class*="size-"]) { width: 1.5rem; height: 1.5rem; }
    }

    /* -- Interaction states --------------------------------- */
    &:hover { background-color: var(--accent); color: var(--accent-foreground); }

    &:has(> input:focus-visible) {
      outline: 2px solid var(--ring);
      outline-offset: 2px;
    }

    &:has(> input:disabled) {
      pointer-events: none;
      opacity: 0.5;
      cursor: not-allowed;
    }
  }

  /* Accessibility: honour a reduced-motion request — the faces still swap,
     they just do not animate (near-zero duration keeps transitionend firing). */
  @media (prefers-reduced-motion: reduce) {
    .swap .swap-on,
    .swap .swap-off,
    .swap .swap-indeterminate {
      transition-duration: 0.01ms !important;
    }
  }

  @media (prefers-contrast: more) {
    .swap {
      border: 2px solid transparent;

      &:has(> input:checked),
      &[data-active] { border-color: currentColor; }
    }
  }

  @media (forced-colors: active) {
    .swap {
      border: 1px solid ButtonText;
      color: ButtonText;
      forced-color-adjust: none;

      &:has(> input:checked),
      &[data-active] {
        background: Highlight;
        color: HighlightText;
      }

      &:has(> input:disabled) { border-color: GrayText; color: GrayText; }
    }
  }
}
