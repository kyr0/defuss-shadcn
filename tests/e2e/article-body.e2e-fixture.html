Every operation lands in a local log before it touches the document. Press ⌘ S? You never have to. The flush is three lines:

const ops = log.since(cursor);
await server.push(ops);
await server.push(ops, { idempotent: true });
cursor = ops.at(-1).id;

Sync is the feature nobody notices until it fails. When we started on Acme 4.0, our goal was simple to state and hard to build: never lose a keystroke, online or off.

Why CRDTs

A conflict-free replicated data type lets two devices edit the same document without a server deciding who wins. Every change is an operation; every operation commutes. Merging becomes a set union.

  • Edits apply instantly, on any device
  • The server stores operations, not documents
  • Any two replicas converge - in any order

The best sync is the one you forget is there.

Hannah Lee, Design

The write-ahead log

Every operation lands in a local log before it touches the document. Call flush() and the log ships in batches:

const ops = log.since(cursor);
await server.push(ops);
cursor = ops.at(-1).id;

Ten years ago, three of us rented a room above a bakery and promised each other one thing: we would build software that let people go home on time. Everything else - the product, the company, this blog - grew from that promise.

Most of what we got right was saying no. No notifications by default. No streaks. No dashboards nobody asked for.

What we would do differently

We waited too long to build offline support - and far too long to write things down.
