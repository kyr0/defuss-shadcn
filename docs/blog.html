BlogBLK

Native basis

The whole card is a single <a> wrapping the preview — one tab stop, one click target. Excerpt clamping uses -webkit-line-clamp (shipped everywhere), media uses aspect-ratio; authors compose the [Avatar](../avatar/component-skill.md) component.
