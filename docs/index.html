defuss-shadcn / introduction

A UI component system
that scales with local AI.

Themeable components built on semantic HTML, modern CSS, and vanilla JavaScript. No framework. No build step for consumers — dist/ is committed and ready to use as-is. The simplest possible foundation for AI-driven prototyping.

Get Started GitHub

This documentation dogfoods the system: on the published site the bundled stylesheet and script every demo here is styled and driven by — all.css / all.js — plus the theme are loaded straight from the jsDelivr CDN — the same URLs as the CDN quick start. Every demo that renders correctly is proof that the CDN install works in general. The demos also use the optional sizing, layout + accessibility modules directly — the utility classes you see in the code samples are the shipped ones, not docs CSS; the Form page even grids mixed field controls to prove they share one height ladder, and the density + size axes most components ship are demonstrated on their own pages.

Why this system exists, from the agents who built it: ARCH.md.

Themeable

Full shadcn semantic token model. Swap a tweakcn theme and every component updates instantly.

Component Skills

Every component includes a structured skill — markup, variants, sizes, density, ARIA, and wiring conventions — grounded in web standards. Point an agent at dist/SKILL.md: the generated index of every skill (type/why/when/where + supported states).

Observable state

Interactive components expose a State API (el.api.setState('open')), so agents and tests can drive every documented state by name.

Accessible

Built on native HTML elements and WAI-ARIA patterns. Keyboard navigation, focus management, and screen reader support by default — and every theme preset's nav text is contrast-gated (WCAG AA) by verify.

Framework Free

Runs in any browser, zero dependencies, no build pipeline required — and 44 of 71 components need no JavaScript at all. The shipped footprint (counts per type, JS/CSS-only split, byte sizes raw/minified/gzipped) is published as dist/stats.json.
