Width & Height

Arithmetic dimensions, content and viewport sizing, and explicit constraints. Density does not change geometric sizes.

Numeric dimensions

w-n, h-n and size-n map directly to n × --size-base. Width and height are physical axes, matching their CSS names. Density does not change them. inline-n and block-n are the logical-axis alternatives.

w-48 h-8
w-1/2
size-8
HTML
<div class="w-48 h-16">192 × 64px at the default 16px root</div>
<div class="size-8">Square</div>
<div class="w-1/2 max-w-full">Half of the containing width</div>
<div class="inline-48 block-16">Writing-mode-aware dimensions</div>

Numeric scale: 0, 0.5, 1, 1.5, 2, 2.5, 3, 3.5, 4, 5, 6, 7, 8, 9, 10, 11, 12, 14, 16, 20, 24, 28, 32, 36, 40, 48, 56, 64, 72, 80, 96. Values not listed require ordinary CSS. size-4 sets both width and height; it does not set flex-shrink or box-sizing.

Dimensions are constraints, not clipping

Percentage heights need a definite containing height. w-full is usually preferable to w-screen inside a page. In flex layouts, a requested width may shrink: add shrink-0 when that is intentional. Use min-w-0 on a flexible child and give long content an explicit wrapping or scroll policy.

HTML
<div class="flex gap-4">
  <aside class="w-48 shrink-0">Navigation</aside>
  <main class="flex-1 min-w-0" style="overflow-wrap:anywhere;">
    AnUnusuallyLongIdentifierThatMustWrapInsteadOfWideningThePage
  </main>
</div>

Application-specific sizes

CSS
.inspector { width: clamp(16rem, 30vw, 24rem); }
.application-shell { min-height: 100dvh; }
.article-copy { max-inline-size: 70ch; }

Keep content widths, typography and control recipes semantically distinct from the small geometric --size-xs…xl aliases. Load sizing.css; load layout.css as well for Flex/Grid helpers.
