Grid

Intrinsic card grids, explicit tracks and aligned subgrids. Responsive to available space without a breakpoint utility generator.

Intrinsic columns without breakpoints

grid only enables Grid. Add grid-cols-auto for auto-fit columns with a preferred minimum; --layout-min defaults to 16rem. Empty tracks collapse, and populated tracks share spare space.

CSS
grid-template-columns:
  repeat(auto-fit, minmax(min(100%, var(--layout-min)), 1fr));

The inner minimum prevents the preferred track width itself from exceeding a narrow container. It does not wrap long identifiers, shrink arbitrary media or eliminate intrinsic child overflow. Set those policies on the content.

Explicit tracks and spans

ConcernClasses
Columnsgrid-cols-1 through grid-cols-12; equal minmax(0, 1fr) tracks.
Rowsgrid-rows-1 through grid-rows-6.
Spanscol-span-1…12, row-span-1…6, col-span-full, row-span-full.
Other tracksgrid-cols-none, grid-rows-none, auto-cols-auto, auto-rows-auto.
Subgridgrid-cols-subgrid, grid-rows-subgrid.
Alignmentitems-*, justify-items-start/end/center/stretch, justify-self-auto/start/end/center/stretch, place-items-start/end/center/stretch/baseline, place-self-auto/start/end/center/stretch.
HTML
<div class="grid grid-cols-3 gap-4">
  <header class="col-span-full">Dashboard</header>
  <aside>Filters</aside>
  <section class="col-span-2">Results</section>
</div>

A span larger than the available explicit tracks can create implicit columns. Keep spans compatible with every responsive track configuration; do not use a fixed span in a one-column auto-fit layout without an intentional override.

A much longer body that would push a naive footer down. Subgrid keeps both footers on one line.

HTML
<div class="grid grid-cols-2 gap-4">
  <article class="grid row-span-3 grid-rows-subgrid">
    <h3>Starter</h3>
    <p>For a small project.</p>
    <button class="btn" type="button" aria-label="Choose Starter">Select</button>
  </article>
  <article class="grid row-span-3 grid-rows-subgrid">
    <h3>Team</h3>
    <p>For a larger group working across several projects.</p>
    <button class="btn" type="button" aria-label="Choose Team">Select</button>
  </article>
</div>

Each card spans three parent rows and adopts those rows as its subgrid. Subgrid is a structure contract, not a universal card rule. Without support, the cards retain ordinary independent grids; shared row alignment is the enhancement. CSS Grid is layout, not an ARIA grid widget.
